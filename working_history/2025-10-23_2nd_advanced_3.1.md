### 3. Toggle 시 처리

```kotlin
fun toggleAutoRun(id: String, isEnabled: Boolean) {
    viewModelScope.launch {
        repository.toggleEnabled(id, isEnabled)
        
        val autoRun = repository.getAll().first().find { it.id == id }
        if (autoRun != null) {
            if (isEnabled) {
                alarmManager.scheduleTimeBasedAutoRun(autoRun)
            } else {
                alarmManager.cancelTimeBasedAutoRun(id)
            }
        }
    }
}
```

**특징**:
- ✅ Toggle ON → 알람 스케줄링
- ✅ Toggle OFF → 알람 취소
- ✅ UI에서 Switch 클릭 시 즉시 반영

**리뷰어 2의 지적**: `toggleAutoRun()`에서 `repository.toggleEnabled()` 직후 `_autoRuns.value.find()`로 가져온 엔티티는 **stale data**(DB 업데이트 전 값)이므로, `isEnabled`가 여전히 false입니다.

        val autoRun = _autoRuns.value.find { it.id == autoRunId }
        if (autoRun != null) {
            if (isEnabled) {
                alarmManager.scheduleTimeBasedAutoRun(autoRun) // ❌ autoRun.isEnabled = false

            }

**결과**:

- 내부에서 `isEnabled` 체크 시 스케줄링을 건너뜀
- **Toggle ON 시 알람이 실제로 등록되지 않음** (Critical Bug)

---

### 해결 방법

**DB 업데이트 전에 엔티티를 복사하여 `isEnabled`를 업데이트한 후 전달**

```kotlin

fun toggleAutoRun(autoRunId: String, isEnabled: Boolean) {
    viewModelScope.launch {
        try {
            // 🔧 Critical Fix: stale data 문제 해결
            // DB 업데이트 전에 현재 엔티티를 복사하여 isEnabled 업데이트
            val currentAutoRun = _autoRuns.value.find { it.id == autoRunId }
            if (currentAutoRun == null) {
                _errorState.value = "자동 실행을 찾을 수 없습니다"
                return@launch
            }
            
            repository.toggleEnabled(autoRunId, isEnabled)
            
            // 활성화 시 알람 등록, 비활성화 시 알람 취소
            if (isEnabled) {
                // 복사한 엔티티의 isEnabled를 업데이트하여 전달
                alarmManager.scheduleTimeBasedAutoRun(currentAutoRun.copy(isEnabled = true))
            } else {
                alarmManager.cancelTimeBasedAutoRun(autoRunId)
            }
        } catch (e: Exception) {
            _errorState.value = "활성화 변경 실패: ${e.message}"
        }
    }
}
```

**개선 효과**:
- ✅ `currentAutoRun.copy(isEnabled = true)`로 최신 상태 전달

#### 2. AutoRunSettingsRepositoryImpl 구현

**파일**: `app/src/main/java/com/allday/detoxy/data/repository/AutoRunSettingsRepositoryImpl.kt` (108줄)

**구조**:
```kotlin
@Singleton
class AutoRunSettingsRepositoryImpl @Inject constructor(
    @ApplicationContext private val context: Context
) : AutoRunSettingsRepository {
    
    private val Context.dataStore by preferencesDataStore(name = "auto_run_settings")
    
    override val excludeWeekendsFlow: Flow<Boolean> = 
        dataStore.data.map { it[KEY_EXCLUDE_WEEKENDS] ?: false }
    
    override suspend fun saveExcludeWeekends(exclude: Boolean) {
        dataStore.edit { it[KEY_EXCLUDE_WEEKENDS] = exclude }
    }
    // ... 나머지 메서드 구현
}
```

**특징**:
