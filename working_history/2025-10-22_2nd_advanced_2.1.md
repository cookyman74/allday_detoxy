## 🔍 기술적 하이라이트

### 1. GPS 정확도 로깅 (위치 기반)
```kotlin
// AutoRunLog 엔티티
val gpsAccuracyMeters: Float? = null  // GPS 정확도 (미터)
val dwellSeconds: Int? = null         // 실제 체류 시간 (초)
```

**활용**:
- UI에서 "높음(< 20m)", "보통(20~50m)", "낮음(> 50m)" 표시
- 위치별 성공률 분석 시 정확도가 낮은 경우 필터링
- 체류 시간과 설정값(`dwellTimeMinutes`) 비교하여 정확도 검증

### 2. Foreign Key 전략

**AutoRunLog → FocusSession (FK)**:
```sql
FOREIGN KEY(sessionId) REFERENCES focus_sessions(id) ON DELETE SET NULL
```
- 세션 삭제 시 로그는 유지 (sessionId만 NULL)
- 통계 분석을 위해 이력 보존

**AutoRunLog → TimeBasedAutoRun/LocationBasedAutoRun (soft reference)**:
```kotlin
val triggerSourceId: String  // FK 없음
```
- 원본 자동 실행 삭제 시에도 로그 유지
- 통계 분석 (삭제된 자동 실행 포함)

### 3. 확장성 고려

**metaJson 필드** (AutoRunLog):
```kotlin
val metaJson: String? = null  // JSON 형식
```
- 향후 확장 가능한 유연한 필드
- 예: `{"battery": 85, "network": "WIFI", "playServicesVersion": "21.0.0"}`

**enabledDays JSON** (TimeBasedAutoRun):
```kotlin
val enabledDays: String  // JSON 배열
```
- 요일별 활성화: `["MON", "TUE", "WED", "THU", "FRI"]`
- 단순화 vs 정규화 트레이드오프 (단순화 선택)
