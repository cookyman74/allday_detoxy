### 1. DetoxyControlSettingsScreen 구현
**파일**: `app/src/main/java/com/allday/detoxy/presentation/ui/settings/focus/DetoxyControlSettingsScreen.kt`

#### 주요 기능
- 디톡시 프리셋 선택 (완전 차단/표준 디톡시/느슨함)
- 카테고리별 앱 차단 설정 토글
- 권한 상태 카드 표시 및 설정 안내
- 메신저 카테고리 안내 다이얼로그
- 디톡시 루틴 활성화 토글

#### UI 구성 요소
```kotlin
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun DetoxyControlSettingsScreen(
    onBack: () -> Unit = {},
    viewModel: FocusSettingsViewModel = hiltViewModel()
) {
    // 1. 프리셋 선택 섹션
    PresetSelectionSection(
        selectedPreset = selectedPreset,
        onPresetSelected = { preset -> viewModel.applyPreset(preset) }
    )

    // 2. 카테고리별 앱 차단 토글 섹션
    CategoryTogglesSection(
        enabledCategories = uiState.enabledCategories,
        otherAppsEnabled = uiState.otherAppsEnabled,
        onToggleCategory = viewModel::toggleCategory,
        onToggleOtherApps = viewModel::toggleOtherApps,
        onShowMessengerDialog = { showMessengerDialog = true }
    )

    // 3. 권한 상태 표시 섹션
    PermissionStatusSection(
        dndPermissionState = uiState.dndPermissionState,
        accessibilityEnabled = uiState.accessibilityEnabled,
        overlayEnabled = uiState.overlayEnabled
    )

    // 4. 디톡시 루틴 토글
    DetoxyRoutineSection(
        routineEnabled = uiState.routineEnabled,
        onToggle = viewModel::toggleRoutine
    )
}
```

## 🔧 해결된 이슈

### 1. Theme 이름 불일치
- **문제**: `AlldayDetoxyTheme` 참조 오류
- **해결**: `DetoxyTheme`로 수정 (실제 테마 파일 확인)

### 2. 누락된 의존성
- **문제**: `collectAsStateWithLifecycle` 참조 오류
- **해결**: `androidx-lifecycle-runtime-compose` 의존성 추가

### 3. DataStore 의존성
- **문제**: DataStore 관련 import 오류
- **해결**: `androidx-datastore-preferences` 의존성 추가

### 4. ExperimentalMaterial3Api 경고
- **문제**: Material3 실험적 API 사용 경고
- **해결**: `@OptIn(ExperimentalMaterial3Api::class)` 어노테이션 추가

```kotlin
// DND 권한 상태
enum class DndPermissionState {
    GRANTED,      // 권한 허용됨
    DENIED,       // 권한 거부됨
    RESTRICTED    // 시스템 제한
}

// 권한 체크 및 업데이트
fun updatePermissionStates() {
    val context = getApplication<Application>()
    _uiState.update { state ->
        state.copy(
            dndPermissionState = dndManager.getPermissionState(),
            accessibilityEnabled = PermissionUtils.isAccessibilityServiceEnabled(context),
            overlayEnabled = Settings.canDrawOverlays(context)
        )
    }
}
```
