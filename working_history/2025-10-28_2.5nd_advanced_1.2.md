        "RELAXED" -> "완화 모드"

    }
}

### 3.2 클래스 구조

#### 3.2.1 의존성
```kotlin
@HiltViewModel
class AutoRunDashboardViewModel @Inject constructor(
    private val nextAutoRunCalculator: NextAutoRunCalculator,
    private val timeBasedAutoRunRepository: TimeBasedAutoRunRepository,
    private val autoRunSettingsRepository: AutoRunSettingsRepository,
    private val userSettingsRepository: UserSettingsRepository,
    private val analyticsHelper: AnalyticsHelper
) : ViewModel()
```

#### 3.2.2 StateFlow 목록

**다음 예정 자동 실행**
- `nextAutoRunInfo: StateFlow<NextAutoRunInfo?>` - 다음 예정 자동 실행 정보
- `isLoading: StateFlow<Boolean>` - 로딩 상태
- `errorState: StateFlow<String?>` - 에러 메시지

**자동 실행 제어 상태**
- `masterEnabled: StateFlow<Boolean>` - 마스터 스위치 상태
- `pauseUntil: StateFlow<Long?>` - 일시중지 해제 시각

**글로벌 옵션**
- `excludeWeekends: StateFlow<Boolean>` - 주말 제외 설정

### 3.3 주요 메서드

#### 3.3.1 refreshNextAutoRun()
다음 자동 실행 정보 새로고침

**구현 로직**:
1. `isLoading = true` 설정
2. `timeBasedAutoRunRepository.getEnabled()` 조회
3. `nextAutoRunCalculator.calculateNextAutoRun()` 호출
4. `_nextAutoRunInfo.value` 업데이트
5. Analytics 이벤트 (필요시 추가 가능)
6. 에러 처리 및 `isLoading = false`

**특징**:
- Flow를 collect하여 실시간 업데이트
- 자동 실행 설정 변경 시 자동으로 재계산

#### 3.3.2 skipNextAutoRun()
이 회차 건너뛰기

**구현 로직**:
1. `nextAutoRunInfo` null 체크
2. 다음 트리거 시각 + 1분까지 일시중지 설정
3. `userSettingsRepository.setAutoRunPauseUntil(pauseUntil)` 호출
4. `analyticsHelper.logAutoRunSkipped()` 호출
5. `refreshNextAutoRun()` 호출하여 다음 자동 실행 재계산

**특징**:
- 트리거 시각 + 1분으로 설정하여 해당 회차만 건너뜀
- 건너뛴 후 자동으로 다음 예정 계산

#### 3.3.3 setMasterEnabled(enabled: Boolean)
마스터 스위치 토글

**구현 로직**:
1. `userSettingsRepository.setAutoRunMasterEnabled(enabled)` 호출
2. `_masterEnabled.value` 업데이트
3. `refreshNextAutoRun()` 호출

#### 3.3.4 setPauseUntil(pauseUntil: Long?)
일시중지 설정

**구현 로직**:
1. `userSettingsRepository.setAutoRunPauseUntil(pauseUntil)` 호출
2. `_pauseUntil.value` 업데이트
3. `refreshNextAutoRun()` 호출

**사용 시나리오**:
- "오늘 하루 중지": `pauseUntil = 오늘 자정`
- "N시간 동안 중지": `pauseUntil = 현재 + N시간`
- "즉시 해제": `pauseUntil = null`

### 3.4 Analytics 통합

#### logAutoRunSkipped()
- triggerType: "TIME" 또는 "LOCATION"
- reason: "manual_dashboard_skip"

## 7. 기술적 학습 내용

### 7.1 Jetpack Compose Material Icons
- Icons.Default.*에 있는 아이콘만 사용 가능
- Icons.Filled.*는 별도 의존성 필요할 수 있음

### 7.2 AnalyticsHelper 패턴
- private logEvent() 메서드 + public 특정 이벤트 메서드
- Bundle을 사용한 파라미터 전달
- 타입 안전성을 위해 각 이벤트별 전용 메서드 제공

### 7.3 Flow.collect()와 ViewModel 생명주기
- viewModelScope.launch로 coroutine 시작
- Flow.collect()는 무한 루프 (flow가 끝날 때까지)
- ViewModel이 clear될 때 자동으로 취소됨
