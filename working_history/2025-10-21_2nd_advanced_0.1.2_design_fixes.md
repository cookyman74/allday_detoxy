# 2차 고도화 설계 불일치 수정 (리뷰 반영)

**작업 일자**: 2025-10-21  
**작업자**: AI Assistant  
**브랜치**: feat/v0.8  
**관련 문서**: PRD, Room 마이그레이션 전략, Analytics 스키마, 작업 계획서

---

## 1. 작업 배경

최종 리뷰 결과, 2차 고도화 문서 세트가 전반적으로 일관성이 확보되었으나, **서비스 구현 단계에서 실제로 문제가 될 수 있는 두 가지 설계 불일치**가 발견되었습니다:

1. **AutoRun 일시중지 설계 불일치**: 
   - PRD/Wireframe에는 "특정 시간대 반복 일시중지" 기능이 정의됨
   - 그러나 Room 스키마에는 `autoRunPauseUntil` (단일 timestamp)만 존재
   - 반복 시간대를 저장할 수 없는 구조적 문제

2. **위치 성공률·GPS 정확도 로그 부족**:
   - UI/PRD에서는 GPS 정확도, 성공률, 상세 실패 사유 표시 요구
   - `auto_run_log` 테이블에 이런 상세 정보를 담을 필드가 없음
   - 데이터 기반 분석 및 UI 표시 불가능

이 두 가지 문제를 즉시 해결하기 위해 설계를 수정합니다.

---

## 2. 해결 방안

### 2.1 AutoRun 일시중지 설계

**결정**: **2차 범위 축소 + 3차로 미루기** (안전한 접근)

#### 2.1.1 2차 고도화 범위 (v0.6) ✅
- **단일 timestamp 기반 일시중지**:
  - "오늘 하루 중지" (자정까지)
  - "N시간 동안 중지" (1h/3h/6h)
  - "다음 자동 실행까지 중지"
- **구현**: `UserSettings.autoRunPauseUntil` (단일 timestamp)
- **저전력 모드 감지**: 자동으로 위치 기반 자동 실행 일시중지

#### 2.1.2 3차 고도화로 연기 ⚠️
- **반복 시간대 일시중지**:
  - "야간 시간 (22:00~07:00) 자동 실행 중지"
  - 사용자 지정 시간대 설정 (최대 3개)
- **이유**: `AutoRunPauseWindow` 별도 테이블 필요, 복잡도 증가
- **캘린더 연동**: 시스템 캘린더 "바쁨" 일정 확인

### 2.2 GPS 정확도 로그 설계

**결정**: **`auto_run_log` 테이블 확장** (데이터 기반 분석 가능)

#### 2.2.1 추가 필드
```kotlin
data class AutoRunLog(
    // ... 기존 필드 ...
    // 🆕 위치 기반 상세 정보 (triggerType == LOCATION일 때)
    val gpsAccuracyMeters: Float? = null,  // GPS 정확도 (미터)
    val dwellSeconds: Int? = null,         // 실제 체류 시간 (초)
    val metaJson: String? = null           // 추가 메타데이터 (JSON)
)
```

#### 2.2.2 활용 방안
- **UI 표시**:
  - "GPS 정확도: 높음(< 20m), 보통(20~50m), 낮음(> 50m)"
  - 위치별 성공률 분석
  - 실패 사유 상세 표시
- **Analytics**:
  - `auto_run_started`, `auto_run_failed` 이벤트에 GPS 정확도 파라미터 추가
  - 위치 정확도와 성공률 상관관계 분석
  - 위치 설정 개선 제안 (반경 확대) 근거

- **수정 위치**: §2.4 AutoRunLog
- **추가 필드**:
  - `gpsAccuracyMeters: Float?`
  - `dwellSeconds: Int?`
  - `metaJson: String?`
- **SQL 수정**:
  ```sql
  CREATE TABLE IF NOT EXISTS auto_run_log (
      -- ... 기존 필드 ...
      gpsAccuracyMeters REAL,
      dwellSeconds INTEGER,
      metaJson TEXT,
      -- ...
  );
  ```
- **비즈니스 로직 추가**:
  - GPS 정확도 활용 방안 (UI 표시, 성공률 분석)
