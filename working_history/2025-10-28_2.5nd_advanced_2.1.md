### 2.2 데이터 클래스 구조

#### 2.2.1 AutoRunStatistics
```kotlin
data class AutoRunStatistics(
    val weeklyTimeBasedCount: Int,
    val weeklyLocationBasedCount: Int,
    val successRate: Float, // 0.0 ~ 1.0
    val totalFocusTimeMinutes: Int,
    val weeklyTrend: List<DailyStats>
)
```

**주요 필드**:
- `weeklyTimeBasedCount`: 이번 주 시간 기반 자동 실행 횟수
- `weeklyLocationBasedCount`: 이번 주 위치 기반 자동 실행 횟수
- `successRate`: 자동 실행 성공률 (0.0 ~ 1.0)
- `totalFocusTimeMinutes`: 자동 실행으로 얻은 총 집중 시간 (분)
- `weeklyTrend`: 주간 트렌드 데이터 (최근 7일)

#### 2.2.2 DailyStats
```kotlin
data class DailyStats(
    val date: String, // YYYY-MM-DD
    val timeBasedCount: Int,
    val locationBasedCount: Int,
    val successCount: Int,
    val totalCount: Int
)
```

**주요 필드**:
- `date`: 날짜 (YYYY-MM-DD 형식)
- `timeBasedCount`: 시간 기반 자동 실행 횟수
- `locationBasedCount`: 위치 기반 자동 실행 횟수
- `successCount`: 성공 횟수
- `totalCount`: 전체 자동 실행 횟수

            _statisticsLoading.value = true

            val newStatistics = autoRunStatisticsCalculator.calculateStatistics()
            _statistics.value = newStatistics

## 8. 설계 결정사항

### 8.1 통계 계산 로직

#### 8.1.1 이번 주 범위
- 일요일 00:00:00부터 현재 시각까지
- Calendar.DAY_OF_WEEK를 사용하여 일요일 계산

#### 8.1.2 성공률 계산
- `result == "STARTED"` 인 로그의 비율
- 로그가 없을 경우 0.0 반환

#### 8.1.3 총 집중 시간 계산
- AutoRunLog의 sessionId를 통해 FocusSession 조회
- `(endTime - startTime) / 60000`으로 실제 집중 시간 계산
- endTime이 null이면 0으로 처리 (진행 중 세션)

#### 8.1.4 주간 트렌드 생성
- 최근 7일간 데이터 생성 (가장 오래된 날부터 오늘까지)
- SimpleDateFormat("yyyy-MM-dd")로 날짜 포맷
- 날짜별로 로그 그룹핑하여 일별 통계 생성

### 8.2 UI 디자인

#### 8.2.1 색상 사용
- **시간 기반**: MaterialTheme.colorScheme.primary (파란색)
- **위치 기반**: MaterialTheme.colorScheme.secondary (보라색)
- **배경**: MaterialTheme.colorScheme.surface
- **텍스트**: MaterialTheme.colorScheme.onSurfaceVariant

#### 8.2.2 원형 그래프
- strokeWidth: 8.dp
- startAngle: -90f (12시 방향부터 시작)
- StrokeCap.Round로 부드러운 끝 처리

#### 8.2.3 막대 그래프
- 7개 막대 (7일)
- 각 막대는 2개로 분리 (시간 기반 + 위치 기반)
- barWidth = chartWidth / (weeklyTrend.size * 2)

### 8.3 ViewModel 설계

#### 8.3.1 StateFlow 패턴

- StateFlow를 public으로 노출 (읽기 전용)

## 9. 기술적 학습 내용

### 9.1 Suspend 함수와 Flow
- Flow는 실시간 업데이트에 적합
- Suspend 함수는 일회성 데이터 조회에 적합
- 통계 계산은 일회성이므로 suspend 함수 사용

### 9.2 Canvas 그래프 그리기
- drawCircle: 배경 원 그리기
- drawArc: 성공률 원호 그리기
- drawRect: 막대 그래프 그리기

### 9.3 SimpleDateFormat 사용
- "yyyy-MM-dd" 형식으로 날짜 포맷
- Locale.getDefault()로 로컬 설정 사용

### 9.4 DAO 메서드 설계
- Flow: 실시간 업데이트가 필요한 경우
- suspend List: 일회성 데이터 조회가 필요한 경우
- 통계 계산은 일회성이므로 suspend List 사용

### 14.6 Clean Architecture 레이어 구조 (최종)

```
┌─────────────────────────────────────────┐
│         Presentation Layer              │
│  (AutoRunDashboardViewModel)            │
└──────────────┬──────────────────────────┘
               │ depends on
               ↓
┌─────────────────────────────────────────┐
│          Domain Layer                   │
│  - AutoRunStatisticsCalculator          │
│  - IAutoRunLogRepository (interface)    │
│  - IFocusSessionRepository (interface)  │
└──────────────┬──────────────────────────┘
               │ implemented by
               ↓
┌─────────────────────────────────────────┐
│           Data Layer                    │
│  - AutoRunLogRepository (impl)          │
│  - FocusSessionRepository (impl)        │
│  - AutoRunLogDao                        │
│  - FocusSessionDao                      │
└─────────────────────────────────────────┘
```

**핵심 원칙**:
- domain 레이어는 data 레이어를 **알지 못함**
- data 레이어가 domain 레이어의 인터페이스를 **구현**
- 의존성 방향: Presentation → Domain ← Data (implements)
