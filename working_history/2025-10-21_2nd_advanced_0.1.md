### 2.2 02_advanced_room_migration_strategy.md (966줄)

**파일 경로**: `docs/02_advanced_room_migration_strategy.md`

**작성 내용**:
1. **마이그레이션 개요**:
   - Database v3 → v4
   - 신규 엔티티 4개, 기존 엔티티 확장 1개
   - 인덱스 5개, 기본 데이터 삽입 (프리셋 3개)

2. **신규 엔티티 상세 (4개)**:
   - **TimeBasedAutoRun**: 시간 기반 자동 실행 설정 (최대 10개)
     - 필드: hour, minute, durationMinutes, presetType, enabledDays(JSON), label, isEnabled, createdAt
     - 인덱스: (hour, minute), (isEnabled)
   - **LocationBasedAutoRun**: 위치 기반 자동 실행 설정 (최대 5개)
     - 필드: label, address, lat/lng, radiusMeters, durationMinutes, presetType, triggerType, dwellTimeMinutes 🆕, requiresUserConfirmation 🆕
     - 인덱스: (isEnabled)
   - **CustomTimerPreset**: 커스텀 타이머 프리셋 (최대 10개)
     - 필드: name, durationMinutes, presetType, usageCount, displayOrder, createdAt
     - 인덱스: (displayOrder)
   - **AutoRunLog**: 자동 실행 이력 로그
     - 필드: triggerType, triggerSourceId, triggerTime, result, failureReason, sessionId(FK)
     - 인덱스: (triggerTime DESC)

3. **기존 엔티티 확장**:
   - **UserSettings**: 2개 필드 추가
     - `autoRunPauseUntil`: 일시중지 종료 시간 (nullable)
     - `autoRunMasterEnabled`: 마스터 토글 (default: true)

4. **Migration_3_4 구현**:
   - CREATE TABLE 4개
   - CREATE INDEX 5개
   - ALTER TABLE user_settings (2개 필드)
   - INSERT 기본 프리셋 3개 (25분, 45분, 60분)

5. **DAO 인터페이스 스펙 (4개, 40개 메서드)**:
   - TimeBasedAutoRunDao (10개 메서드)
   - LocationBasedAutoRunDao (10개 메서드)
   - CustomTimerPresetDao (12개 메서드)
   - AutoRunLogDao (8개 메서드)

6. **테스트 전략**:
   - 마이그레이션 테스트 (MigrationTest_3_4)
   - DAO 단위 테스트
   - 통합 테스트 (Repository-DAO)

7. **성능 최적화**:
   - 인덱스 전략 (5개)
   - 데이터 정리 정책 (AutoRunLog 90일 자동 삭제)

8. **백업 및 복원**:
   - 백업 대상: TimeBasedAutoRun, LocationBasedAutoRun, CustomTimerPreset (사용자 생성), UserSettings
   - 백업 제외: AutoRunLog (재생성 가능)

9. **롤백 전략**:
   - 마이그레이션 실패 시 자동 처리
   - v3 DB 백업 유지
   - 데이터 손실 방지

**참조 링크**:
- [2차 고도화 PRD §5.1](../docs/02_advanced_autosetting_prd.md#51-로컬-db-room-v3v4)
- [1차 고도화 마이그레이션](../docs/01_advanced_room_migration_strategy.md)

### 2.3 02_advanced_analytics_schema.md (1,087줄)

**파일 경로**: `docs/02_advanced_analytics_schema.md`

**작성 내용**:
1. **로깅 원칙**:
   - 명명 규칙: `snake_case`
   - 개인정보 보호: 위치 라벨만 해시 처리, 좌표/주소 수집 안 함
   - 데이터 보존: Firebase Analytics 14개월

2. **신규 이벤트 21개**:
   - **자동 실행 설정 (8개)**:
     - `auto_run_time_created` (템플릿 여부, 요일 수)
     - `auto_run_time_edited`, `auto_run_time_toggled`, `auto_run_time_deleted`
     - `auto_run_location_created` (라벨 해시, 반경, 체류 시간 🆕, 도착 후 확인 🆕)
     - `auto_run_location_edited`, `auto_run_location_toggled`, `auto_run_location_deleted` (성공률)
   - **자동 실행 트리거 (6개)**:
     - `auto_run_triggered` (트리거 타입, 소스 ID 해시)
     - `auto_run_notification_shown` (사전 알림 여부)
     - `auto_run_notification_action` (START/SNOOZE/SKIP, 응답 시간)
     - `auto_run_started` (자동/수동 시작, 지연 시간)
     - `auto_run_skipped` (건너뜀 이유)
     - `auto_run_failed` (실패 사유)
   - **커스텀 타이머 (5개)**:
     - `custom_timer_adjusted` (DRAG/TAP, 커스텀 시간 여부)
     - `custom_preset_created` (이름, 시간, 총 개수)
     - `custom_preset_used` (사용 횟수)
     - `custom_preset_edited`, `custom_preset_deleted`
   - **권한 (2개)**:
     - `permission_exact_alarm_requested` (승인 여부, WorkManager fallback)
     - `permission_background_location_requested` (권한 레벨: ALWAYS/WHILE_IN_USE/DENIED)

3. **주요 KPI 및 지표 (4개)**:
   - 자동 실행 전환율: ≥ 40% (DAU 대비)
   - 자동 실행 성공률: ≥ 60% (started / (started + skipped + failed))
   - 커스텀 타이머 사용률: ≥ 50% (타이머 화면 진입자 대비)
   - 위치 권한 승인율: ≥ 50% (백그라운드 위치 "항상 허용")

4. **AnalyticsHelper 클래스 확장**:
   - 21개 메서드 추가 (총 40개)
   - 파라미터 타입: String, Int, Boolean
   - 해시 함수 사용 (위치 라벨, 소스 ID)

5. **개인정보 보호 준수**:
   - Google Play 정책: "대략적 위치" 선언
   - GDPR 준수: 데이터 최소화, 익명화, 사용자 동의, 삭제 권리
   - 한국 개인정보보호법: 위치정보법 준수, 명시적 동의

6. **테스트 및 검증**:
   - 로깅 테스트 체크리스트
   - Firebase Console 이벤트 수신 확인 (24시간 이내)
   - BigQuery 연동 (선택)
