## 구현된 기능 요약

### 1. 데이터 모델

```kotlin
// ScheduleGroup (v8+)
data class ScheduleGroup(
    // ... 기존 필드 ...
    val manualOverrideState: String? = null,  // null/INACTIVE/PAUSED
    val pauseUntil: Long? = null              // 일시중지 해제 시각
)
```

### 2. 상태 관리

```kotlin
enum class ScheduleGroupControlState {
    ACTIVE,    // 정상 작동
    PAUSED,    // 일시중지 (알람만 건너뛰기)
    INACTIVE;  // 완전 비활성화
    
    companion object {
        fun fromEntity(manualOverrideState: String?, pauseUntil: Long?): ScheduleGroupControlState
    }
}
```

### 3. UI 컴포넌트

```kotlin
@Composable
fun ScheduleControlButton(
    controlState: ScheduleGroupControlState,
    pauseUntil: Long?,
    onStateChange: (ScheduleGroupControlState) -> Unit,
    onPause: (PauseDuration) -> Unit,
    modifier: Modifier = Modifier
)
```

**동작 방식**:
- **탭**: ACTIVE ↔ INACTIVE 전환, PAUSED → ACTIVE
- **롱프레스**: 드롭다운 메뉴 표시
- **드롭다운**: 활성/비활성/일시중지 옵션

### 4. 우선순위 계층

```
레벨 1: 마스터 스위치 (UserSettings.isAutoRunEnabled)
   ↓
레벨 2: 수동 제어 (manualOverrideState) ← v8 신규
   ↓
레벨 3: 자동 제어 (isActive)
   ↓
레벨 4: 개별 시간대 (TimeBasedAutoRun.isEnabled)
```

| 항목 | 변경 전 | 변경 후 |
