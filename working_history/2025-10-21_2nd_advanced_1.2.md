## 2. AlarmManager vs WorkManager 비교 및 선택

### 2.1 기술 개요

#### 2.1.1 AlarmManager
- **목적**: 정확한 시간에 작업 실행 (시스템 시계 기반)
- **API Level**: API 1부터 사용 가능
- **특징**:
  - 기기가 절전 모드(Doze)에 있어도 실행 가능
  - 앱이 종료되어 있어도 작동
  - 시스템 재부팅 후에도 재등록 가능 (BOOT_COMPLETED)

#### 2.1.2 WorkManager
- **목적**: 지연 가능한(deferrable) 백그라운드 작업
- **API Level**: AndroidX 라이브러리 (Android 4.0+)
- **특징**:
  - 제약 조건 기반 실행 (네트워크, 배터리 등)
  - 자동 재시도 및 백오프 정책
  - 작업 체이닝 및 병렬 실행 지원

### 2.2 비교 분석

| 항목 | AlarmManager | WorkManager |
|------|-------------|-------------|
| **정확도** | 정확 (±수초) | 불정확 (±15분) |
| **배터리** | 높음 | 최적화됨 |
| **Doze 모드** | `setExactAndAllowWhileIdle()` 필요 | 자동 처리 |
| **재시도** | 수동 구현 | 자동 지원 |
| **권한 (Android 12+)** | SCHEDULE_EXACT_ALARM 필요 | 불필요 |
| **사용 사례** | 알람, 타이머, 정확한 스케줄 | 데이터 동기화, 업로드 |

### 2.3 2차 고도화 선택: **AlarmManager (Primary) + WorkManager (Fallback)**

#### 2.3.1 선택 이유
1. **정확도 우선**: 시간 기반 자동 실행은 사용자가 설정한 정확한 시간에 실행되어야 함
2. **사용자 경험**: "10:00 AM에 시작"이라고 설정했는데 10:15 AM에 실행되면 신뢰도 저하
3. **권한 대응**: Android 12+ 에서 정확 알람 권한이 거부되면 WorkManager로 fallback

#### 2.3.2 구현 전략
```kotlin
class AutoRunAlarmManager @Inject constructor(
    private val context: Context,
    private val alarmManager: AlarmManager,
    private val workManager: WorkManager
) {
    fun scheduleTimeBasedAutoRun(autoRun: TimeBasedAutoRun) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            // Android 12+: 정확 알람 권한 체크
            if (alarmManager.canScheduleExactAlarms()) {
                scheduleWithAlarmManager(autoRun)
            } else {
                // Fallback: WorkManager
                scheduleWithWorkManager(autoRun)
                showPermissionGuidanceBanner()
            }
        } else {
            // Android 11 이하: AlarmManager 직접 사용
            scheduleWithAlarmManager(autoRun)
        }
    }
    
    private fun scheduleWithAlarmManager(autoRun: TimeBasedAutoRun) {
        val triggerTime = calculateNextTriggerTime(autoRun)
        val pendingIntent = createPendingIntent(autoRun.id)
        
        alarmManager.setExactAndAllowWhileIdle(
            AlarmManager.RTC_WAKEUP,
            triggerTime,
            pendingIntent
        )
    }
    
    private fun scheduleWithWorkManager(autoRun: TimeBasedAutoRun) {
        val delay = calculateDelayFromNow(autoRun)
        val request = OneTimeWorkRequestBuilder<AutoRunWorker>()
            .setInitialDelay(delay, TimeUnit.MILLISECONDS)
            .setInputData(
                workDataOf("autoRunId" to autoRun.id)
            )
            .build()
        
        workManager.enqueue(request)
    }
}
```

#### 2.3.3 주의사항
1. **Doze 모드 대응**:
   - `setExactAndAllowWhileIdle()` 사용 (Doze 중에도 실행)
   - `setExact()` 대신 사용 (Doze에서 지연될 수 있음)

2. **Android 12+ 권한 요청**:
   ```kotlin
   if (!alarmManager.canScheduleExactAlarms()) {
       val intent = Intent(Settings.ACTION_REQUEST_SCHEDULE_EXACT_ALARM)
       context.startActivity(intent)
   }
   ```

3. **PendingIntent 플래그** (Android 12+):
   ```kotlin
   val flags = PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT
   ```

4. **재부팅 시 재등록**:
   ```kotlin
   class BootCompletedReceiver : BroadcastReceiver() {
       override fun onReceive(context: Context, intent: Intent) {
           if (intent.action == Intent.ACTION_BOOT_COMPLETED) {
               // DB에서 활성화된 자동 실행 가져와서 재등록
           }
       }
   }
   ```
   - Manifest에 `RECEIVE_BOOT_COMPLETED` 권한 추가 필요

## 3. Geofencing API 학습

### 3.1 기술 개요

#### 3.1.1 Geofencing이란?
- 지리적 경계(Geofence)를 설정하고, 사용자가 해당 경계에 진입/이탈할 때 이벤트를 감지하는 기술
- Google Play Services Location API의 일부

#### 3.1.2 주요 개념
1. **Geofence**: 위도, 경도, 반경으로 정의된 원형 영역
2. **Transition**: 진입(ENTER), 이탈(EXIT), 체류(DWELL)
3. **Loitering Delay**: 체류로 간주되기까지의 대기 시간
4. **Expiration**: Geofence 유효 기간 (기본: `NEVER_EXPIRE`)

### 3.2 구현 방법

#### 3.2.1 Geofence 생성
```kotlin
fun createGeofence(location: LocationBasedAutoRun): Geofence {
    return Geofence.Builder()
        .setRequestId(location.id) // 고유 ID
        .setCircularRegion(
            location.latitude,
            location.longitude,
            location.radiusMeters.toFloat()
        )
        .setExpirationDuration(Geofence.NEVER_EXPIRE)
        .setTransitionTypes(Geofence.GEOFENCE_TRANSITION_ENTER)
        .setLoiteringDelay(0) // 즉시 트리거
        .build()
}
```

#### 3.2.2 GeofencingRequest 생성
```kotlin
fun createGeofencingRequest(geofences: List<Geofence>): GeofencingRequest {
    return GeofencingRequest.Builder()
        .setInitialTrigger(GeofencingRequest.INITIAL_TRIGGER_ENTER)
        .addGeofences(geofences)
        .build()
}
```

#### 3.2.3 Geofence 등록
```kotlin
suspend fun addGeofence(location: LocationBasedAutoRun): Result<Unit> {
    return suspendCancellableCoroutine { continuation ->
        val geofence = createGeofence(location)
        val request = createGeofencingRequest(listOf(geofence))
        val pendingIntent = createGeofencePendingIntent()
        
        geofencingClient.addGeofences(request, pendingIntent)
            .addOnSuccessListener {
                continuation.resume(Result.success(Unit))
            }
            .addOnFailureListener { exception ->
                val error = when (exception) {
                    is SecurityException -> "위치 권한 없음"
                    is ApiException -> {
                        when (exception.statusCode) {
                            GeofenceStatusCodes.GEOFENCE_TOO_MANY_GEOFENCES -> 
                                "최대 Geofence 개수 초과"
                            GeofenceStatusCodes.GEOFENCE_NOT_AVAILABLE -> 
                                "Geofence 사용 불가 (위치 서비스 OFF)"
                            else -> "Geofence 등록 실패: ${exception.message}"
                        }
                    }
                    else -> "알 수 없는 오류"
                }
                continuation.resume(Result.failure(Exception(error)))
            }
    }
}
```

#### 3.2.4 Geofence 트리거 처리
```kotlin
class GeofenceTransitionsReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val geofencingEvent = GeofencingEvent.fromIntent(intent) ?: return
        
        if (geofencingEvent.hasError()) {
            val errorCode = geofencingEvent.errorCode
            Log.e(TAG, "Geofence error: $errorCode")
            return
        }
        
        val transition = geofencingEvent.geofenceTransition
        if (transition == Geofence.GEOFENCE_TRANSITION_ENTER) {
            val triggeringGeofences = geofencingEvent.triggeringGeofences ?: return
            val location = geofencingEvent.triggeringLocation
            
            triggeringGeofences.forEach { geofence ->
                val locationId = geofence.requestId
                val gpsAccuracy = location?.accuracy ?: 0f
                
                // AutoRunLog 기록 (GPS 정확도 포함)
                logAutoRunTrigger(
                    locationId = locationId,
                    gpsAccuracyMeters = gpsAccuracy,
                    dwellSeconds = 0
                )
                
                // 알림 표시 또는 자동 시작
                triggerLocationBasedAutoRun(locationId)
            }
        }
    }
}
```

### 3.3 제약 사항 및 대응

#### 3.3.1 최대 등록 개수
- **시스템 제한**: 100개 (앱당)
- **2차 고도화 제한**: 5개 (배터리 효율 고려)
- **대응**: UI에서 5개 초과 시 경고 메시지

#### 3.3.2 배터리 효율성
- **전략**: `PRIORITY_BALANCED_POWER_ACCURACY` 사용
  ```kotlin
  LocationRequest.Builder(Priority.PRIORITY_BALANCED_POWER_ACCURACY, 10000)
      .setMinUpdateIntervalMillis(5000)
      .build()
  ```
- **예상 배터리 소모**: 위치 기반 자동 실행 2개 활성화 시 일일 3~5%
- **최적화**: 사용자가 비활성화한 위치는 즉시 Geofence 해제

#### 3.3.3 Google Play Services 의존성
- **필수**: Google Play Services 설치 필요
- **대응**:
  ```kotlin
  fun isPlayServicesAvailable(): Boolean {
      val availability = GoogleApiAvailability.getInstance()
      val result = availability.isGooglePlayServicesAvailable(context)
      return result == ConnectionResult.SUCCESS
  }
  ```
- **Huawei 기기 대응**: HMS(Huawei Mobile Services) 대신 "위치 기반 기능 사용 불가" 안내

#### 3.3.4 위치 정확도
- GPS 정확도에 따라 트리거 신뢰도 달라짐
- **대응**:
  - AutoRunLog에 `gpsAccuracyMeters` 저장
  - 정확도 낮으면 (> 50m) 반경 확대 제안
  - `dwellTimeMinutes` 옵션으로 오차 보정 (1/3/5분 체류 후 트리거)

### 3.4 권한 요구사항
1. **ACCESS_FINE_LOCATION**: 필수
2. **ACCESS_BACKGROUND_LOCATION**: Android 10+ 필수
3. **AndroidManifest.xml**:
   ```xml
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
   <uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
   ```

## 4. 위치 권한 플로우

### 4.1 권한 종류 및 목적

#### 4.1.1 ACCESS_FINE_LOCATION
- **목적**: 정확한 위치 정보 획득 (GPS 기반)
- **필요성**: Geofence 등록에 필수
- **권한 레벨**: Dangerous (사용자 승인 필요)

#### 4.1.2 ACCESS_BACKGROUND_LOCATION (Android 10+)
- **목적**: 앱이 백그라운드에 있을 때 위치 정보 접근
- **필요성**: 사용자가 앱을 열지 않아도 Geofence 트리거 감지
- **권한 레벨**: Dangerous (별도 승인 필요)
- **제약**: Android 11+에서는 2단계 요청 필수

### 4.2 권한 요청 플로우 (Android 11+ 기준)

### 4.3 권한 상태 모니터링

#### 4.3.1 앱 포그라운드 진입 시 권한 재확인

#### 4.3.2 권한 변경 감지
```kotlin
class LocationBasedAutoRunViewModel @Inject constructor(
    private val context: Application,
    private val geofenceManager: AutoRunGeofenceManager
) : ViewModel() {
    
    fun checkLocationPermissions() {
        val hasFineLocation = ContextCompat.checkSelfPermission(
            context,
            Manifest.permission.ACCESS_FINE_LOCATION
        ) == PackageManager.PERMISSION_GRANTED
        
        val hasBackgroundLocation = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            ContextCompat.checkSelfPermission(
                context,
                Manifest.permission.ACCESS_BACKGROUND_LOCATION
            ) == PackageManager.PERMISSION_GRANTED
        } else {
            true // Android 9 이하는 FINE_LOCATION만 필요
        }
        
        val newState = when {
            !hasFineLocation -> LocationPermissionState.DENIED
            !hasBackgroundLocation -> LocationPermissionState.FOREGROUND_ONLY
            else -> LocationPermissionState.GRANTED
        }
        
        _permissionState.value = newState
        
        // 권한 해제 시 Geofence 자동 해제
        if (newState != LocationPermissionState.GRANTED) {
            viewModelScope.launch {
                geofenceManager.removeAllGeofences()
            }
        }
    }
}

enum class LocationPermissionState {
    DENIED,              // 위치 권한 없음
    FOREGROUND_ONLY,     // 포그라운드만 허용
    GRANTED              // 백그라운드 포함 허용
}
```

## 5. Compose Canvas 학습

### 5.1 기술 개요

#### 5.1.1 Canvas란?
- Jetpack Compose에서 커스텀 그래픽을 그리기 위한 저수준 API
- Android의 기존 Canvas API를 Compose에서 사용할 수 있도록 래핑

#### 5.1.2 주요 용도
- 커스텀 UI 컴포넌트 (차트, 그래프, 게이지 등)
- 애니메이션
- 복잡한 도형 및 경로 그리기

### 5.2 도넛 그래프 구현

#### 5.2.1 기본 구조
```kotlin
@Composable
fun DonutTimerPicker(
    selectedMinutes: Int,
    onMinutesChange: (Int) -> Unit,
    minMinutes: Int = 5,
    maxMinutes: Int = 180,
    modifier: Modifier = Modifier
) {
    var currentAngle by remember { mutableStateOf(minutesToAngle(selectedMinutes, maxMinutes)) }
    val animatedAngle by animateFloatAsState(
        targetValue = currentAngle,
        animationSpec = spring(
            dampingRatio = Spring.DampingRatioMediumBouncy,
            stiffness = Spring.StiffnessLow
        )
    )
    
    Box(
        modifier = modifier.size(300.dp),
        contentAlignment = Alignment.Center
    ) {
        Canvas(
            modifier = Modifier
                .fillMaxSize()
                .pointerInput(Unit) {
                    detectDragGestures { change, _ ->
                        val angle = calculateAngle(change.position, size)
                        val minutes = angleToMinutes(angle, minMinutes, maxMinutes, 5)
                        onMinutesChange(minutes)
                        currentAngle = minutesToAngle(minutes, maxMinutes)
                    }
                }
        ) {
            val strokeWidth = 40.dp.toPx()
            val radius = size.minDimension / 2 - strokeWidth / 2
            
            // 1. 배경 원 그리기
            drawCircle(
                color = Color.LightGray.copy(alpha = 0.3f),
                radius = radius,
                style = Stroke(width = strokeWidth)
            )
            
            // 2. 진행 호(Arc) 그리기
            drawArc(
                color = Color(0xFF4CAF50),
                startAngle = -90f,
                sweepAngle = animatedAngle,
                useCenter = false,
                topLeft = Offset(strokeWidth / 2, strokeWidth / 2),
                size = Size(size.width - strokeWidth, size.height - strokeWidth),
                style = Stroke(
                    width = strokeWidth,
                    cap = StrokeCap.Round
                )
            )
            
            // 3. 시간 눈금 그리기
            drawTimeMarkers(radius, strokeWidth)
            
            // 4. 드래그 핸들 그리기
```

#### 5.2.2 각도 ↔ 시간 변환
```kotlin
// 시간 → 각도 (0분 = 0°, 180분 = 360°)
private fun minutesToAngle(minutes: Int, maxMinutes: Int): Float {
    return (minutes.toFloat() / maxMinutes) * 360f
}

// 각도 → 시간
private fun angleToMinutes(angle: Float, minMinutes: Int, maxMinutes: Int, step: Int): Int {
    val minutes = ((angle / 360f) * maxMinutes).toInt()
    return minutes.coerceIn(minMinutes, maxMinutes).roundToNearestStep(step)
}

// N분 단위로 반올림 (5분 단위)
private fun Int.roundToNearestStep(step: Int): Int {
    return ((this + step / 2) / step) * step
}
```

#### 5.2.3 터치 위치 → 각도 계산
```kotlin
private fun calculateAngle(position: Offset, size: Size): Float {
    val centerX = size.width / 2
    val centerY = size.height / 2
    
    val dx = position.x - centerX
    val dy = position.y - centerY
    
    // atan2: -180° ~ 180° 범위 반환
    val radians = atan2(dy, dx)
    
    // 0° ~ 360° 범위로 변환, 12시 방향(위)을 0°로 조정
    var degrees = Math.toDegrees(radians.toDouble()).toFloat() + 90f
    if (degrees < 0) degrees += 360f
    
    return degrees
}
```

```kotlin
private fun DrawScope.drawTimeMarkers(radius: Float, strokeWidth: Float) {
    val markers = listOf(5, 15, 30, 60, 90, 120, 180) // 분
    val maxMinutes = 180f
    
    markers.forEach { minutes ->
        val angle = (minutes / maxMinutes) * 360f - 90f // -90°: 12시 방향 시작
        val angleRadians = Math.toRadians(angle.toDouble()).toFloat()
        
        // 외부 끝점
        val outerX = center.x + (radius + strokeWidth / 2) * cos(angleRadians)
        val outerY = center.y + (radius + strokeWidth / 2) * sin(angleRadians)
        
        // 내부 끝점
        val innerX = center.x + (radius - strokeWidth / 2) * cos(angleRadians)
        val innerY = center.y + (radius - strokeWidth / 2) * sin(angleRadians)
        
        // 눈금선 그리기
        drawLine(
            color = Color.White,
            start = Offset(innerX, innerY),
            end = Offset(outerX, outerY),
            strokeWidth = 4.dp.toPx(),
            cap = StrokeCap.Round
        )
        
        // 텍스트 위치 계산 (더 바깥쪽)
        val textRadius = radius + strokeWidth / 2 + 20.dp.toPx()
        val textX = center.x + textRadius * cos(angleRadians)
        val textY = center.y + textRadius * sin(angleRadians)
        
        // 텍스트 그리기 (drawText는 별도 구현 필요)
        // Compose에서는 Text 컴포넌트를 Box로 배치하는 방식 권장
    }
}
```

```kotlin
private fun DrawScope.drawDragHandle(angle: Float, radius: Float) {
    val angleRadians = Math.toRadians((angle - 90f).toDouble()).toFloat()
```
