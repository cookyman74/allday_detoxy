### 2. 트랜잭션 로직 개선

#### 2.1 addLocation() 트랜잭션 순서 변경

**이전 문제**:
```kotlin
// DB 저장 → Geofence 등록 (실패 시 불일치)
repository.insert(location)  // ✅ DB 저장 성공
geofenceManager.addGeofence(location)  // ❌ Geofence 실패
// → DB에는 있지만 Geofence는 없는 불일치 상태!
```

**개선 후**:
```kotlin
// 1. Geofence 등록 먼저 시도
if (location.isEnabled) {
    val result = geofenceManager.addGeofence(location)
    if (result.isFailure) {
        _errorState.value = LocationError.GeofenceError(...)
        return@launch  // 실패 시 DB 저장 안 함
    }
}

// 2. Geofence 성공 후 DB 저장
repository.insert(location)

// 3. DB 저장 실패 시 Geofence 롤백
catch (e: Exception) {
    if (location.isEnabled) {
        geofenceManager.removeGeofence(location.id)
    }
    _errorState.value = LocationError.DatabaseError(...)
}
```

**효과**:
- ✅ Geofence 등록 실패 시 DB 저장 안 함 → 불일치 방지
- ✅ DB 저장 실패 시 Geofence 자동 롤백 → 데이터 일관성 보장
- ✅ 사용자에게 실패 원인 명확히 전달

### 3. 권한 체크 타이밍 개선

**파일**: `LocationBasedAutoRunScreen.kt` (수정, +45줄)

#### 3.1 DisposableEffect로 onResume 권한 재확인

**이전 문제**:
- 권한 설정 화면에서 돌아올 때 권한 상태가 자동으로 갱신되지 않음
- 사용자가 설정에서 권한을 허용해도 UI가 업데이트되지 않음

**개선 후**:
```kotlin
// 화면 복귀 시 권한 재확인 (설정 화면에서 돌아올 때)
DisposableEffect(lifecycleOwner) {
    val observer = LifecycleEventObserver { _, event ->
        if (event == Lifecycle.Event.ON_RESUME) {
            viewModel.checkPermissions()
        }
    }
    lifecycleOwner.lifecycle.addObserver(observer)
    onDispose {
        lifecycleOwner.lifecycle.removeObserver(observer)
    }
}
```

**효과**:
- ✅ 화면 복귀 시 자동으로 권한 재확인
- ✅ 권한 설정 화면에서 돌아올 때 UI 즉시 업데이트
- ✅ FAB, 권한 카드 등 모든 권한 관련 UI 자동 갱신

#### 3.2 Snackbar로 에러 표시

```kotlin
// Snackbar 상태
val snackbarHostState = remember { SnackbarHostState() }
val errorState by viewModel.errorState.collectAsState()

// 에러 표시
LaunchedEffect(errorState) {
    errorState?.let { error ->
        val message = when (error) {
            is LocationError.GeofenceError -> "Geofence 오류: ${error.message}"
            is LocationError.PermissionError -> "권한 오류: ${error.message}"
            is LocationError.DatabaseError -> "저장소 오류: ${error.message}"
            is LocationError.UnknownError -> "알 수 없는 오류: ${error.message}"
        }
        snackbarHostState.showSnackbar(message)
        viewModel.clearError()
    }
}

// Scaffold에 SnackbarHost 추가
Scaffold(
    snackbarHost = {
        SnackbarHost(hostState = snackbarHostState)
    }
) { ... }
```

**효과**:
- ✅ 에러 발생 시 사용자에게 즉시 Snackbar로 알림
- ✅ 에러 타입별 적절한 메시지 표시
- ✅ 자동으로 에러 상태 초기화
