## 작업 개요

### 목적
**우선순위 규칙 구현을 위한 데이터 레이어 준비**: `updatedAt` 필드 추가 및 마이그레이션

### 선행 작업
- 3차 고도화 (v0.8) 완료 ✅ (2025-10-31)

### 배경
- **위치 충돌 해소**: 면적 → 히스테리시스 → 거리 → **최근 수정** 순으로 우선순위 결정
- **"어디서나 적용" 스케줄 충돌**: 구체성 → **최근 수정** → 생성 순서
- 이를 위해 `updatedAt` 필드가 필요하여 DB Schema v6 → v7 업그레이드 수행

### 0.2 Migration 추가 ✅

**파일**:
- `app/src/main/java/com/allday/detoxy/data/local/migration/Migration_6_7.kt` (신규)

**구현 내용**:
```kotlin
val MIGRATION_6_7 = object : Migration(6, 7) {
    override fun migrate(database: SupportSQLiteDatabase) {
        val currentTime = System.currentTimeMillis()

        // 1. ScheduleGroup 테이블에 updatedAt 추가
        database.execSQL(
            """
            ALTER TABLE schedule_group 
            ADD COLUMN updatedAt INTEGER NOT NULL DEFAULT $currentTime
            """.trimIndent()
        )

        // 2. LocationBasedAutoRun 테이블에 updatedAt 추가
        database.execSQL(
            """
            ALTER TABLE location_based_auto_run 
            ADD COLUMN updatedAt INTEGER NOT NULL DEFAULT $currentTime
            """.trimIndent()
        )

        // 3. TimeBasedAutoRun 테이블에 updatedAt 추가
        database.execSQL(
            """
            ALTER TABLE time_based_auto_run 
            ADD COLUMN updatedAt INTEGER NOT NULL DEFAULT $currentTime
            """.trimIndent()
        )
    }
}
```

**설명**:
- SQLite의 `ALTER TABLE ADD COLUMN` 사용
- 기본값으로 현재 시간(timestamp) 설정
- 기존 데이터 보존하며 안전하게 컬럼 추가

## 기술적 의사결정

### 1. updatedAt 기본값 설정

**결정**: 마이그레이션 시 `DEFAULT $currentTime` 사용

**근거**:
- 기존 데이터에 대해 "생성 시각 = 수정 시각"으로 간주하는 것이 합리적
- 마이그레이션 시점의 timestamp를 사용하여 일관성 유지

### 2. Repository 레이어에서 updatedAt 자동 갱신

**결정**: `update()` 메서드 내부에서 `copy()` + `updatedAt` 갱신

**근거**:
- 비즈니스 로직 레이어(Repository)에서 자동화하여 실수 방지
- DAO는 순수하게 데이터 접근만 담당
- ViewModel이나 UseCase에서 매번 updatedAt을 설정할 필요 없음

**장점**:
- 일관성: 모든 update 호출 시 자동으로 updatedAt 갱신
- 안전성: 개발자가 updatedAt 설정을 잊어버릴 위험 제거
- 유지보수성: 중앙화된 관리로 수정 용이

### 3. insert() 메서드는 수정하지 않음

**결정**: `insert()` 메서드는 그대로 유지

**근거**:
- 엔티티의 기본값(`System.currentTimeMillis()` 또는 `createdAt`)이 자동으로 설정됨
- Repository에서 추가 로직 불필요
