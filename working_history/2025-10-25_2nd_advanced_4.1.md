#### 1.3 에러 처리

```kotlin
sealed class LocationError {
    data class GeofenceError(val message: String) : LocationError()
    data class PermissionError(val message: String) : LocationError()
    data class DatabaseError(val message: String) : LocationError()
    data class UnknownError(val message: String) : LocationError()
}

fun clearError() {
    _errorState.value = null
}
```

**에러 발생 시나리오**:
- Geofence 등록 실패: `GeofenceError` → 롤백 처리
- 권한 없음: `PermissionError` → 사용자 안내
- DB 오류: `DatabaseError` → Geofence 롤백

#### 1.4 권한 체크

```kotlin
fun checkPermissions() {
    // Play Services 체크
    _playServicesAvailable.value = geofenceManager.isPlayServicesAvailable()

    // 백그라운드 위치 권한 체크 (Android 10+)

        PermissionUtils.hasBackgroundLocationPermission(context)
}
```

## 🎯 트랜잭션 로직 (핵심 구현)

### 1. addLocation (위치 추가)

```kotlin
fun addLocation(location: LocationBasedAutoRun) {
    viewModelScope.launch {
        try {
            // 1단계: Geofence 등록 먼저 (활성화 상태일 때)
            if (location.isEnabled) {
                val result = geofenceManager.addGeofence(location)
                if (result.isFailure) {
                    _errorState.value = LocationError.GeofenceError(
                        exception?.message ?: "Geofence 등록 실패"
                    )
                    return@launch  // 실패 시 DB 저장 안 함
                }
            }
            
            // 2단계: Geofence 성공 후 DB 저장
            repository.insert(location)
            
        } catch (e: Exception) {
            // 3단계: DB 저장 실패 시 Geofence 롤백
            if (location.isEnabled) {
                geofenceManager.removeGeofence(location.id)
            }
            _errorState.value = LocationError.DatabaseError("저장 실패")
        }
    }
}
```

**효과**: Geofence와 DB 데이터의 일관성 보장

### 2. updateLocation (위치 수정)

```kotlin
fun updateLocation(location: LocationBasedAutoRun) {
    viewModelScope.launch {
        try {
            // 1단계: 기존 Geofence 제거
            geofenceManager.removeGeofence(location.id)
            
            // 2단계: 새 Geofence 등록 (활성화 상태일 때)
            if (location.isEnabled) {
                val result = geofenceManager.addGeofence(location)
                if (result.isFailure) {
                    _errorState.value = LocationError.GeofenceError("Geofence 등록 실패")
                    return@launch
                }
            }
            
            // 3단계: DB 업데이트
            repository.update(location)
            
        } catch (e: Exception) {
            // 롤백 처리
            if (location.isEnabled) {
                geofenceManager.removeGeofence(location.id)
            }
            _errorState.value = LocationError.DatabaseError("업데이트 실패")
        }
    }
}
```

### 3. deleteLocation (위치 삭제)

```kotlin
fun deleteLocation(locationId: String) {
    viewModelScope.launch {
        try {
            // 1단계: Geofence 제거 먼저
            geofenceManager.removeGeofence(locationId)
            
            // 2단계: DB 삭제
            repository.deleteById(locationId)
            
        } catch (e: Exception) {
            _errorState.value = LocationError.DatabaseError("삭제 실패")
        }
    }
}
```

### 4. toggleLocation (활성화 토글)

```kotlin
fun toggleLocation(locationId: String, isEnabled: Boolean) {
    viewModelScope.launch {
        try {
            val location = repository.getById(locationId).first() ?: return@launch
            
            if (isEnabled) {
                // 활성화: Geofence 등록
                val result = geofenceManager.addGeofence(location)
                if (result.isFailure) {
                    _errorState.value = LocationError.GeofenceError("Geofence 등록 실패")
                    return@launch
                }
            } else {
                // 비활성화: Geofence 제거
                geofenceManager.removeGeofence(locationId)
            }
            
            // DB 상태 업데이트
            repository.toggleEnabled(locationId, isEnabled)
            
        } catch (e: Exception) {
            // 롤백 처리
            if (isEnabled) {
                geofenceManager.removeGeofence(locationId)
            }
            _errorState.value = LocationError.DatabaseError("토글 실패")
        }
    }
}
```
