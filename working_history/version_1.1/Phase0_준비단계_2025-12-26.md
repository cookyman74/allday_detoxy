## 문제 상황 / 작업 배경

v1.1 기능 추가로 스케줄에 목표(title) + 할일(todos)을 추가하여 집중 목적을 명확화하는 기능을 구현해야 함.

**MVP 핵심 기능**:
- 차단 오버레이 할일 표시
- 세션 종료 개별 체크 (30초 타이머)
- 30초 미응답 처리 (필수=미완료, 일반=미응답)
- 목표 상태 자동 도출
