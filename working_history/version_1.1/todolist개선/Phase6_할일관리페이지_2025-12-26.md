```kotlin
// 서브 탭 (전체 스케줄 / 할일 관리)
var selectedSubTab by remember { mutableStateOf(0) }
val subTabs = listOf("전체 스케줄", "📋 할일 관리")

TabRow(selectedTabIndex = selectedSubTab) {
    subTabs.forEachIndexed { index, title ->
        Tab(
            selected = selectedSubTab == index,
            onClick = { selectedSubTab = index },
            text = { Text(title) }
        )
    }
}

when (selectedSubTab) {
    0 -> { /* 기존 스케줄 목록 */ }
    1 -> { TodoManagementScreen() }
}
```

## 수정 가능 항목 정책

| 상태 | 목표만 있을 때 | 목표+할일 있을 때 |
|------|---------------|------------------|
| 완료 | 수정 불필요 | 수정 불필요 |
| 미완료 | ✅ 수정 가능 | 할일만 수정 가능 (목표는 자동 도출) |
| 미응답 | ✅ 수정 가능 | 할일만 수정 가능 (목표는 자동 도출) |

목표 자동 도출 규칙:
- 모든 할일 완료 → 목표 완료
- 하나라도 미완료/미응답 → 목표 미완료
