## 🔍 주요 구현 내용

### GrayscaleTipBanner 컴포저블

```kotlin
@Composable
fun GrayscaleTipBanner(
    onDismiss: () -> Unit,
    onNavigateToSettings: () -> Unit
) {
    // Android 15+에서는 표시하지 않음
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.VANILLA_ICE_CREAM) return

    GlassSurface(/* Glass 스타일 */) {
        // 헤더 + 버튼 영역
        Row {
            OutlinedButton(onClick = onDismiss) { Text("다시 보지 않기") }
            Button(onClick = onNavigateToSettings) { Text("설정 열기") }
        }
    }
}
```

### 배너 표시 조건
- Android 14 이하
- 흑백 모드 설정 ON
- "다시 보지 않기" 상태가 false

## 🔧 리뷰 피드백 반영 (2026-01-06)

### [중간] GrayscaleTipBanner 미호출
- **문제**: 배너가 어디에서도 호출되지 않음
- **해결**: 
  - TimerViewModel에 grayscaleModeEnabled, grayscaleTipDismissed StateFlow 추가
  - TimerViewModel에 dismissGrayscaleTip() 메서드 추가
  - TimerScreen에서 제목 아래에 GrayscaleTipBanner 통합

### [중간] grayscaleTipDismissed 미사용
- **문제**: "다시 보지 않기" 저장 로직이 UI와 연결되지 않음
- **해결**: TimerScreen에서 viewModel.dismissGrayscaleTip() 호출로 연결

### 타이머 화면 통합 코드
```kotlin
// 조건: Android 14 이하 + 흑백 모드 ON + "다시 보지 않기" 상태가 false
val grayscaleModeEnabled by viewModel.grayscaleModeEnabled.collectAsState()
val grayscaleTipDismissed by viewModel.grayscaleTipDismissed.collectAsState()

if (grayscaleModeEnabled && !grayscaleTipDismissed) {
    GrayscaleTipBanner(
        onDismiss = { viewModel.dismissGrayscaleTip() },
        onNavigateToSettings = { /* 설정 화면 이동 */ }
    )
}
```
