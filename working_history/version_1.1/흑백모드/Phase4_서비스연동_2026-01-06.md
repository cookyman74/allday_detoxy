# Grayscale Mode Phase 4 - FocusTimerService 연동

**작업일**: 2026-01-06  
**버전**: v1.1  
**Phase**: Phase 4 (FocusTimerService 연동)

---

## 📋 작업 요약

타이머 시작/종료 시 흑백 모드를 자동으로 활성화/비활성화하도록 FocusTimerService에 연동했습니다.

---

## ✅ 완료된 작업

### TASK-001: GrayscaleManager DI 추가
- **파일**: `service/timer/FocusTimerService.kt`
- **추가**:
  ```kotlin
  @Inject
  lateinit var grayscaleManager: GrayscaleManager
  ```

### TASK-002: startTimerInternal() 연동
- **파일**: `FocusTimerService.kt`
- **위치**: DND 활성화 코드 다음 (라인 ~382)
- **추가 코드** (리뷰 반영 최신 버전):
  ```kotlin
  // 흑백 모드 활성화 (설정 ON + Android 15+ + 권한 있음만)
  // ⚠️ 리뷰 반영: 레이스 컨디션 방지를 위해 Job을 추적하고 상태 확인
  grayscaleEnableJob?.cancel()
  grayscaleEnableJob = serviceScope?.launch {
      try {
          val isGrayscaleEnabled = settingsRepository.grayscaleModeEnabledFlow.first()
          if (isGrayscaleEnabled && _state.value == FocusState.RUNNING) {
              val grayscaleResult = grayscaleManager.enableGrayscaleIfNeeded()
              Log.d(TAG, "✅ Grayscale mode enable attempted: result=$grayscaleResult")
          }
      } catch (e: Exception) {
          Log.e(TAG, "❌ Failed to enable grayscale mode: ${e.message}", e)
      }
  }
  ```

### TASK-003: stopTimerInternal() 연동
- **파일**: `FocusTimerService.kt`
- **위치**: DND 비활성화 코드 다음 (라인 ~471)
- **추가 코드** (리뷰 반영 최신 버전):
  ```kotlin
  // 흑백 모드 비활성화
  // ⚠️ 리뷰 반영: 활성화 Job 취소 (레이스 컨디션 방지)
  grayscaleEnableJob?.cancel()
  grayscaleEnableJob = null
  val grayscaleResult = grayscaleManager.disableGrayscaleIfNeeded()
  Log.d(TAG, "✅ Grayscale mode disable attempted: result=$grayscaleResult")
  ```

## � 리뷰 피드백 반영 (2026-01-06)

### [높음] 레이스 컨디션 방지
- **문제**: `startTimerInternal()`에서 흑백 활성화를 비동기 실행, `stopTimerInternal()`은 즉시 비활성화 → 타이머 빠른 종료 시 활성화가 뒤늦게 실행될 수 있음
- **해결**:
  1. `grayscaleEnableJob` 변수 추가하여 활성화 Job 추적
  2. 활성화 전 `_state.value == FocusState.RUNNING` 상태 확인
  3. `stopTimerInternal()`에서 `grayscaleEnableJob?.cancel()` 호출

### [중간] DataStore 예외 처리
- **문제**: `grayscaleModeEnabledFlow.first()` 호출에 예외 처리 없음
- **해결**: try/catch 블록 추가, 실패 시 에러 로그 기록

### 수정된 코드 (startTimerInternal)
```kotlin
grayscaleEnableJob?.cancel()
grayscaleEnableJob = serviceScope?.launch {
    try {
        val isGrayscaleEnabled = settingsRepository.grayscaleModeEnabledFlow.first()
        // 상태 확인: 타이머가 여전히 실행 중인지 확인 (레이스 컨디션 방지)
        if (isGrayscaleEnabled && _state.value == FocusState.RUNNING) {
            val grayscaleResult = grayscaleManager.enableGrayscaleIfNeeded()
            Log.d(TAG, "✅ Grayscale mode enable attempted: result=$grayscaleResult")
        }
    } catch (e: Exception) {
        Log.e(TAG, "❌ Failed to enable grayscale mode: ${e.message}", e)
    }
}
```

### 수정된 코드 (stopTimerInternal)
```kotlin
// ⚠️ 리뷰 반영: 활성화 Job 취소 (레이스 컨디션 방지)
grayscaleEnableJob?.cancel()
grayscaleEnableJob = null
val grayscaleResult = grayscaleManager.disableGrayscaleIfNeeded()
```
