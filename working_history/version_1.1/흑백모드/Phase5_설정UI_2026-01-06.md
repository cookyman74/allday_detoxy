## 🔍 주요 구현 내용

### Android 버전별 UI 분기

```kotlin
if (isAndroid15OrAbove) {
    // Android 15+: 토글 스위치
    GrayscaleToggleItem(
        isEnabled = grayscaleModeEnabled,
        onToggle = onToggle
    )
} else {
    // Android 14 이하: 경고 배너
    GrayscaleWarningBanner(
        onNavigateToSettings = onNavigateToSettings
    )
}
```

### Glass 스타일 UI

기존 DetoxyControlSettingsScreen의 Glass 스타일을 따라 일관된 디자인 적용:
- `GlassSurface` 사용 (alpha = 0.35f)
- MaterialTheme 컬러 스키마 활용
- 아이콘 + 텍스트 + 스위치 레이아웃

## 🔧 리뷰 피드백 반영 (2026-01-06)

### [중간] GrayscaleWarningBanner 콜백 미사용
- **문제**: `onNavigateToSettings`를 받지만 내부에서 직접 Intent 생성
- **해결**: 콜백 함수를 직접 사용하도록 수정, DetoxyControlSettingsScreen에서 Intent 제공

### [중간] 권한 다이얼로그 dismiss 로직
- **문제**: `onDismissDialog`가 `onGrayscalePermissionResult(false)`로 연결되어 의미 혼동
- **상태**: 현재 동작상 문제 없음 (토글은 이미 false). 추후 별도 dismiss 콜백 분리 가능
