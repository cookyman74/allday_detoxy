- **경로**: `app/src/main/java/com/allday/detoxy/presentation/model/WeeklyHeatmapModels.kt`

## 🔧 주요 해결 이슈

### org.json.JSONArray 호환성 문제
- **문제**: Android 단위 테스트에서 `org.json.JSONArray`는 stub으로만 존재하여 동작하지 않음
- **해결**: 정규식 기반 파싱으로 변경
```kotlin
val dayPattern = Regex(""""(MON|TUE|WED|THU|FRI|SAT|SUN)"""")
dayPattern.findAll(enabledDaysJson).mapNotNull { match -> ... }
```
