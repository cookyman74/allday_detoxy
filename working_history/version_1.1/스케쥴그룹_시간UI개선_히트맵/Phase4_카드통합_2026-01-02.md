## 🎬 애니메이션 구현

```kotlin
AnimatedVisibility(
    visible = isHeatmapExpanded && timeBasedAutoRuns.isNotEmpty(),
    enter = expandVertically(),
    exit = shrinkVertically()
) {
    WeeklyHeatmap(
        heatmap = heatmap,
        onRowClick = onHeatmapRowClick
    )
}
```

- `expandVertically()`: 위에서 아래로 펼쳐지는 애니메이션
- `shrinkVertically()`: 아래에서 위로 접히는 애니메이션
- 다른 UI 요소들이 자연스럽게 재배치됨

## 📝 UX 피드백 반영 (2026-01-02)

### 변경 사항

| 변경 전 | 변경 후 |
|---------|---------|
| "히트맵 보기" 버튼으로 토글 | **히트맵 항상 표시** |
| 시간 스케줄 목록 기본 표시 | **목록 기본 접기**, "목록 보기"로 펼치기 |

### 성능 관련

- 스케줄 그룹 목록은 `LazyColumn` 사용 → 화면에 보이는 항목만 렌더링
- 히트맵이 항상 표시되어도 각 카드가 화면에 있을 때만 렌더링되므로 성능 문제 없음
