## 📁 생성된 파일

### 1. HeatmapCell.kt
- **경로**: `app/src/main/java/com/allday/detoxy/presentation/ui/heatmap/HeatmapCell.kt`
- **기능**: 1시간 슬롯의 집중 계획 밀도를 색상으로 표현
- **접근성**: 스크린 리더 지원 ("9시 30분 계획됨")

### 2. HeatmapRow.kt
- **경로**: `app/src/main/java/com/allday/detoxy/presentation/ui/heatmap/HeatmapRow.kt`
- **기능**: 요일+시간대(AM/PM) 행, 12개 셀 포함
- **접근성**: 최소 터치 타겟 48dp, 스크린 리더 지원

### 3. WeeklyHeatmap.kt
- **경로**: `app/src/main/java/com/allday/detoxy/presentation/ui/heatmap/WeeklyHeatmap.kt`
- **기능**: 14개 행 + 요약 정보 + 범례 통합

### 4. HeatmapLegend.kt
- **경로**: `app/src/main/java/com/allday/detoxy/presentation/ui/heatmap/HeatmapLegend.kt`
- **기능**: 색상 레벨 의미 설명 (없음 ~ 60분)

### 5. HeatmapDetailSheet.kt
- **경로**: `app/src/main/java/com/allday/detoxy/presentation/ui/heatmap/HeatmapDetailSheet.kt`
- **기능**: 행 탭 시 시간 스케줄 상세 정보 BottomSheet
