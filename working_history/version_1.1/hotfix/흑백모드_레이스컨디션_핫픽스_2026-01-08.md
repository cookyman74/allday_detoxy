## 🔍 근본 원인

### 두 개의 ZenRule 충돌

1. **`implicit_com.allday.detoxy`** (암묵적 룰)
   - `DndManager.setInterruptionFilter(ALARMS)` 호출 시 시스템이 자동 생성
   - 타입: DND 전용

2. **`3e53e8f5...`** (그레이스케일 룰)
   - `GrayscaleManager`가 생성
   - 타입: 그레이스케일 + `INTERRUPTION_FILTER_ALL`

### 실행 순서 문제
```
[FocusTimerService.startTimerInternal()]

1. dndManager.enableDnd()  ← 동기 실행
   └→ setInterruptionFilter(ALARMS)
   └→ 암묵적 ZenRule 활성화

2. grayscaleManager.enableGrayscaleIfNeeded()  ← 비동기 실행 (launch)
   └→ 그레이스케일 룰 활성화 시도
   └→ 시스템이 충돌 감지 → 그레이스케일 룰 비활성화!
```

### 2. FocusTimerService 실행 순서 변경

**`FocusTimerService.kt`**:
```kotlin
// v5: 흑백 모드 먼저 시도, 성공 시 DND 별도 호출 스킵
grayscaleEnableJob = serviceScope?.launch {
    val grayscaleResult = grayscaleManager.enableGrayscaleIfNeeded()
    
    if (!grayscaleResult) {
        // 흑백 실패 시에만 별도 DND 활성화
        dndManager.enableDnd()
    } else {
        Log.d(TAG, "ℹ️ DND skipped - included in grayscale rule")
    }
}
```
