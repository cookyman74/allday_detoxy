## 📋 문제 요약

1. 화면 켤 때: 흑백 모드 잠깐 켜졌다가 터치(잠금해제) 시 꺼지는 현상 ("turned off after touch")
2. 원인 분석: 
   - `Update` 방식은 시스템이 무시하는 경우가 발생.
   - `Toggle` 방식이 확실하지만, 동기식 `Thread.sleep`과 쿨다운 로직이 잠금해제 시점의 재적용을 방해하거나 ANR 위험이 있음.
   - 빠른 화면 전환 시 쿨다운 때문에 재적용 로직이 건너뛰어져서 효과가 적용되지 않음.

## 🔁 버전 히스토리 (요약)

### v15 (Toggle 복원 + 300ms)
- 쿨다운을 줄였으나, 동기식 처리가 성능에 영향을 줄 수 있고, 여전히 타이밍 이슈 존재 가능성.

### v16 (2026-01-14) - 현재 (Fundamental Fix)
**핵심 변경 사항**:
1. **비동기 처리 (`suspend fun` + `delay`)**:
   - `Thread.sleep()`을 제거하고 코루틴 `delay()`를 사용하여 메인 스레드나 작업 스레드를 차단하지 않음. **(성능 개선)**
2. **AtomicBoolean 가드 (`isReapplying`)**:
   - `synchronized` 락 대신 `AtomicBoolean`을 사용하여 재적용 로직이 실행 중일 때만 중복 요청을 무시(Debounce).
   - 실행 중이 아니면 언제든(쿨다운 없이) 즉시 재적용 시도.
3. **쿨다운 제거**:
   - 시간 기반(300ms) 쿨다운을 제거하여, 사용자가 화면을 빠르게 껐다 켜거나 잠금해제 할 때마다 즉시 반응하도록 수정.
4. **로직 유지**:
   - `Toggle` (False -> 100ms -> True) 방식 유지 (가장 확실한 효과).
   - `FILTER_ALL` 유지 (DND 알림 없음).
