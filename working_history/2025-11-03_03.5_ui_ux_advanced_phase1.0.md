## 작업 개요

### 배경
3.5차 고도화 (v0.9) 완료 후, UI/UX 리뷰에서 다음과 같은 피드백을 받음:
- 예약설정이 "디톡시 제어 설정" 화면 깊숙이 숨어있어 발견성 낮음
- 핵심 기능인데 "옵션"처럼 인식될 위험
- 접근 깊이 3단계 (설정 탭 → 스크롤 → 예약설정 섹션)
- 반복 사용성 저하

### 목표
- 📌 **스케줄 탭 신설**: 하단 네비게이션에 "스케줄" 탭 추가
- 🎯 **발견성 개선**: 3단계 → 1단계 접근 (67% 단축)
- ♻️ **기존 UI 재사용**: ScheduleGroupCard 등 이미 구현된 컴포넌트 활용
- 📊 **사용자 여정 강화**: 타이머(수동) → 스케줄(자동) 흐름 명확화

### 작업 범위
- ✅ Phase 1.1: MainActivity.kt 수정 (탭 4개로 확장, Back Stack 관리)
- ✅ Phase 1.2: ScheduleTabScreen.kt 구현 (리스트/요약 화면 신규 생성)
- ✅ Phase 1.3: ScheduleGroupViewModel.kt 확장 (3개 메서드 추가)
- ✅ Phase 1.4: DetoxyControlSettingsScreen.kt 수정 (안내 카드 교체)
- ✅ Phase 1.5: 빌드 검증 (린트 확인)

## Phase 1.3: ScheduleGroupViewModel.kt 확장 ✅

### 작업 내용
1. **Import 추가**
   - `java.time.LocalTime` - 시간 파싱용

2. **getNextScheduleToday() 메서드 추가**
   ```kotlin
   fun getNextScheduleToday(): Flow<TimeBasedAutoRun?> = flow {
       val now = LocalTime.now()
       val currentActiveGroup = activeGroup.value
       
       if (currentActiveGroup != null) {
           val timeSlots = repository.getLinkedTimeBasedAutoRuns(currentActiveGroup.id)
           
           val nextSlot = timeSlots
               .filter { slot ->
                   val slotTime = parseTime(slot.hour, slot.minute)
                   slotTime > now
               }
               .sortedBy { slot -> slot.hour * 60 + slot.minute }
               .firstOrNull()
           
           emit(nextSlot)
       } else {
           emit(null)
       }
   }
   ```

3. **getTimeSlotCount() 메서드 추가**
   ```kotlin
   fun getTimeSlotCount(groupId: String): Flow<Int> = 
       flow {
           val timeSlots = linkedTimeBasedAutoRuns.value[groupId] ?: emptyList()
           emit(timeSlots.size)
       }
   ```

4. **getLinkedLocationName() 메서드 추가**
   ```kotlin
   fun getLinkedLocationName(groupId: String): Flow<String?> = flow {
       val locations = linkedLocations.value[groupId] ?: emptyList()
       emit(locations.firstOrNull()?.name)
   }
   ```

5. **parseTime() 헬퍼 함수 추가**
   ```kotlin
   private fun parseTime(hour: Int, minute: Int): LocalTime {
       return LocalTime.of(hour, minute)
   }
   ```

### 빌드 및 컴파일
```bash
# 클린 빌드
./gradlew clean

# 컴파일 확인

# 린트 확인

# 전체 빌드

# APK 설치

```

### 수동 테스트 시나리오
1. **네비게이션 전환**
   - 타이머 탭 → 스케줄 탭 → 리포트 탭 → 설정 탭 전환 확인
