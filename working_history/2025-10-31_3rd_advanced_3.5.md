## 1. 작업 개요

### 1.1 배경

**문제 발견**:
- 사용자가 스케줄 그룹의 연필(편집) 아이콘을 클릭했을 때, 시간 설정 화면이 나타나지 않음
- `AddScheduleGroupDialog`는 그룹의 이름과 설명만 편집 가능
- 연결된 시간대(TimeBasedAutoRun)를 편집하려면 별도로 [시간 기반] 화면으로 이동해야 함

**사용자 피드백**:
> "스케쥴 그룹의 시간표를 수정하기 위해 편집(연필모양)을 누르면 시간설정 화면은 나오지 않고 있다."

**현재 사용자 흐름 (불편함)**:
```
[스케줄 그룹] 화면
  └─ "학교" 카드
      ├─ 9시 오전 업무 (90분)  ← 클릭 불가!
      ├─ 14시 오후 업무 (120분) ← 클릭 불가!
      └─ [편집] 버튼
          ↓
      AddScheduleGroupDialog
          ├─ 이름: "학교"
          └─ 설명: "ㅎㅎ"
          
          ❌ 시간대 편집 불가!

// 시간대를 편집하려면...
[예약설정] 탭 → [시간 기반] 화면으로 이동
  ↓
"오전 업무" 편집
  ↓
시간표 연결 변경
```

### 1.2 목표

**Option B: "시간표 관리" 버튼 추가 (빠른 구현)**
- ScheduleGroupCard에 "시간표 관리" 버튼 추가
- 버튼 클릭 시 TimeBasedAutoRunScreen으로 자동 이동
- 사용자가 시간대를 쉽게 편집할 수 있도록 UX 개선

**장점**:
- ✅ 빠르게 구현 가능 (~10분)
- ✅ 기존 UI 패턴 재사용
- ✅ 화면 이동을 통한 자연스러운 흐름

### 1.3 참조 문서
- `docs/03_complex_time&location_todolist.md` §3 (UI 구현)
- `working_history/2025-10-31_3rd_advanced_3.4.md` (네비게이션 통합)

## 2. ScheduleGroupCard 확장

### 2.1 개요

ScheduleGroupCard 컴포넌트에 "시간표 관리" 버튼을 추가하여 사용자가 연결된 시간대를 쉽게 편집할 수 있도록 개선했습니다.

**파일**: `app/src/main/java/com/allday/detoxy/presentation/ui/autorun/components/ScheduleGroupCard.kt`

### 2.2 주요 변경사항

#### 2.2.1 함수 시그니처 확장

**Before**:
```kotlin
@Composable
fun ScheduleGroupCard(
    group: ScheduleGroup,
    isActive: Boolean,
    timeBasedAutoRuns: List<TimeBasedAutoRun>,
    linkedLocationCount: Int,
    onActivate: () -> Unit,
    onEdit: () -> Unit,
    onDelete: () -> Unit,
    modifier: Modifier = Modifier
)
```

**After**:
```kotlin
@Composable
fun ScheduleGroupCard(
    group: ScheduleGroup,
    isActive: Boolean,
    timeBasedAutoRuns: List<TimeBasedAutoRun>,
    linkedLocationCount: Int,
    onActivate: () -> Unit,
    onEdit: () -> Unit,
    onDelete: () -> Unit,
    onManageTimeSlots: () -> Unit = {},  // 🆕 추가
    modifier: Modifier = Modifier
)
```

**변경 사항**:
- `onManageTimeSlots` 콜백 파라미터 추가
- 기본값 `{}` 설정으로 하위 호환성 유지

**목적**:
- TimeBasedAutoRunScreen으로 이동하는 콜백 제공
- 시간표 관리 버튼 클릭 시 호출

#### 2.2.2 UI 레이아웃 개선

**Before**:
```kotlin
// 액션 버튼
Row(
    modifier = Modifier.fillMaxWidth(),
    horizontalArrangement = Arrangement.SpaceBetween,
    verticalAlignment = Alignment.CenterVertically
) {
    // 활성화/비활성화 버튼
    if (isActive) {
        OutlinedButton(onClick = onActivate) {
            Text("비활성화")
        }
    } else {
        Button(onClick = onActivate) {
            Text("활성화")
        }
    }
    
    Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
        // 확장/축소, 편집, 삭제 아이콘 버튼
    }
}
```

**After**:
```kotlin
// 액션 버튼
Column(
    modifier = Modifier.fillMaxWidth(),
    verticalArrangement = Arrangement.spacedBy(8.dp)
) {
    // 상단: 활성화 버튼 + 시간표 관리 버튼
    Row(
        modifier = Modifier.fillMaxWidth(),
        horizontalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        // 활성화/비활성화 버튼
        if (isActive) {
            OutlinedButton(
                onClick = onActivate,
                modifier = Modifier.weight(1f)  // 🆕 동일한 너비
            ) {
                Text("비활성화")
            }
        } else {
            Button(
                onClick = onActivate,
                modifier = Modifier.weight(1f)  // 🆕 동일한 너비
            ) {
                Text("활성화")
            }
        }
        
        // 🆕 시간표 관리 버튼 (시간대가 있을 때만 표시)
        if (timeBasedAutoRuns.isNotEmpty()) {
            OutlinedButton(
                onClick = onManageTimeSlots,
                modifier = Modifier.weight(1f)
            ) {
                Icon(
                    imageVector = Icons.Default.Edit,
                    contentDescription = null,
                    modifier = Modifier.size(18.dp)
                )
                Spacer(modifier = Modifier.width(4.dp))
                Text("시간표 관리")
            }
        }
    }
    
    // 하단: 아이콘 버튼들
    Row(
        modifier = Modifier.fillMaxWidth(),
        horizontalArrangement = Arrangement.End
    ) {
        Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            // 확장/축소, 편집, 삭제 아이콘 버튼
        }
    }
}
```

**변경 사항**:
1. **레이아웃 구조 변경**: `Row` → `Column`
   - 버튼이 많아져서 세로 배치로 변경
   - 상단: 활성화 + 시간표 관리 버튼
   - 하단: 아이콘 버튼들

2. **"시간표 관리" 버튼 추가**:
   - 아이콘: `Icons.Default.Edit`
   - 텍스트: "시간표 관리"
   - 조건부 표시: `if (timeBasedAutoRuns.isNotEmpty())`
   - 시간대가 없으면 버튼 숨김

3. **버튼 너비 균등 분배**:
   - `Modifier.weight(1f)` 적용
   - 두 버튼이 동일한 너비로 표시

**아이콘 선택 이슈**:
- 초기: `Icons.Default.Schedule` 사용 시도 → 컴파일 에러 (Unresolved reference)
- 해결: `Icons.Default.Edit`로 변경 (이미 import되어 있음)

## 8. 추가 고려사항

### 8.1 향후 개선 가능 사항 (Option A)

**시간대 클릭 편집 기능**:
- 시간대 리스트에서 각 항목 클릭 시 즉시 편집 다이얼로그 표시
- 예상 작업 시간: ~30분
- 장점: 한 화면에서 모든 작업 가능
- 단점: 코드 복잡도 증가

**구현 예시**:
```kotlin
timeBasedAutoRuns.forEach { autoRun ->
    Surface(
        modifier = Modifier
            .fillMaxWidth()
            .clickable { onTimeSlotClick(autoRun) },  // 🆕 클릭 가능
        color = MaterialTheme.colorScheme.surface
    ) {
        Row {
            Text("• ${formatTime(autoRun.hour, autoRun.minute)}")
            Icon(Icons.Default.Edit, modifier = Modifier.size(16.dp))
        }
    }
}
```

### 8.2 현재 구현의 장점

1. **간단한 구조**:
   - 기존 네비게이션 패턴 재사용
   - 추가 코드 최소화

2. **명확한 의도**:
   - "시간표 관리" 버튼으로 명확한 액션 제시
   - 사용자 혼란 최소화

3. **일관된 UX**:
   - 다른 화면 전환과 동일한 패턴
   - Material Design 3 가이드라인 준수
