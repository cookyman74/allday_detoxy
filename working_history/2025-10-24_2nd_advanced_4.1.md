### 1. LocationBasedAutoRunRepository 구현

**파일**: `app/src/main/java/com/allday/detoxy/data/repository/LocationBasedAutoRunRepository.kt` (신규, ~95줄)

```kotlin
/**
 * 위치 기반 자동 실행 Repository
 *
 * LocationBasedAutoRun 데이터에 대한 비즈니스 로직과 데이터 액세스를 담당합니다.
 */
@Singleton
class LocationBasedAutoRunRepository @Inject constructor(
    private val dao: LocationBasedAutoRunDao
) {
    fun getAll(): Flow<List<LocationBasedAutoRun>>
    fun getById(id: String): Flow<LocationBasedAutoRun?>
    fun getEnabled(): Flow<List<LocationBasedAutoRun>>
    suspend fun insert(autoRun: LocationBasedAutoRun)
    suspend fun update(autoRun: LocationBasedAutoRun)
    suspend fun deleteById(id: String)
    suspend fun toggleEnabled(id: String, isEnabled: Boolean)
    suspend fun getCount(): Int
    suspend fun getEnabledCount(): Int
}
```

**특징**:
- Singleton 스코프로 앱 전체에서 단일 인스턴스 사용
- DAO를 통한 데이터 액세스 추상화
- Flow를 통한 반응형 데이터 스트림 제공

#### 3.1 DisposableEffect로 onResume 권한 재확인

**이전 문제**:
- 권한 설정 화면에서 돌아올 때 권한 상태가 자동으로 갱신되지 않음
- 사용자가 설정에서 권한을 허용해도 UI가 업데이트되지 않음

**개선 후**:
```kotlin
// 화면 복귀 시 권한 재확인 (설정 화면에서 돌아올 때)
DisposableEffect(lifecycleOwner) {
    val observer = LifecycleEventObserver { _, event ->
        if (event == Lifecycle.Event.ON_RESUME) {
            viewModel.checkPermissions()
        }
    }
    lifecycleOwner.lifecycle.addObserver(observer)
    onDispose {
        lifecycleOwner.lifecycle.removeObserver(observer)
    }
}
```

**효과**:
- ✅ 화면 복귀 시 자동으로 권한 재확인
- ✅ 권한 설정 화면에서 돌아올 때 UI 즉시 업데이트

### 1. 🔴 Play Services 경고 처리 방식 오류 (즉시 수정)

**문제**:
- `LocationBasedAutoRunScreen.kt:189`에서 `return@LazyColumn` 사용
- LazyColumn DSL 블록 내부에서는 `return` 사용 불가
- 컴파일 오류는 아니지만 의도한 동작이 수행되지 않음

**해결**:
```kotlin
// Before: return@LazyColumn 사용 (작동하지 않음)
if (!playServicesAvailable) {
    item { PlayServicesWarningCard(...) }
    return@LazyColumn // ❌ 작동 안 함
}
if (!hasFullLocationPermission) {
    item { LocationPermissionCard(...) }
}

// After: else-if 구조로 명확히 분리
if (!playServicesAvailable) {
    item { PlayServicesWarningCard(...) }
    // Play Services 없으면 이후 항목 표시 안 함
} else if (!hasFullLocationPermission) {
    // 위치 권한 안내 (Play Services는 있지만 권한 없음)
    item { LocationPermissionCard(...) }
} else {
    // Play Services 있고 권한도 있음 - 위치 리스트 표시
    // ... 위치 리스트, 배터리 안내 등
}
```

**효과**:
- ✅ Play Services 미지원 시 경고만 표시
- ✅ 권한 상태에 따라 적절한 UI만 렌더링
- ✅ 의도한 대로 조건별 화면 분기 동작

```kotlin

if (!playServicesAvailable) {

    // 2단계: 권한 없음 → 권한 안내만
    item { LocationPermissionCard(...) }

    if (locations.isEmpty()) {

}
```
