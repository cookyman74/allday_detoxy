## 2. 테스트 의존성 추가 (사전 작업)

### 2.1 문제 발견
**증상**: `compileDebugAndroidTestKotlin` 실행 시 다음 에러 발생
```
e: Unresolved reference: testing
e: Unresolved reference: MigrationTestHelper
e: Unresolved reference: assertEquals
e: Unresolved reference: assertTrue
```

**원인**: Room testing 라이브러리와 kotlin-test가 build.gradle.kts에 누락

### 2.2 해결 방법

#### 2.2.1 libs.versions.toml 업데이트
**파일**: `gradle/libs.versions.toml`

**추가 라이브러리**:
```toml
# Room
androidx-room-testing = { group = "androidx.room", name = "room-testing", version.ref = "room" }
kotlin-test = { group = "org.jetbrains.kotlin", name = "kotlin-test", version.ref = "kotlin" }
```

**설명**:
- `androidx-room-testing`: Room 마이그레이션 테스트를 위한 MigrationTestHelper 제공
- `kotlin-test`: Kotlin 테스트 어설션 함수 제공 (assertEquals, assertTrue 등)

#### 2.2.2 build.gradle.kts 업데이트
**파일**: `app/build.gradle.kts`

**추가 의존성**:
```kotlin
// Testing
testImplementation(libs.junit)
testImplementation(libs.kotlin.test)                // 추가
androidTestImplementation(libs.androidx.junit)
androidTestImplementation(libs.androidx.espresso.core)
androidTestImplementation(platform(libs.androidx.compose.bom))
androidTestImplementation(libs.androidx.ui.test.junit4)
androidTestImplementation(libs.androidx.room.testing)  // 추가
androidTestImplementation(libs.kotlin.test)            // 추가
```

**명령어**: `./gradlew compileDebugAndroidTestKotlin`

**결과**: ✅ **BUILD SUCCESSFUL** (3분 24초)

## 10. 기술적 학습 내용

### 10.1 Room MigrationTestHelper

**핵심 메서드**:
- `createDatabase(name, version)`: 특정 버전의 DB 생성
- `runMigrationsAndValidate(name, version, validate, migrations)`: 마이그레이션 실행 및 검증
- `close()`: DB 종료 (use 블록 활용)

**테스트 패턴**:
```kotlin
helper.createDatabase(TEST_DB, 4).apply {
    // 샘플 데이터 삽입

    close()

```

sourceSets {
