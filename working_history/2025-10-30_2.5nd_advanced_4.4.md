**build.gradle.kts 확인**:
```kotlin
signingConfigs {
    create("release") {
        storeFile = file("../screensence-release-key.jks")
        storePassword = System.getenv("KEYSTORE_PASSWORD") ?: "screensence@hoya1024"
        keyAlias = "screensence"
        keyPassword = System.getenv("KEY_PASSWORD") ?: "screensence@hoya1024"
    }
}
buildTypes {
    release {
        isMinifyEnabled = false
        proguardFiles(...)
        signingConfig = signingConfigs.getByName("release")
    }
}
```

**결론**: ✅ **서명 설정 확인됨**
- Keystore: `screensence-release-key.jks`
- Key Alias: `screensence`
- 서명 자동 적용 (signingConfig)
