## 2. MainActivity 네비게이션 확장

### 2.1 개요

MainActivity에 ScheduleGroupScreen으로 이동할 수 있는 네비게이션 타입과 분기를 추가했습니다.

**파일**: `app/src/main/java/com/allday/detoxy/MainActivity.kt`

### 2.2 주요 변경사항

#### 2.2.1 ScheduleGroupScreen import 추가

```kotlin
import com.allday.detoxy.presentation.ui.autorun.TimeBasedAutoRunScreen
import com.allday.detoxy.presentation.ui.autorun.LocationBasedAutoRunScreen
import com.allday.detoxy.presentation.ui.autorun.ScheduleGroupScreen  // 🆕 3차 고도화
import com.allday.detoxy.presentation.ui.onboarding.WelcomeScreen
```

**목적**: ScheduleGroupScreen을 MainActivity에서 사용할 수 있도록 import

#### 2.2.2 AutoRunScreenType enum 확장

**Before**:
```kotlin
enum class AutoRunScreenType {
    NONE,           // 자동 실행 화면 없음
    TIME_BASED,     // 시간 기반 자동 실행
    LOCATION_BASED  // 위치 기반 자동 실행
}
```

**After**:
```kotlin
enum class AutoRunScreenType {
    NONE,           // 자동 실행 화면 없음
    TIME_BASED,     // 시간 기반 자동 실행
    LOCATION_BASED, // 위치 기반 자동 실행
    SCHEDULE_GROUP  // 🆕 3차 고도화: 시간표 그룹 관리
}
```

**변경 사항**:
- `SCHEDULE_GROUP` 타입 추가
- 주석 추가로 용도 명확화

#### 2.2.3 네비게이션 분기 추가

**Before**:
```kotlin
when (showAutoRunScreen) {
    AutoRunScreenType.TIME_BASED -> {
        TimeBasedAutoRunScreen(
            onBack = { showAutoRunScreen = AutoRunScreenType.NONE },
            onNavigateToLocationBased = { showAutoRunScreen = AutoRunScreenType.LOCATION_BASED }
        )
    }
    AutoRunScreenType.LOCATION_BASED -> {
        LocationBasedAutoRunScreen(
            onBack = { showAutoRunScreen = AutoRunScreenType.NONE },
            onNavigateToTimeBased = { showAutoRunScreen = AutoRunScreenType.TIME_BASED }
        )
    }
    AutoRunScreenType.NONE -> {
        // 탭별 화면
    }
}
```

**After**:
```kotlin
when (showAutoRunScreen) {
    AutoRunScreenType.TIME_BASED -> {
        TimeBasedAutoRunScreen(
            onBack = { showAutoRunScreen = AutoRunScreenType.NONE },
            onNavigateToLocationBased = { showAutoRunScreen = AutoRunScreenType.LOCATION_BASED },
            onNavigateToScheduleGroup = { showAutoRunScreen = AutoRunScreenType.SCHEDULE_GROUP }  // 🆕
        )
    }
    AutoRunScreenType.LOCATION_BASED -> {
        LocationBasedAutoRunScreen(
            onBack = { showAutoRunScreen = AutoRunScreenType.NONE },
            onNavigateToTimeBased = { showAutoRunScreen = AutoRunScreenType.TIME_BASED },
            onNavigateToScheduleGroup = { showAutoRunScreen = AutoRunScreenType.SCHEDULE_GROUP }  // 🆕
        )
    }
    // 🆕 3차 고도화: 시간표 그룹 관리 화면
    AutoRunScreenType.SCHEDULE_GROUP -> {
        ScheduleGroupScreen(
            onBack = { showAutoRunScreen = AutoRunScreenType.NONE }
        )
    }
    AutoRunScreenType.NONE -> {
        // 탭별 화면
    }
}
```

**변경 사항**:
1. TimeBasedAutoRunScreen에 `onNavigateToScheduleGroup` 파라미터 추가
2. LocationBasedAutoRunScreen에 `onNavigateToScheduleGroup` 파라미터 추가
3. `SCHEDULE_GROUP` 케이스 추가하여 ScheduleGroupScreen 표시

### 2.3 네비게이션 플로우

## 3. TimeBasedAutoRunScreen 확장

### 3.1 개요

TimeBasedAutoRunScreen의 TopAppBar에 시간표 관리 화면으로 이동하는 버튼을 추가했습니다.

**파일**: `app/src/main/java/com/allday/detoxy/presentation/ui/autorun/TimeBasedAutoRunScreen.kt`

### 3.2 주요 변경사항

#### 3.2.1 Import 추가

```kotlin
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Add
import androidx.compose.material.icons.filled.ArrowBack
import androidx.compose.material.icons.filled.Delete
import androidx.compose.material.icons.filled.List  // 🆕 3차 고도화
import androidx.compose.material3.*
```

**설명**: List 아이콘을 시간표 관리 버튼에 사용

**참고**: 
- 원래 문서에서는 `Icons.Default.Folder` 사용 권장
- Folder 아이콘이 Material Icons에 없어서 `Icons.Default.List` 사용
- 시간표 목록을 나타내기에 적절한 아이콘

#### 3.2.2 함수 시그니처 업데이트

**Before**:
```kotlin
@Composable
fun TimeBasedAutoRunScreen(
    onBack: () -> Unit = {},
    onNavigateToLocationBased: () -> Unit = {},
    viewModel: TimeBasedAutoRunViewModel = hiltViewModel()
)
```

**After**:
```kotlin
@Composable
fun TimeBasedAutoRunScreen(
    onBack: () -> Unit = {},
    onNavigateToLocationBased: () -> Unit = {},
    onNavigateToScheduleGroup: () -> Unit = {},  // 🆕 3차 고도화: 시간표 관리로 이동
    viewModel: TimeBasedAutoRunViewModel = hiltViewModel()
)
```

**변경 사항**:
- `onNavigateToScheduleGroup` 파라미터 추가
- Default 값 제공으로 하위 호환성 유지

#### 3.2.3 TopAppBar에 actions 추가

**Before**:
```kotlin
TopAppBar(
    title = { Text("예약설정") },
    navigationIcon = {
        IconButton(onClick = onBack) {
            Icon(
                imageVector = Icons.Default.ArrowBack,
                contentDescription = "뒤로가기"
            )
        }
    }
)
```

**After**:
```kotlin
TopAppBar(
    title = { Text("예약설정") },
    navigationIcon = {
        IconButton(onClick = onBack) {
            Icon(
                imageVector = Icons.Default.ArrowBack,
                contentDescription = "뒤로가기"
            )
        }
    },
    actions = {
        // 🆕 3차 고도화: 시간표 관리 버튼
        IconButton(onClick = onNavigateToScheduleGroup) {
            Icon(
                imageVector = Icons.Default.List,
                contentDescription = "시간표 관리"
            )
        }
    }
)
```

**변경 사항**:
- TopAppBar의 `actions` 파라미터 추가
- List 아이콘 버튼 추가
- 클릭 시 `onNavigateToScheduleGroup` 콜백 호출

## 8. 기술적 고려사항

### 8.1 아이콘 선택

**시도한 아이콘들**:
1. `Icons.Default.Folder` - ❌ 존재하지 않음 (문서 권장)
2. `Icons.Default.CalendarMonth` - ❌ 존재하지 않음 (시도)
3. `Icons.Default.List` - ✅ 최종 선택

**선택 이유**:
- Material Icons filled에서 사용 가능한 아이콘
- 시간표 목록을 나타내기에 적절
- 일관된 디자인 언어 유지

**대안**:
- `Icons.Default.Event` (캘린더 이벤트)
- `Icons.Default.ViewList` (목록 보기)
- `Icons.Default.Schedule` (스케줄)
- 이모지 사용 (📋)

### 8.2 네비게이션 패턴

**현재 구조**:
```kotlin
var showAutoRunScreen by remember { 
    mutableStateOf<AutoRunScreenType>(AutoRunScreenType.NONE) 
}

when (showAutoRunScreen) {
    AutoRunScreenType.TIME_BASED -> { /* ... */ }
    AutoRunScreenType.LOCATION_BASED -> { /* ... */ }
    AutoRunScreenType.SCHEDULE_GROUP -> { /* ... */ }
    AutoRunScreenType.NONE -> { /* 탭별 화면 */ }
}
```

**장점**:
- 단순하고 명확한 상태 관리
- Compose의 상태 호이스팅 패턴
- 전체 화면 네비게이션에 적합

**대안** (향후 고려 가능):
- Jetpack Navigation Compose
- Voyager
- Decompose

### 8.3 TopAppBar actions 위치

**Material Design 3 가이드라인**:
- actions는 TopAppBar 우측에 위치
- 최대 3개까지 권장
- 중요도 순서로 배치

**현재 구현**:
- 1개의 action (List 아이콘)
- 가장 우측에 배치
- 적절한 contentDescription 제공

## 13. 빠른 시간표 생성 기능 추가 (3차 고도화 개선)

### 13.1 개요 및 문제 발견

**사용자 피드백**:
> "일반적으로 사람은 '위치'를 선택하고 해당 위치에 따라 시간표를 작성하거나 기존에 작성된 시간표 템플릿을 이용하여 설정하면 위치기반에 따른 시간표가 구현될 것이다. 하지만 지금 구현된 구조에서는 이러한 방식이 아닌 것으로 보인다."

**문제 분석**:

- ✅ 경로 A: 기존 시간표 선택 (구현됨)

```kotlin
suspend fun createScheduleGroup(name: String, description: String?): String {
    if (name.isBlank()) {
        _errorState.value = "그룹 이름을 입력해주세요"
        throw IllegalArgumentException("그룹 이름을 입력해주세요")
    }

    try {
        _isLoading.value = true
        val scheduleGroup = ScheduleGroup(
            name = name.trim(),
            description = description?.trim()?.takeIf { it.isNotEmpty() }
        )
        repository.insert(scheduleGroup)
        return scheduleGroup.id  // 🆕 ID 반환
    } catch (e: Exception) {
        _errorState.value = "그룹 생성 실패: ${e.message}"
        throw e
    } finally {
        _isLoading.value = false
    }
}
```
