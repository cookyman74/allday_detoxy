## 기술적 구현 세부사항

### 1. ReportViewModel
```kotlin
@HiltViewModel
class ReportViewModel @Inject constructor(
    private val repository: FocusRepository
) : ViewModel() {

    private val _todaySessions = MutableStateFlow<List<FocusSession>>(emptyList())
    val todaySessions: StateFlow<List<FocusSession>> = _todaySessions.asStateFlow()

    private val _settings = MutableStateFlow(
        UserSettings(
            id = 1,
            totalPoints = 0,
            currentStreak = 0,
            lastSuccessDate = null
        )
    )
    val settings: StateFlow<UserSettings> = _settings.asStateFlow()

    init {
        loadData()
    }

    private fun loadData() {
        viewModelScope.launch {
            repository.getTodaySessions().collect { sessions ->
                _todaySessions.value = sessions
            }
        }

        viewModelScope.launch {
            repository.getSettings().collect { userSettings ->
                userSettings?.let {
                    _settings.value = it
                }
            }
        }
    }
}
```

**특징**:
- FocusRepository를 통한 데이터 접근
- Flow.collect로 실시간 데이터 업데이트 감지
- 초기 로드 시 두 개의 코루틴으로 병렬 처리
- 통계 계산을 위한 유틸리티 함수 제공

#### 통계 카드 (StatCard)
```kotlin
@Composable
fun StatCard(
    title: String,
    value: String,
    unit: String,
    icon: ImageVector,
    color: Color
) {
    Card(
        colors = CardDefaults.cardColors(
            containerColor = color.copy(alpha = 0.1f)
        )
    ) {
        Column(
            horizontalAlignment = Alignment.CenterHorizontally
        ) {
            Icon(icon, tint = color)
            Text(title)
            Row {
                Text(value, style = MaterialTheme.typography.headlineMedium)
                Text(unit, modifier = Modifier.padding(start = 4.dp))
            }
        }
    }
}
```

**특징**:
- 반투명 배경색 (alpha = 0.1f)
- 아이콘, 제목, 값, 단위 구조
- 재사용 가능한 컴포넌트

#### 세션 카드 (SessionCard)
```kotlin
@Composable
fun SessionCard(session: FocusSession) {
    Card(
        colors = CardDefaults.cardColors(
            containerColor = if (session.success) {
                Color(0xFF4CAF50).copy(alpha = 0.1f)
            } else {
                Color(0xFFFF5252).copy(alpha = 0.1f)
            }
        )
    ) {
        Row {
            Icon(
                imageVector = if (session.success) {
                    Icons.Default.CheckCircle
                } else {
                    Icons.Default.Close
                },
                tint = if (session.success) {
                    Color(0xFF4CAF50)
                } else {
                    Color(0xFFFF5252)
                }
            )
            // 세션 정보 표시
        }
    }
}
```

**특징**:
- 성공/실패에 따른 색상 변경
- SimpleDateFormat으로 시간 포맷팅
- 포인트 획득 표시 (성공 시)

### 3. UI 레이아웃 구조

```
Column (전체 화면)
├── Surface (헤더)
│   └── Text ("일일 리포트")
└── LazyColumn (스크롤 가능한 컨텐츠)
    ├── Row (통계 카드 1행)
    │   ├── StatCard (총 집중 시간)
    │   └── StatCard (성공 세션)
    ├── Row (통계 카드 2행)
    │   ├── StatCard (연속 성공)
    │   └── StatCard (총 포인트)
    ├── Card (성공률)
    │   └── LinearProgressIndicator
    ├── Text ("오늘의 세션" 헤더)
    └── items (세션 리스트)
        └── SessionCard (각 세션)
```

### 4. 색상 테마

- **Primary**: MaterialTheme 기본 색상 (헤더, 타이머 아이콘)
- **Success**: `Color(0xFF4CAF50)` (초록색 - 성공 표시)
- **Error**: `Color(0xFFFF5252)` (빨간색 - 실패 표시)
- **Warning**: `Color(0xFFFFC107)` (노란색 - 포인트, 스타)
- **Fire**: `Color(0xFFFF6B35)` (주황색 - 스트릭)

### 5. 아이콘 사용

- `Icons.Default.PlayArrow`: 총 집중 시간
- `Icons.Default.CheckCircle`: 성공 세션
- `Icons.Default.Favorite`: 연속 성공 (스트릭)
- `Icons.Default.Star`: 총 포인트
- `Icons.Default.Close`: 실패한 세션
- `Icons.Default.Info`: 빈 상태 안내

**참고**: Timer, Whatshot 등 일부 아이콘이 Material Icons에 없어서 대체 아이콘 사용

## 구현 패턴 및 Best Practices

### 1. MVVM Architecture
- **Model**: FocusSession, UserSettings (Room 엔티티)
- **View**: ReportScreen (Compose UI)
- **ViewModel**: ReportViewModel (비즈니스 로직)
- StateFlow를 통한 반응형 UI 업데이트

### 2. Dependency Injection (Hilt)
- @HiltViewModel로 ViewModel 주입
- FocusRepository 인터페이스 주입
- hiltViewModel() Compose 통합

### 3. Material Design 3
- Material3 컴포넌트 사용 (Card, Surface, NavigationBar)
- Material 색상 시스템 활용
- 일관된 spacing과 typography

### 4. Reactive Programming
- StateFlow로 상태 관리
- collectAsState()로 Compose UI 연동
- Flow.collect로 실시간 데이터베이스 변경 감지

### 5. 성능 최적화
- LazyColumn으로 긴 리스트 효율적 렌더링
- remember와 derivedStateOf 활용
- 불필요한 recomposition 방지
