## 🎯 목표

자동 실행 기능의 제어 시스템을 MVP 버전으로 구현합니다.

**주요 기능 (MVP)**:
1. 자동 실행 마스터 스위치 (전체 활성화/비활성화)
2. 일시중지 기능 (1시간/3시간/6시간/오늘 하루 중지)
3. UserSettingsRepository를 통한 상태 관리
4. AlarmManager와 Geofence에서 UserSettings 체크

**제외된 기능 (3차 고도화로 연기)**:
- 별도의 AutoRunDashboardScreen (기존 화면에 통합)

- PermissionStatusScreen (권한 현황 페이지)

### 2. 복합 체크 로직

**isAutoRunEnabled() 메서드**:
```kotlin
suspend fun isAutoRunEnabled(): Boolean {
    // 마스터 스위치 체크
    if (!getAutoRunMasterEnabled()) {
        return false
    }

    // 일시중지 체크
    val pauseUntil = getAutoRunPauseUntil()
    if (pauseUntil != null && System.currentTimeMillis() < pauseUntil) {
        return false
    }

    return true
}
```

**특징**:
- ✅ 마스터 스위치와 일시중지 복합 체크

### 3. 편의 메서드

**pauseUntilMidnight() 메서드**:
```kotlin
suspend fun pauseUntilMidnight() {
    val calendar = Calendar.getInstance().apply {
        set(Calendar.HOUR_OF_DAY, 23)
        set(Calendar.MINUTE, 59)
        set(Calendar.SECOND, 59)
        set(Calendar.MILLISECOND, 999)
    }
    setAutoRunPauseUntil(calendar.timeInMillis)
}
```

**특징**:
