 *
 * Analytics 개인정보 보호를 위해 라벨을 해시 처리합니다.

private fun hashLocationLabel(label: String): String {

#### 4.2.4 성공률 계산 로직
**자동 실행 성공률**:
```
성공률 = (auto_run_started 이벤트 수) / (auto_run_triggered 이벤트 수) × 100
```

**BigQuery SQL**:
```sql
WITH triggered AS (
  SELECT COUNT(*) AS trigger_count
  FROM `project.analytics_*.events_*`
  WHERE event_name = 'auto_run_triggered'
    AND event_timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 7 DAY)
),
started AS (
  SELECT COUNT(*) AS started_count
  FROM `project.analytics_*.events_*`
  WHERE event_name = 'auto_run_started'
    AND event_timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 7 DAY)
)
SELECT
  ROUND((started.started_count / triggered.trigger_count) * 100, 2) AS success_rate_percentage
FROM triggered, started;
```

#### 4.2.8 GPS 정확도별 성공률 분석
**목적**: GPS 정확도가 성공률에 미치는 영향 분석

**BigQuery SQL**:
```sql
WITH gps_accuracy_bins AS (
  SELECT
    CASE
      WHEN CAST((SELECT value.double_value FROM UNNEST(event_params) WHERE key = 'gps_accuracy_meters') AS FLOAT64) < 20 THEN 'HIGH'
      WHEN CAST((SELECT value.double_value FROM UNNEST(event_params) WHERE key = 'gps_accuracy_meters') AS FLOAT64) < 50 THEN 'MEDIUM'
      ELSE 'LOW'
    END AS accuracy_level,
    COUNT(*) AS started_count
  FROM `project.analytics_*.events_*`
  WHERE event_name = 'auto_run_started'
    AND (SELECT value.string_value FROM UNNEST(event_params) WHERE key = 'trigger_type') = 'LOCATION'
    AND event_timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 7 DAY)
  GROUP BY accuracy_level
)
SELECT
  accuracy_level,
  started_count,
  ROUND((started_count / SUM(started_count) OVER ()) * 100, 2) AS percentage
FROM gps_accuracy_bins
ORDER BY started_count DESC;
```

## 7. 기술적 학습 내용

### 7.1 SHA-256 해시 함수
**Kotlin 구현**:
```kotlin
private fun hashLabel(label: String): String {
    val bytes = label.toByteArray()
    val md = MessageDigest.getInstance("SHA-256")
    val digest = md.digest(bytes)
    return digest.joinToString("") { "%02x".format(it) }
}
```

**주요 특징**:
- `MessageDigest.getInstance("SHA-256")`: Java 표준 라이브러리 사용
- `toByteArray()`: 문자열을 바이트 배열로 변환
- `digest()`: SHA-256 해시 계산 (32바이트)
- `"%02x".format(it)`: 바이트를 2자리 16진수 문자열로 변환
- `joinToString("")`: 64자 hex 문자열 생성

### 7.2 BigQuery SQL for Firebase Analytics
**이벤트 파라미터 추출**:
```sql
SELECT value.string_value FROM UNNEST(event_params) WHERE key = 'trigger_type'
```

**주요 특징**:
- `UNNEST()`: 배열을 테이블로 변환
- `event_params`: Firebase Analytics 이벤트의 파라미터 배열
- `key`, `value`: 파라미터의 키-값 쌍

### 7.3 Firebase Analytics 제한 사항
- 이벤트당 최대 25개 파라미터
