## 11. 리뷰 피드백 반영 (2025-10-30 추가)

### 11.1 문제 발견

**리뷰어 지적 사항**:
> ScheduleGroupScreen과 ScheduleGroupViewModel은 현재 구조상 그룹별 연결 수(시간표/위치)를 제대로 표시하지 못합니다. 리스트 아이템에서 LaunchedEffect(group.id)로 loadLinkedTimeBasedAutoRuns() / loadLinkedLocations()를 호출하지만, ViewModel에서 이 데이터를 단일 StateFlow<List<TimeBasedAutoRun>> / StateFlow<List<LocationBasedAutoRun>>로만 들고 있고 최신 호출 값이 계속 덮어써집니다. 결국 모든 카드가 마지막으로 로딩한 그룹의 값으로 표시되므로, 그룹별 데이터를 따로 캐싱하거나 Map 기반 상태로 바꿔야 합니다.

**문제 분석**:
1. 기존 구현에서는 단일 `StateFlow<List<TimeBasedAutoRun>>`과 `StateFlow<List<LocationBasedAutoRun>>` 사용
2. `LazyColumn`의 각 아이템에서 `LaunchedEffect(group.id)`로 개별 로딩
3. 각 그룹이 로딩될 때마다 단일 StateFlow가 덮어써짐
4. 결과적으로 마지막에 로딩된 그룹의 데이터만 모든 카드에 표시됨

### 11.2 해결 방법

#### 11.2.1 Repository에 카운트 조회 메서드 추가

**파일**: `app/src/main/java/com/allday/detoxy/domain/repository/ScheduleGroupRepository.kt`

```kotlin
/**
 * 특정 그룹에 연결된 시간 기반 자동 실행 개수 조회
 */
suspend fun getLinkedTimeBasedAutoRunCount(scheduleGroupId: String): Int

/**
 * 특정 그룹에 연결된 위치 기반 자동 실행 개수 조회
 */
suspend fun getLinkedLocationCount(scheduleGroupId: String): Int
```

**구현** (`ScheduleGroupRepositoryImpl.kt`):
```kotlin
override suspend fun getLinkedTimeBasedAutoRunCount(scheduleGroupId: String): Int {
    return timeBasedAutoRunDao.getByScheduleGroup(scheduleGroupId).size
```
