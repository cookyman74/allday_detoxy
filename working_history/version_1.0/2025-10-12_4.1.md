### 2. PreferenceManager 온보딩 플래그 추가

**파일**: `app/src/main/java/com/allday/detoxy/core/utils/PreferenceManager.kt`

#### 추가된 메서드
```kotlin
// 온보딩 완료 여부 확인
fun isOnboardingCompleted(): Boolean
```

#### 플래그 관리 전략

- 두 플래그를 분리하여 온보딩과 권한 체크를 독립적으로 관리

### 3. MainActivity 온보딩 플로우 통합 (4.1.2)

**파일**: `app/src/main/java/com/allday/detoxy/MainActivity.kt`

#### 변경 사항

**이전 로직**:
```kotlin
if (showPermissionCheck) {
    PermissionCheckScreen(...)
} else {
    MainScreenWithNavigation()
}
```

**새로운 로직**:
```kotlin
when {
    // 1. 온보딩 미완료 -> 환영 화면
    showOnboarding -> WelcomeScreen(...)
    
    // 2. 온보딩 완료 후 권한 체크 -> 권한 안내 화면
    showPermissionCheck -> PermissionCheckScreen(...)
    
    // 3. 모두 완료 -> 메인 화면
    else -> MainScreenWithNavigation()
}
```

#### 상태 전환 플로우
```
앱 최초 실행
    ↓
[WelcomeScreen]
    ↓ (시작하기 버튼 클릭)
    ↓ setOnboardingCompleted()
    ↓
[PermissionCheckScreen]
    ↓ (모든 필수 권한 허용)
    ↓ setFirstLaunchCompleted()
    ↓
[MainScreenWithNavigation]
```

#### 재실행 시 동작
- 온보딩 완료 + 권한 설정 완료 → 바로 MainScreen
- 온보딩 완료 + 권한 미설정 → PermissionCheckScreen
- 온보딩 미완료 → WelcomeScreen
