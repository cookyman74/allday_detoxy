# 작업 기록: UX 변경 작업 (v8.1)

**작업 일시**: 2025-12-11  
**작업 범위**: ScheduleGroupCard UI 개선 (토글 복원 + 일시중지 버튼 재배치)

## 작업 목적

v8에서 도입한 `ScheduleControlButton`의 UX 문제를 개선합니다.

### 문제점
- 타이틀 옆에 토글+드롭다운 통합 버튼이 있어 UI가 복잡하고 발견성이 낮음
- 롱프레스 동작은 사용자가 발견하기 어려움
- 기존 토글 스위치 대비 학습 비용 발생

### 해결 방안 (방안 A 채택)
- 헤더: 토글 스위치로 복원 (활성/비활성 즉시 제어)
- 시간 섹션: 일시중지 버튼 추가 (드롭다운 메뉴로 기간 선택)

### 관련 PRD
- [04_버튼역할변경_prd.md](../../docs/04_버튼역할변경_prd.md)

## UX 분석

### 방안 비교

| 항목 | 방안 A (채택) | 방안 B |
|------|--------------|--------|
| 헤더 | 토글 스위치 | 일시중지 버튼 (롱프레스로 활성화) |

### 채택 이유

1. **발견성**: 토글 스위치는 모든 사용자에게 익숙
2. **학습 비용**: 롱프레스는 추가 학습 필요
3. **Android UX 가이드라인**: 토글은 ON/OFF 표준 컴포넌트

## 변경 사항

### 1. ScheduleGroupCard.kt 수정

**파일**: `app/src/main/java/com/allday/detoxy/presentation/ui/autorun/components/ScheduleGroupCard.kt`

#### 헤더 영역: ScheduleControlButton → Switch

```kotlin
// 변경 전 (v8)
ScheduleControlButton(
    controlState = controlState,
    pauseUntil = pauseUntil,
    onStateChange = onStateChange,
    onPause = onPause
)

// 변경 후 (v8.1)
val isEnabled = controlState != ScheduleGroupControlState.INACTIVE
Switch(
    checked = isEnabled,
    onCheckedChange = { checked ->
        if (checked) {
            onStateChange(ScheduleGroupControlState.ACTIVE)
        } else {
            onStateChange(ScheduleGroupControlState.INACTIVE)
        }
    }
)
```

#### 시간 섹션: 일시중지 버튼 추가

```kotlin
// v8.1: 일시중지 버튼 (활성 상태일 때만 표시)
if (controlState != ScheduleGroupControlState.INACTIVE) {
    if (controlState == ScheduleGroupControlState.PAUSED) {
        // PAUSED: 해제 버튼 + 남은 시간 표시
        OutlinedButton(onClick = { onStateChange(ACTIVE) }) {
            Text("해제 (${formatRemainingTime(pauseUntil)})")
        }
    } else {
        // ACTIVE: 일시중지 버튼 + 드롭다운 메뉴
        OutlinedButton(onClick = { showPauseDropdown = true }) {
            Text("일시중지")
        }
        DropdownMenu(expanded = showPauseDropdown) {
            PauseDuration.entries.forEach { duration ->
                DropdownMenuItem(onClick = { onPause(duration) })
            }
        }
    }
}
```

#### 유틸 함수 추가

```kotlin
private fun formatRemainingTime(pauseUntil: Long?): String {
    if (pauseUntil == null) return ""
    
    val now = System.currentTimeMillis()
    val diff = pauseUntil - now
    
    if (diff <= 0) return "곧 해제"
    
    val hours = diff / (1000 * 60 * 60)
    val minutes = (diff % (1000 * 60 * 60)) / (1000 * 60)
    
    return when {
        hours > 0 && minutes > 0 -> "${hours}시간 ${minutes}분"
        hours > 0 -> "${hours}시간"
        minutes > 0 -> "${minutes}분"
        else -> "1분 미만"
    }
}
```
