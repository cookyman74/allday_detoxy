#### 주요 기능

##### AppCategory.kt
```kotlin
enum class AppCategory {
    SNS,           // 소셜 네트워크 (Instagram, Facebook, Twitter 등)
    MESSENGER,     // 메신저 (KakaoTalk, WhatsApp, Telegram 등)
    WEB,           // 웹 브라우저 (Chrome, Samsung Browser, Firefox 등)
    VIDEO_SHORTS,  // 영상 & 쇼츠 (YouTube, TikTok, Netflix 등)
    OTHER;         // 기타 앱 (Catch-All)
    
    fun getDisplayName(): String  // "SNS", "메신저", "Web 서핑", "영상 & 쇼츠", "기타 앱"
    fun getIcon(): String         // 📱, 💬, 🌐, 🎬, 📦
    fun getRiskDescription(): String   // 중독 위험도 설명
    fun getRecoveryEffect(): String    // 회복 효과 설명
}
```

**특징**:
- 디톡시 회복 관점의 메서드 추가 (`getRiskDescription`, `getRecoveryEffect`)
- UI 표시용 아이콘 및 이름 제공

##### AppCategoryMapper.kt
```kotlin
object AppCategoryMapper {
    // 1. 카테고리별 패키지 매핑 (40개 앱)
    private val categoryMap = mapOf(
        AppCategory.SNS to setOf(9개 앱),
        AppCategory.MESSENGER to setOf(11개 앱),
        AppCategory.WEB to setOf(8개 앱),
        AppCategory.VIDEO_SHORTS to setOf(12개 앱)
    )
    
    // 2. 시스템 앱 필터링
    private val systemApps = setOf(10개 앱)
    
    // 3. 차단 로직
    fun isBlocked(
        packageName: String,
        enabledCategories: Set<AppCategory>,
        otherAppsEnabled: Boolean
    ): Boolean
    
    // 4. 프리셋 정의 (디톡시 제어 관점)
    enum class DetoxyPreset {
        COMPLETE_BLOCK,   // 완전 차단 (회복 초기 1-2주)
```

**특징**:

### 2. FocusAccessibilityService 동적 차단 목록 연동

#### 수정된 파일
- **`app/src/main/java/com/allday/detoxy/service/accessibility/FocusAccessibilityService.kt`**

#### 주요 변경사항

##### Before (하드코딩)
```kotlin
private val BLOCKED_APPS = setOf(
    "com.instagram.android",
    "com.zhiliaoapp.musically",
    "com.google.android.youtube",
    "com.facebook.katana",
    "com.android.chrome"
)

if (packageName in BLOCKED_APPS) {
    navigateToHome()
}
```

##### After (동적 차단)
```kotlin
@Volatile
var enabledCategories: Set<AppCategory> = setOf(
    AppCategory.SNS,
    AppCategory.WEB,
    AppCategory.VIDEO_SHORTS
)

@Volatile
var otherAppsEnabled: Boolean = false

private fun isAppBlocked(packageName: String): Boolean {
    return AppCategoryMapper.isBlocked(
        packageName = packageName,
        enabledCategories = enabledCategories,
        otherAppsEnabled = otherAppsEnabled
    )
}

private fun handleBlockedApp(packageName: String, category: AppCategory?) {
    // 차단 이벤트 로깅 (TODO: Analytics 연동)
    Log.i(TAG, "🚫 App blocked: $packageName (${category?.getDisplayName() ?: "기타 앱"})")
    navigateToHome()
}
```

#### 새로운 API
```kotlin
// 차단 설정 업데이트 (TimerViewModel에서 호출 예정)
fun updateBlockSettings(categories: Set<AppCategory>, blockOtherApps: Boolean)

// 프리셋 빠른 적용
fun applyPreset(preset: AppCategoryMapper.DetoxyPreset)
```

#### 특징
- 하드코딩된 5개 앱 → 동적 카테고리 기반 40+ 앱 차단
- 카테고리 정보 로깅으로 디버깅 개선
- 프리셋 지원으로 사용자 편의성 증가

## 💡 구현 하이라이트

### 1. 디톡시 회복 관점 통합
모든 enum, 메서드, 메시지가 **"디지털 중독 진단 및 회복"** 관점으로 통일:
- 카테고리: 중독 위험도 + 회복 효과 설명
- 프리셋: 회복 단계별 권장 (초기/중기/후기)
- DND 안내: 디톡시 효과 강조

### 2. 확장성 고려
- 카테고리 추가 용이: `AppCategory` enum에 추가만 하면 됨
- 프리셋 확장 가능: `DetoxyPreset` enum 추가
- Analytics 파라미터: `toAnalyticsParams()` 메서드로 일관성 유지

### 3. 성능 최적화
- 기본 모니터링 범위: 카테고리 앱만 (40개)
- 기타 앱 차단 시에만 전체 앱 모니터링
- 시스템 앱 자동 필터링

### 4. 개인정보 보호
- 패키지명: 로컬 DB 전용
- Analytics: 카테고리만 전송
- `MonitoringPolicy`에 명확한 가이드라인
