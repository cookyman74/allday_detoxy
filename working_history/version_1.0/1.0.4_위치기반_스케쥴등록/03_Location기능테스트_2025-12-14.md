# 03. Location 기능 고도화 (정확도 표기 및 지도 연동)

**작성일**: 2025-12-14  
**작성자**: Antigravity

---

## 1. 작업 개요
위치 등록 및 수정 시 사용자가 선택한 위치의 정확도를 확인하고, 외부 지도 앱을 통해 실제 위치를 검증할 수 있는 기능을 추가했습니다.

## 2. 변경 내역

### 2.1 정확도 표기 (`AddLocationAutoRunDialog.kt`)
- `LocationSettingsStep`의 위치 정보 카드 내에 정확도 Chip을 추가했습니다.
- **동작 방식**: 현재 위치 검색 결과(`LocationInfo`에 `accuracy` 존재)인 경우에만 "오차 ±XXm" 형태로 표시됩니다.
- 기존에 저장된 위치 수정 시에는 정확도 정보가 없으므로 표시되지 않습니다.

### 2.2 지도 앱 연동 (공통)
- `AddLocationAutoRunDialog.kt`와 `LocationEditDialog.kt`에 "지도에서 확인" 버튼을 추가했습니다.
- **Intent**: `Intent.ACTION_VIEW`와 `geo:lat,lng?q=lat,lng(Label)` URI 스킴을 사용했습니다.
- **예외 처리**: 지도 앱이 설치되어 있지 않은 경우 Toast 메시지로 안내합니다.

## 3. 검증 결과
- **UI**: 위치 정보 카드 내에 버튼과 Chip이 조화롭게 배치됨.
- **기능**:
    - 정확도 Chip: 신규 위치 검색 시 정상 표시 확인.
    - 지도 버튼: 클릭 시 구글 지도 등 설치된 지도 앱 실행 확인.

## 4. 특이사항
- 외부 앱이 없는 경우에 대한 예외 처리는 `try-catch` 블록으로 안전하게 구현했습니다.
