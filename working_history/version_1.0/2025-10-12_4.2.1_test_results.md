✅ **핵심 메서드 확인**:
```kotlin
fun enableDnd(): Boolean {
    // INTERRUPTION_FILTER_ALARMS: 알람만 허용, 모든 알림 차단
    notificationManager?.setInterruptionFilter(
        NotificationManager.INTERRUPTION_FILTER_ALARMS
    )
}

fun disableDnd(): Boolean {
    // INTERRUPTION_FILTER_ALL: 모든 알림 허용
    notificationManager?.setInterruptionFilter(
        NotificationManager.INTERRUPTION_FILTER_ALL
    )
}

fun hasNotificationPolicyAccess(): Boolean {
    // Android 6.0 (API 23) 이상에서만 지원
    return notificationManager?.isNotificationPolicyAccessGranted ?: false
}

fun isDndEnabled(): Boolean {
    val currentFilter = notificationManager?.currentInterruptionFilter
    return currentFilter != NotificationManager.INTERRUPTION_FILTER_ALL
}
```

### 2.5 Repository 구현 확인

**파일**: `app/src/main/java/com/allday/detoxy/data/repository/FocusRepositoryImpl.kt`

```kotlin
override suspend fun startSession(session: FocusSession) {
    sessionDao.insert(session)
}

override suspend fun endSession(sessionId: String, success: Boolean, endTime: Long) {
    val session = sessionDao.getSessionById(sessionId)
    session.collect { existingSession ->
        existingSession?.let {
            val updatedSession = it.copy(
                endTime = endTime,
                success = success
            )
            sessionDao.update(updatedSession)
        }
    }
}

override fun getTodaySessions(): Flow<List<FocusSession>> {
    return sessionDao.getTodaySessions()
}
```

✅ **결과**: Repository가 DAO를 올바르게 사용하여 세션 CRUD 작업 수행
