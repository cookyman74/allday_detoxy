## 📝 작업 개요
리퀴드 글래스 디자인 시스템의 핵심이 되는 기본 컴포넌트들을 구현했습니다.
`Haze` 라이브러리를 기반으로 한 `Modifier.liquidGlass`와 이를 포함하는 컨테이너인 `GlassScaffold`를 작성하여, 이후 화면 구현 시 손쉽게 효과를 적용할 수 있도록 만들었습니다.

## 🛠 작업 내용

### 1. Modifier.liquidGlass 구현
`app/src/main/java/com/allday/detoxy/presentation/ui/component/GlassModifier.kt`

가장 핵심이 되는 Modifier로, 다음 기능을 캡슐화했습니다:
- **Realtime Blur**: `hazeChild`를 사용하여 배경을 흐리게 처리.
- **Translucency**: 반투명 `glassTint` 적용.
- **Border**: 1dp 두께의 미세한 그라데이션 테두리.
- **Shadow**: 부드러운 그림자 효과.
- **Clip**: 둥근 모서리(RoundedCorner) 적용.

```kotlin
// 사용 예시
Box(
    modifier = Modifier
        .size(200.dp)
        .liquidGlass() // 기본값 사용
) {
    Text("Glass Effect")
}
```

### 2. GlassScaffold 구현
`app/src/main/java/com/allday/detoxy/presentation/ui/component/GlassScaffold.kt`

Glass 효과가 작동하려면 반드시 배경이 `Haze Source`로 지정되어야 합니다. `GlassScaffold`는 이를 자동화합니다.
- Mesh Gradient 배경을 자동으로 깔아줍니다 (다크/라이트 모드 대응).
- `HazeState`를 생성하고 `LocalHazeState`로 제공합니다.
- 전체 컨텐츠 영역을 `haze` 소스로 등록합니다.

### 3. GlassSurface 구현
Material3의 Surface 대용으로 사용할 수 있는 래퍼 컴포넌트입니다.

## ⚠️ 기술적 이슈 및 해결

### Haze 라이브러리 API 변경 대응
- **이슈**: `HazeStyle`의 `tint` 파라미터가 `Color`가 아닌 `HazeTint` 타입을 요구함.
- **해결**: `tint = HazeTint(glassTint)`로 래핑하여 전달.
- **이슈**: `hazeChild`의 `shape` 파라미터가 Deprecated됨.
- **해결**: `hazeChild`에서 `shape`를 제거하고, Modifier 체인 마지막에 `.clip(shape)`를 명시적으로 호출하여 해결.

### Compose 컴파일 에러
- **이슈**: `MaterialTheme.colorScheme.isLight` 참조 불가.
- **해결**: `!isSystemInDarkTheme()` 함수를 사용하여 테마 모드 감지.

## 📸 검증
- `./gradlew compileDebugKotlin` 빌드 성공.
- Haze 라이브러리와 Compose Modifier 간의 연결이 정상적으로 컴파일됨을 확인.
