## 📝 작업 개요
앱의 핵심 화면인 `TimerScreen`과 `ScheduleGroupScreen`에 Glassmorphism 디자인을 본격적으로 적용했습니다. 단순한 배경 흐림을 넘어, 컨텐츠 그룹핑을 위한 "투명 패널" 개념을 도입하여 대시보드 형태의 UI를 완성했습니다.

## 🛠 작업 내용

### 1. TimerScreen (홈 화면)
`app/src/main/java/com/allday/detoxy/presentation/ui/timer/TimerScreen.kt`

- **Glass Panel 도입**: 기존의 산재된 UI 요소(도넛 차트, 프리셋 버튼, 시작 버튼 등)를 하나의 커다란 `GlassSurface`로 감싸서, 마치 유리 판 위에 조작부가 떠 있는 듯한 느낌을 주었습니다.
- **IDLE 상태**: 타이머 설정 화면 전체를 Glass 패널로 감싸 시각적 일관성을 부여했습니다.
- **RUNNING 상태**: 실행 중인 타이머 디스플레이와 포기 버튼을 별도의 Glass 패널로 중앙 배치하여 집중도를 높였습니다.
- **Transparency**: 알파값 `0.3f`를 적용하여 뒤쪽의 Mesh Gradient 배경이 은은하게 비치도록 했습니다.

### 2. ScheduleGroupScreen (스케줄 관리)
`app/src/main/java/com/allday/detoxy/presentation/ui/autorun/components/ScheduleGroupCard.kt`

- **Card 교체**: 기존의 Material3 `Card`를 `GlassSurface`로 전면 교체했습니다.
- **상태별 Tinting**:
  - 기존에는 불투명한 `containerColor`로 상태(ACTIVE/PAUSED/INACTIVE)를 구분했으나, Glass 디자인에 맞게 반투명 `tint` 색상으로 변경했습니다.
  - **ACTIVE**: 녹색 계열 (`primaryContainer`, alpha 0.5)
  - **PAUSED**: 주황 계열 (`tertiaryContainer`, alpha 0.5)
  - **INACTIVE**: 회색 계열 (`surfaceVariant`, alpha 0.5)
- **리스트 가시성**: 여러 개의 Glass Card가 리스트로 나열될 때, 각각의 블러 효과가 배경과 어우러져 고급스러운 깊이감을 형성합니다.

## ✨ 디자인 포인트

- **계층 구조(Hierachy)**: 
  - Level 0: Mesh Gradient 배경 (최하단)
  - Level 1: GlassScaffold (전체 블러)
  - Level 2: GlassSurface Card (컨텐츠 패널, 약한 블러 + 틴트)
  - Level 3: Text & Icons (최상단)
- **가독성 확보**: Glass 효과로 배경이 복잡해질 수 있음을 고려하여, 컨텐츠가 올라가는 패널에는 적절한 Tint(색조)를 주어 텍스트 가독성을 확보했습니다.

## 📸 검증
- `./gradlew compileDebugKotlin` 빌드 성공.
- `ScheduleGroupCard`의 리스트 스크롤 시 `Haze` 라이브러리의 실시간 블러 성능 확인 필요 (일반적으로 최신 기기에서는 60fps 유지 가능).
