## 2. 수정 내용

### 2.1 엔티티 스키마 업데이트

#### 2.1.1 LocationBasedAutoRun.address nullable 변경
- **위치**: §2.1.1 신규 엔티티 정의
- **변경 전**: `val address: String`
- **변경 후**: `val address: String?`
- **사유**: 장소 검색 실패 또는 좌표만 있는 경우 허용 (리뷰 반영)
- **참조**: `02_advanced_room_migration_strategy.md` §2.2

### 2.2 UI 개선 사항 추가

#### 2.2.1 정확 알람 권한 경고 배너
- **위치**: §3.1.1 TimeBasedAutoRunScreen 레이아웃
- **추가 내용**:
  - 정확 알람 권한 없을 때 화면 상단에 경고 배너 표시
  - "정확한 실행을 위해 권한을 허용하세요" 메시지
  - "권한 설정하기" 버튼
  - WorkManager fallback 사용 중임을 안내
- **참조**: `02_advanced_wireframe_spec.md` §2.1

#### 2.2.2 템플릿 최대 개수 초과 안내
- **위치**: §3.1.1 템플릿 선택 버튼
- **추가 내용**: 최대 10개 제한 초과 시 안내 다이얼로그
- **참조**: `02_advanced_wireframe_spec.md` §2.4

#### 2.2.3 위치 기반 오류 상태 UI
- **위치**: §4.1.1 LocationBasedAutoRunScreen 레이아웃
- **추가 내용**:
  - Play Services 미지원 상태 안내
  - 위치 권한 거부 상태 안내
  - 위치 서비스 OFF 상태 안내
- **참조**: `02_advanced_wireframe_spec.md` §3.1

#### 2.2.4 배터리 영향 표시 수정
- **위치**: §4.1.1 배터리 영향 안내 카드
- **변경 전**: "배터리 소모 예상 3~5%/일"
- **변경 후**: "배터리 영향 최소 수준" (구체적 수치는 실측 후 업데이트)
- **사유**: 실제 측정 근거 없이 정량 수치 표시는 신뢰도 저하 우려
- **참조**: `02_advanced_wireframe_spec.md` §3.1

### 2.3 Analytics 이벤트 수정

#### 2.3.1 개인정보 보호 강화
- **위치**: §6.2.1 AnalyticsHelper 확장
- **변경 내용**:
  - `logCustomPresetCreated(name: String, ...)` → `logCustomPresetCreated(nameLength: Int, ...)`
  - 사용자가 입력한 이름 대신 길이만 로깅
- **참조**: `02_advanced_analytics_schema.md` §1.2

#### 2.3.2 권한 요청 이벤트 파라미터 추가
- **위치**: §6.2.1 AnalyticsHelper 확장
- **추가 내용**: `logPermissionExactAlarmRequested(granted: Boolean, wentToSettings: Boolean)`
  - `wentToSettings` 파라미터로 설정 화면 이동 여부 추적
- **참조**: `02_advanced_analytics_schema.md` §5.1

### 2.4 QA 시나리오 확장

#### 2.4.1 DST/심야 시간 테스트 추가
- **위치**: §7.3.4.1 (신규 섹션)
- **추가 내용**:

  - 심야(0시 부근) 알람 테스트
- **참조**: `02_advanced_qa_devices.md` §2.4
