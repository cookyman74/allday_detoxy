# 작업 기록: 접근성 서비스 충돌 및 크래시 수정 (최종)

**작업 일시**: 2025-11-30
**작업 범위**: 접근성 서비스 (`FocusAccessibilityService`) 안정성 강화

## 문제 상황

**증상**:
- USB 연결 상태 등 특정 상황에서 "이 서비스가 제대로 작동하지 않습니다" 메시지 발생.
- 접근성 서비스가 강제로 비활성화됨.

**원인 분석**:
1.  **예외 처리 부족**: `onAccessibilityEvent`에서 `Exception`만 catch하고 있어, `Error` 또는 `Throwable` 계열의 심각한 오류(예: OOM, StackOverflow, LinkageError 등)를 놓칠 가능성.
2.  **과도한 로깅 (ANR 가능성)**: `onAccessibilityEvent`는 매우 빈번하게 호출되는 콜백임에도 불구하고, 매 호출마다 `Log.d`를 수행. 특히 USB 디버깅 연결 시 로그 버퍼 오버헤드로 인해 메인 스레드 부하가 가중되어 ANR(Application Not Responding)을 유발하고, 이로 인해 시스템이 서비스를 강제 종료했을 가능성 높음.

## 수정 내용

### 1. `FocusAccessibilityService` 안정성 강화
- **파일**: `app/src/main/java/com/allday/detoxy/service/accessibility/FocusAccessibilityService.kt`
- **변경 사항**:
    - **예외 처리 범위 확대**: `catch (e: Exception)` → `catch (e: Throwable)`로 변경하여 모든 런타임 오류를 방어.
    - **로깅 최적화**: 빈번하게 호출되는 `onAccessibilityEvent` 내의 불필요한 `Log.d` 제거 및 조건부 로깅 적용.
    - **Lifecycle 로깅 추가**: `onUnbind` 오버라이드하여 서비스 종료 시점 추적 용이성 확보.

```kotlin
// 변경 전
catch (e: Exception) {
    Log.e(TAG, "❌ Error in onAccessibilityEvent: ${e.message}", e)
}

// 변경 후
catch (e: Throwable) {
    Log.e(TAG, "❌ Error in onAccessibilityEvent: ${e.message}")
}
```
