## 기술적 구현 세부사항

### 1. MainScreenWithNavigation 구조

```kotlin
@Composable
fun MainScreenWithNavigation() {
    var selectedTab by remember { mutableStateOf(0) }

    Scaffold(
        modifier = Modifier.fillMaxSize(),
        bottomBar = {
            NavigationBar {
                NavigationBarItem(
                    selected = selectedTab == 0,
                    onClick = { selectedTab = 0 },
                    icon = {
                        Icon(
                            imageVector = Icons.Default.PlayArrow,
                            contentDescription = null
                        )
                    },
                    label = { Text("타이머") }
                )
                NavigationBarItem(
                    selected = selectedTab == 1,
                    onClick = { selectedTab = 1 },
                    icon = {
                        Icon(
                            imageVector = Icons.Default.Star,
                            contentDescription = null
                        )
                    },
                    label = { Text("리포트") }
                )
            }
        }
    ) { innerPadding ->
        Box(
            modifier = Modifier
                .fillMaxSize()
                .padding(innerPadding)
        ) {
            when (selectedTab) {
                0 -> TimerScreen()
                1 -> ReportScreen()
            }
        }
    }
}
```

**특징**:
- Scaffold 구조: Material3의 표준 화면 레이아웃
- bottomBar: 하단 네비게이션 바 배치
- innerPadding: Scaffold가 제공하는 padding으로 네비게이션 바와 겹치지 않도록 처리
- when 표현식: 선택된 탭에 따라 화면 전환

### 2. 상태 관리

```kotlin
var selectedTab by remember { mutableStateOf(0) }
```

**특징**:
- remember로 recomposition 시 상태 유지
- mutableStateOf로 상태 변경 감지 및 UI 업데이트
- Int 타입 (0: 타이머, 1: 리포트)
- onClick 핸들러에서 상태 변경

### 3. NavigationBarItem 구성

```kotlin
NavigationBarItem(
    selected = selectedTab == 0,  // 선택 상태
    onClick = { selectedTab = 0 },  // 클릭 핸들러
    icon = { Icon(...) },  // 아이콘
    label = { Text("타이머") }  // 레이블
)
```

**특징**:
- selected: 현재 탭이 선택되었는지 여부 (Material3 스타일 자동 적용)
- onClick: 탭 클릭 시 상태 변경
- icon: Vector 아이콘 표시
- label: 텍스트 레이블 표시

### 5. 화면 전환 로직

**특징**:

## 구현 패턴 및 Best Practices

### 1. Compose Navigation 패턴
- **간단한 탭 네비게이션**: remember + mutableStateOf + when 표현식
- **복잡한 네비게이션**: Jetpack Navigation Compose (1차 릴리스 시 고려)

### 2. Material3 디자인 시스템
- NavigationBar: Material3 표준 하단 네비게이션
- NavigationBarItem: 선택 상태 자동 스타일 적용
- Icon + Label: 아이콘과 텍스트 조합

### 3. State Management
- remember: Recomposition 시 상태 보존
- mutableStateOf: 상태 변경 감지 및 UI 자동 업데이트
- by 위임: 간결한 getter/setter

### 4. Scaffold 레이아웃
- topBar, bottomBar, content 영역 자동 관리
- innerPadding으로 content 영역이 네비게이션 바와 겹치지 않도록 처리
- Material Design 표준 레이아웃 구조

### 5. MVP 범위 준수
- 타이머, 리포트 2개 탭만 구현
- 설정, 상점, 친구 탭은 1차 릴리스로 연기
- 핵심 기능에 집중

### 6. 아이콘 일관성
- ReportScreen에서 사용 중인 아이콘과 통일
- PlayArrow: 타이머/집중 시간 의미
- Star: 리포트/성과 의미

## 주요 교훈 및 문서화

### 1. Material Icons 제한사항
- Compose에서 모든 Material Icons가 지원되지 않음
- Timer, Assessment, AccessTime, BarChart 등 일부 누락
- 대안: 지원되는 아이콘 중 의미가 유사한 것 사용
- 확인 방법: Icons.Default.* 자동완성 확인

### 2. NavigationBar vs NavigationRail
- NavigationBar: 하단 네비게이션 (모바일 표준)
- NavigationRail: 측면 네비게이션 (태블릿/데스크톱)
- MVP는 모바일 우선이므로 NavigationBar 선택

### 3. Scaffold의 innerPadding
- bottomBar 사용 시 반드시 innerPadding 적용
- content가 네비게이션 바와 겹치지 않도록 보장
- Modifier.padding(innerPadding) 필수

### 4. 상태 관리 위치
- 현재: MainScreenWithNavigation 내부 (remember + mutableStateOf)
- 향후: ViewModel로 이동 고려 (화면 재생성 시 탭 상태 보존)
- MVP 범위에서는 현재 방식으로 충분

### 5. 화면 전환 성능
- when 표현식: 즉시 화면 전환 (recomposition)
- 두 화면 모두 매번 새로 생성 (상태 초기화)
- 성능 이슈 없음 (TimerScreen, ReportScreen 모두 경량)
