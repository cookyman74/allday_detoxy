### 2. 차단 카테고리별 패키지 리스트 초안 정리
**문서**: `docs/01_advanced_app_category_mapping.md`

#### 카테고리 정의 (5개)
| 카테고리 | 앱 수 | 대표 앱 | 기본값 |
|----------|-------|---------|--------|
| SNS | 9개 | Instagram, Facebook, Twitter | ON |
| 메신저 & 커뮤니케이션 | 11개 | KakaoTalk, WhatsApp, Telegram | OFF |
| Web 서핑 | 8개 | Chrome, Samsung Internet, Firefox | ON |
| 영상 & 쇼츠 | 12개 | YouTube, TikTok, Netflix | ON |
| 기타 앱 | Catch-All | (명시되지 않은 모든 앱) | ON |

**총 40개 앱 (중복 제거 전)**

#### 중복 처리 전략
- Instagram, Facebook이 SNS와 영상 카테고리 모두에 포함
- `Set` 자료구조로 중복 자동 제거
- 사용자가 둘 중 하나만 선택해도 차단됨

#### 데이터 구조
```kotlin
enum class AppCategory {
    SNS,
    MESSENGER,
    WEB,
    VIDEO_SHORTS,
    OTHER
}

object AppCategoryMapper {
    private val categoryMap: Map<AppCategory, Set<String>>
    fun getCategoryByPackage(packageName: String): AppCategory?
    fun getPackagesByCategory(category: AppCategory): Set<String>
    fun isBlocked(packageName: String, enabledCategories: Set<AppCategory>, otherAppsEnabled: Boolean): Boolean
}
```

#### 프리셋 정의
- **전체 차단**: SNS, Web, 영상, 기타 ON / 메신저 OFF
- **집중**: SNS, 영상 ON / Web, 메신저, 기타 OFF
- **완화**: 영상만 ON / 나머지 OFF

#### 향후 확장
- 2차 고도화: 게임 (9개 앱), 커머스 (7개 앱) 별도 카테고리화
- 사용자 피드백 기반 패키지 추가
- 화이트리스트 기능 (업무/생산성 앱 예외 처리)

### 3. Room 마이그레이션 전략 수립
**문서**: `docs/01_advanced_room_migration_strategy.md`

#### 마이그레이션 로드맵
```
v1 (MVP 현재)
  ↓
v2 (Week 2A)  ← FocusSession 확장 + FocusInterruption 추가
  ↓
v3 (Week 2B)  ← FocusDistraction, DetoxyRoutineLog, FocusSettings 추가
```

#### v1 → v2 마이그레이션 (Week 2A)
**변경사항**:
1. **FocusSession 필드 추가**
   - `interruptedSeconds: Int` (중도 포기 시 경과 시간)
   - `primaryDistractionCategory: String?` (주요 방해요인)
   - `giveUpReason: String?` (포기 사유)

2. **FocusInterruption 엔티티 신규**
   - 세션 중 차단 이벤트 로그
   - sessionId (FK), timestamp, packageName, category

**마이그레이션 코드**:
```kotlin
val MIGRATION_1_2 = object : Migration(1, 2) {
    override fun migrate(database: SupportSQLiteDatabase) {
        // ALTER TABLE focus_sessions ADD COLUMN...
        // CREATE TABLE focus_interruptions...
        // CREATE INDEX...
    }
}
```

#### v2 → v3 마이그레이션 (Week 2B)
**변경사항**:
1. **FocusDistraction** (허용/차단 이벤트 전체)
2. **DetoxyRoutineLog** (루틴 실행/실패 기록)
3. **FocusSettings** (카테고리별 차단 설정)

**최종 엔티티 (v3)**:
- FocusSession (확장됨)
- UserSettings (기존)
- FocusInterruption (v2)
- FocusDistraction (v3)
- DetoxyRoutineLog (v3)
- FocusSettings (v3)

**총 6개 테이블**

#### DAO 업데이트
- FocusSessionDao: `getGiveUpSessions()`, `getTopDistractionCategories()`
- FocusInterruptionDao (신규): `getBySession()`, `getTop3Distractions()`
- FocusDistractionDao (신규): `getByTimeRange()`, `getAvoidanceRate()`
- FocusSettingsDao (신규): `applyPreset()`, 카테고리별 토글 메서드

#### 테스트 전략
- 단위 테스트: `MigrationTest` (MigrationTestHelper 사용)
- 통합 테스트: v1 → v2 → v3 전체 경로 검증
- 데이터 백필: 기존 세션 `interruptedSeconds = 0` 초기화
- 롤백: 개발 중 `.fallbackToDestructiveMigration()` (프로덕션 제거)

#### 주의사항
- 외래 키 제약 조건 (CASCADE, SET NULL)
- 인덱스 최적화 (sessionId, timestamp)
- exportSchema = true (스키마 변경 추적)

### 4. 로깅 스키마 설계
**문서**: `docs/01_advanced_analytics_schema.md`

#### 이벤트 분류
- **집중모드 설정**: `focus_settings_*` (4개 이벤트)
- **리포트**: `report_*` (6개 이벤트)
- **세션**: `session_*` (기존 + 2개 확장)
- **권한**: `permission_*` (3개 이벤트)

**총 15개 이벤트**

#### 주요 이벤트

**1. focus_settings_saved**
```kotlin
FirebaseAnalytics.logEvent("focus_settings_saved") {
    param("preset", "full_block")
    param("sns_enabled", true)
    param("messenger_enabled", false)
    param("web_enabled", true)
    param("video_enabled", true)
    param("other_enabled", true)
    param("total_enabled_count", 4)
}
```

**2. session_interrupted** (신규)
```kotlin
FirebaseAnalytics.logEvent("session_interrupted") {
    param("session_id", sessionId)
    param("category", "sns")  // 차단된 앱 카테고리
    param("elapsed_seconds", 600)
}
```

**3. report_risk_index_calculated** (신규)
```kotlin
FirebaseAnalytics.logEvent("report_risk_index_calculated") {
    param("risk_index", 32)  // 0-100
    param("risk_level", "low")  // low/medium/high
}
```

#### 사용자 속성 (User Properties)
- `total_sessions`: 총 세션 수
- `current_streak`: 현재 스트릭
- `preferred_preset`: 선호 프리셋
- `avg_focus_minutes`: 평균 집중 시간

#### Funnel 분석
1. **온보딩 Funnel**: app_open → onboarding_start → permission_granted(s) → onboarding_complete
2. **설정 Funnel**: focus_settings_open → preset_selected → category_toggle → saved
3. **세션 Funnel**: session_started → session_interrupted(s) → completed/give_up → report_view

#### 핵심 지표 (KPI)
- **DAU**: `app_open` 사용자 수
- **세션 시작률**: `session_started` / DAU
- **카테고리 활용률**: 각 카테고리 활성화 비율
- **집중 성공률**: `session_completed` / `session_started`
- **리포트 조회율**: `report_view_daily` / DAU

#### 구현
```kotlin
object AnalyticsHelper {
    fun logFocusSettingsSaved(...)
    fun logSessionInterrupted(...)
    fun logRiskIndexCalculated(...)
}
```

#### 프라이버시
- ✅ 익명화된 데이터만 수집
- ✅ 사용자 동의 획득 (프라이버시 정책)
- ✅ 데이터 삭제 요청 대응 가능
- ❌ 개인정보 (이메일, 전화번호) 수집 금지
