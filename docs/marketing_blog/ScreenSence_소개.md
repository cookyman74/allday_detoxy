# ScreenSence 소개

## 1. ScreenSence란?
ScreenSence는 스마트폰과 태블릿 사용 습관을 건강하게 관리해 주는 집중 모드 앱입니다. 시간·위치·행동 패턴을 기반으로 사용자가 원하는 순간에 방해 요소를 차단하고, 집중 세션을 성공적으로 마칠 수 있도록 돕습니다.

## 2. 주요 기능
| 기능 | 설명 |
| --- | --- |
| 자동 실행 스케줄 | 시간대 혹은 위치를 지정해 두면 해당 조건이 만족될 때 집중 모드가 자동으로 시작됩니다. |
| 집중 타이머 & 통계 | 세션 성공/실패 기록, 총 집중 시간, 성공률 등을 시각화하여 동기 부여에 도움을 줍니다. |
| 방해요인 분석 | 어떤 앱·카테고리가 집중을 방해하는지 분석하여 맞춤형 코칭 메시지를 제공합니다. |
| 할 일 & 메모 (프리미엄) | 각 스케줄에 할 일과 메모를 추가해 “왜 집중해야 하는지”를 기억하고, 완료율도 추적할 수 있습니다. |
| 프리미엄 코칭 | 위험 지수, 회복 추세, 자동 실행 성공률 등을 종합 분석해 사용자별 행동 가이드를 제공합니다. |

## 3. 사용 흐름
1. **스케줄 만들기**: 원하는 시간·위치·카테고리를 선택하고, 필요하다면 메모/할 일을 추가합니다.
2. **자동 실행**: 조건을 만족하면 집중 모드가 자동으로 시작되고, 사용자는 알림/오버레이를 통해 상태를 확인합니다.
3. **세션 종료**: 성공/실패 여부를 저장하고, 할 일 체크·코칭 피드백을 제공합니다.
4. **리포트 확인**: 리포트 탭에서 주간 성공률, 집중 시간, 방해 요인 Top3 등을 확인하며 루틴을 개선합니다.

## 4. 프리미엄 혜택
- 할 일·메모 기반 집중 스케줄
- 자동 실행 성공률·GPS 정확도 등 고급 통계
- 디톡시 코치 추천(위험 지수 기반 행동 가이드)
- Beta/Trial 기간 동안 무료 체험 가능, 이후 월/연 구독으로 이용

## 5. 왜 ScreenSence인가?
- **자동화된 집중 루틴**: 반복적인 차단 설정 없이도 사용자의 맥락에 맞춰 알아서 실행됩니다.
- **데이터 기반 피드백**: 성공률·방해요인·회복 추세 등 다양한 지표로 “왜 실패했는지”를 파악할 수 있습니다.
- **개인 맞춤 코칭**: 위험 단계별 메시지와 행동 리스트로 실질적인 행동 교정이 가능하도록 설계했습니다.

## 6. 시작하기
1. 앱 설치 후 필수 권한(알림, 접근성, 위치 등)을 안내에 따라 허용합니다.
2. 첫 집중 스케줄을 만들고, “베타 무료” 혹은 Free Trial로 프리미엄 기능을 체험해 보세요.
3. 리포트 탭을 주기적으로 확인하면서 성공률·완료율을 확인하고, 추천되는 코칭 액션을 적용해 보세요.
