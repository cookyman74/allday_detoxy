개인정보처리방침

최종 업데이트: 2025년 11월 14일
적용일: 2025년 11월 14일

1. 개인정보처리방침의 의의

ScreenSence(이하 "본 앱")는 사용자의 개인정보 보호를 매우 중요하게 생각합니다. 본 개인정보처리방침은 본 앱이 수집하는 정보, 그 정보의 사용 방법, 그리고 사용자의 권리에 대해 설명합니다.

본 앱을 사용함으로써 사용자는 본 개인정보처리방침에 동의하는 것으로 간주됩니다.

2. 수집하는 정보

2.1 자동으로 수집하는 정보

2.1.1 기기 정보

  • 기기 모델 및 제조사: 앱 호환성 및 최적화를 위해 수집됩니다.
  • 운영체제 버전: Android 버전 정보
  • 앱 버전: 설치된 앱의 버전 정보
  • 고유 기기 식별자: Firebase Analytics를 통한 익명화된 기기 ID

2.1.2 사용 데이터 (익명화)

  • 앱 사용 통계: 타이머 시작/종료, 세션 완료율 등 기능 사용 패턴
  • 이벤트 로그: Firebase Analytics를 통한 익명화된 사용 이벤트
    • 수집되는 이벤트: 타이머 시작, 세션 완료, 앱 차단 횟수 등
    • 개인을 식별할 수 있는 정보는 포함되지 않습니다

2.1.3 크래시 및 오류 정보

  • 크래시 리포트: Firebase Crashlytics를 통한 앱 오류 및 크래시 정보
    • 스택 트레이스, 오류 메시지, 기기 정보
    • 개인정보는 포함되지 않으며, 오류 해결을 위해서만 사용됩니다

2.2 사용자가 제공하는 정보

2.2.1 위치 정보 (선택적)

중요: 위치 정보는 기기에만 저장되며, 서버로 전송되지 않습니다
  • 위치 기반 자동 실행 기능 사용 시: 사용자가 등록한 장소의 위치 정보
  • 위치 정보는 Geofencing API를 통한 자동 실행 기능에만 사용됩니다
  • 사용자는 언제든지 위치 기반 자동 실행을 삭제하여 위치 정보를 제거할 수 있습니다

2.2.2 앱 사용 통계 (선택적)

  • UsageStats 권한: 더 정확한 앱 사용 통계를 위해 선택적으로 요청됩니다
  • 사용자가 명시적으로 허용한 경우에만 수집됩니다
  • 수집된 정보는 기기에만 저장되며, 서버로 전송되지 않습니다

2.3 결제 및 구독 정보 (향후 추가 예정)

향후 유료 기능이 추가될 경우, 다음 정보가 수집될 수 있습니다:

  • Google Play 결제 정보: Google Play Billing을 통한 구매 내역
    • 본 앱은 직접 결제 정보를 수집하지 않으며, Google Play의 결제 시스템을 통해 처리됩니다
    • 결제 정보는 Google의 개인정보처리방침에 따라 처리됩니다
  • 구독 상태: 유료 구독 활성화 여부 및 만료일
    • 구독 관리를 위해 기기에만 저장됩니다
  • 프리미엄 기능 사용 기록: 유료 기능 사용 통계 (익명화)
현재 버전: 본 앱은 현재 무료로 제공되며, 결제 정보를 수집하지 않습니다.

2.4 수집하지 않는 정보

본 앱은 다음 정보를 수집하지 않습니다:

  • 이름, 이메일 주소, 전화번호 등 개인 식별 정보
  • 연락처 정보
  • SMS 또는 메시지 내용
  • 사진, 동영상, 파일 등 미디어 콘텐츠
  • 다른 앱의 사용자 데이터
  • 신용카드 번호, 계좌 정보 등 직접적인 금융 정보 (Google Play 결제 시스템을 통해서만 처리)

3. 정보 사용 목적

수집된 정보는 다음 목적으로만 사용됩니다:

3.1 서비스 제공

  • 집중 타이머 기능 제공
  • 앱 차단 기능 제공
  • 위치 기반 자동 실행 기능 제공 (사용자가 선택한 경우)
  • 시간 기반 자동 실행 기능 제공

3.2 서비스 개선

  • 앱 안정성 향상 (크래시 리포트 분석)
  • 기능 사용 패턴 분석을 통한 UX 개선
  • 버그 수정 및 성능 최적화

3.3 분석 및 통계

  • Firebase Analytics를 통한 익명화된 사용 통계
  • 기능 사용률 측정
  • 사용자 행동 패턴 분석 (개인 식별 불가능)

4. 제3자 서비스

본 앱은 다음 제3자 서비스를 사용합니다:

4.1 Google Firebase

  • Firebase Analytics: 익명화된 사용 통계 수집
    • 데이터는 Google의 개인정보처리방침에 따라 처리됩니다
    • Google 개인정보처리방침
  • Firebase Crashlytics: 앱 오류 및 크래시 리포트 수집
    • 오류 해결을 위한 기술적 정보만 수집됩니다
    • 개인정보는 포함되지 않습니다

4.2 Google Play Services

  • Location Services: 위치 기반 자동 실행 기능 제공
  • 위치 정보는 기기에만 저장되며, Google 서버로 전송되지 않습니다

4.3 Google Play Billing (향후 추가 예정)

  • 결제 처리: 유료 기능 구매 및 구독 관리
  • 결제 정보는 Google Play의 안전한 결제 시스템을 통해 처리됩니다
  • 본 앱은 신용카드 번호 등 직접적인 결제 정보를 수집하지 않습니다
  • Google Play 결제 정책

5. 데이터 보관 및 보안

5.1 데이터 보관 기간

  • 로컬 저장 데이터: 앱 삭제 시 자동으로 삭제됩니다
  • Firebase Analytics 데이터: Google의 데이터 보관 정책에 따릅니다 (일반적으로 14개월)
  • Firebase Crashlytics 데이터: 90일간 보관됩니다

5.2 데이터 보안

  • 모든 데이터는 암호화되어 전송됩니다 (HTTPS)
  • 로컬 저장 데이터는 Android의 보안 저장소를 사용합니다
  • 위치 정보는 기기에만 저장되며, 서버로 전송되지 않습니다

5.3 데이터 공유

  • 본 앱은 사용자의 개인정보를 제3자에게 판매하거나 공유하지 않습니다
  • 법적 요구사항이 있는 경우를 제외하고, 사용자 동의 없이 정보를 공유하지 않습니다
  • 유료 기능 관련 결제 정보는 Google Play를 통해서만 처리되며, 본 앱은 직접 접근하지 않습니다

6. 사용자 권리

사용자는 다음 권리를 가집니다:

6.1 정보 접근 및 수정

  • 앱 설정에서 수집된 데이터를 확인할 수 있습니다
  • 위치 기반 자동 실행을 삭제하여 위치 정보를 제거할 수 있습니다

6.2 데이터 삭제

  • 앱을 삭제하면 모든 로컬 저장 데이터가 삭제됩니다
  • Firebase Analytics 데이터 삭제를 원하는 경우, 앱 설정에서 Analytics 수집을 비활성화할 수 있습니다

6.3 권한 철회

언제든지 앱 설정에서 다음 권한을 철회할 수 있습니다:

  • 위치 권한
  • UsageStats 권한
  • 접근성 서비스 권한
  • 다른 앱 위에 표시 권한
  • 방해금지 모드 권한

참고: 일부 권한을 철회하면 해당 기능을 사용할 수 없게 됩니다.

7. 권한 사용 목적

본 앱은 다음 권한을 사용합니다:

7.1 필수 권한

접근성 서비스 (BIND_ACCESSIBILITY_SERVICE)

  • 목적: 집중 타이머 실행 중 사용자가 설정한 앱을 차단하기 위해 필요합니다
  • 사용 방법: 사용자가 설정한 앱 목록에 접근하여 차단합니다
  • 수집 정보: 차단된 앱의 패키지 이름 (기기에만 저장)

다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW)

  • 목적: 집중 타이머 실행 중 잠금 화면을 표시하기 위해 필요합니다
  • 사용 방법: 차단된 앱을 열려고 할 때 안내 화면을 표시합니다

방해금지 모드 (ACCESS_NOTIFICATION_POLICY)

  • 목적: 집중 타이머 실행 중 알림을 차단하기 위해 필요합니다
  • 사용 방법: 타이머 실행 중 방해금지 모드를 활성화합니다

7.2 선택적 권한

위치 정보 (ACCESS_FINE_LOCATION, ACCESS_BACKGROUND_LOCATION)

  • 목적: 위치 기반 자동 실행 기능을 제공하기 위해 필요합니다
  • 사용 방법: 사용자가 설정한 장소에 도착하면 자동으로 타이머를 시작합니다
  • 중요: 위치 정보는 기기에만 저장되며, 서버로 전송되지 않습니다
  • 철회: 언제든지 위치 권한을 철회할 수 있으며, 위치 기반 자동 실행 기능만 사용할 수 없게 됩니다

정확 알람 (SCHEDULE_EXACT_ALARM)

  • 목적: 시간 기반 자동 실행 기능의 정확성을 보장하기 위해 필요합니다
  • 사용 방법: 사용자가 설정한 시간에 정확하게 타이머를 시작합니다
  • 철회: 언제든지 정확 알람 권한을 철회할 수 있으며, 시간 기반 자동 실행 기능만 사용할 수 없게 됩니다

앱 사용 통계 (PACKAGE_USAGE_STATS)

  • 목적: 더 정확한 앱 사용 통계를 제공하기 위해 선택적으로 요청됩니다
  • 사용 방법: 앱 사용 시간 및 차단 횟수를 정확하게 측정합니다
  • 수집 정보: 앱 사용 시간 통계 (기기에만 저장)
  • 철회: 언제든지 UsageStats 권한을 철회할 수 있으며, 통계 기능만 제한됩니다

8. 아동의 개인정보 보호

본 앱은 만 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 13세 미만 아동이 본 앱을 사용하는 경우, 보호자의 동의가 필요합니다.

11. 추가 정보

11.1 데이터 수집 비활성화

사용자는 다음 방법으로 데이터 수집을 제한할 수 있습니다:

  1. Firebase Analytics 비활성화:
    • 앱 설정에서 Analytics 수집을 비활성화할 수 있습니다 (향후 업데이트 예정)
  2. 위치 정보 삭제:
    • 위치 기반 자동 실행 설정을 삭제하면 위치 정보가 제거됩니다
  3. 권한 철회:
    • Android 설정 > 앱 > ScreenSence > 권한에서 권한을 철회할 수 있습니다

11.2 국제 사용자

본 앱은 전 세계 사용자를 대상으로 하며, 데이터는 대한민국 및 Google의 서버에 저장될 수 있습니다. 데이터는 해당 지역의 개인정보 보호 법률에 따라 처리됩니다.

11.3 유료 기능 및 구독 (향후 추가 예정)

향후 유료 기능이 추가될 경우:

  • 구독 관리: Google Play Console을 통해 구독을 관리할 수 있습니다
  • 환불 정책: Google Play의 표준 환불 정책이 적용됩니다
  • 구독 취소: 언제든지 Google Play 설정에서 구독을 취소할 수 있습니다
  • 데이터 보관: 구독 취소 후에도 기존에 수집된 익명화된 사용 통계는 정책에 따라 보관됩니다
