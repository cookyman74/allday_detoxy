# 2차 고도화 화면 와이어프레임 스펙

**버전**: v0.6  
**작성일**: 2025-10-20  
**기준 문서**: [2차 고도화 PRD](./02_advanced_autosetting_prd.md)  
**참조**: [1차 고도화 Wireframe](./01_advanced_wireframe_spec.md)

---

## 1. 개요

이 문서는 2차 고도화 기능의 UI/UX 상세 스펙을 정의합니다.

### 1.1 주요 화면
1. **시간 기반 자동 실행 설정** (TimeBasedAutoRunScreen)
2. **위치 기반 자동 실행 설정** (LocationBasedAutoRunScreen)
3. **커스텀 타이머 화면** (도넛 그래프 포함)
4. **자동 실행 대시보드** (AutoRunDashboardScreen)
5. **자동 실행 이력** (AutoRunHistoryScreen)
6. **권한 현황 페이지** (PermissionStatusScreen)
7. **월간 달력 성과 뷰** (MonthlyCalendarScreen)

### 1.2 디자인 원칙
- **일관성**: Material 3 디자인 시스템 준수
- **접근성**: 최소 터치 영역 48dp, 명확한 색상 대비
- **피드백**: 모든 액션에 즉각적인 시각적/햅틱 피드백
- **안내**: 복잡한 권한/설정은 단계별 가이드 제공

### 4.2 DonutTimerPicker 상세 스펙

**Canvas 구조**:
```
┌────────────────────────────────┐
│                                │
│     (배경 원 - 회색)          │
│      ⭕────────────┐           │
│     /              \           │
│    |     45분      |           │
│     \              /           │
│      \___________/             │
│         (선택 영역 - 초록색)   │
│                                │
│  • 시간 눈금 (5분, 15분, ...)  │
│  • 드래그 핸들 (원형, 큰 터치) │
│                                │
└────────────────────────────────┘
```

**인터랙션**:
- **드래그**: 핸들을 드래그하여 각도 조정 → 시간 변경
- **탭**: 원 위 임의 지점 탭 → 즉시 해당 시간으로 변경
- **햅틱**: 5분 단위로 변경 시 진동 피드백
- **애니메이션**: 시간 변경 시 부드러운 arc 애니메이션

**시간 범위**:
- 최소: 5분
- 최대: 180분 (3시간)
- 스텝: 5분

**시각적 요소**:
- 배경 원: LightGray, alpha 0.3, strokeWidth 24dp
- 선택 영역: Primary Color (초록), strokeWidth 24dp
- 중앙 텍스트: `"45분"`, DisplayLarge
- 눈금: 5분(작은 점), 15분/30분/60분(큰 선)
