## ✅ 완료된 작업

### 1. locale_config.xml 생성
- **파일**: `app/src/main/res/xml/locale_config.xml`
- **내용**: 5개 언어 지원 설정 (ko, en, es, ja, zh-Hans)

```xml
<?xml version="1.0" encoding="utf-8"?>
<locale-config xmlns:android="http://schemas.android.com/apk/res/android">
    <locale android:name="ko"/>           <!-- 한국어 (기본) -->
    <locale android:name="en"/>           <!-- 영어 -->
    <locale android:name="es"/>           <!-- 스페인어 -->
    <locale android:name="ja"/>           <!-- 일본어 -->
    <locale android:name="zh-Hans"/>      <!-- 중국어 간체 -->
</locale-config>
```

### 2. AndroidManifest.xml 업데이트
- **파일**: `app/src/main/AndroidManifest.xml`
- **변경**: `<application>` 태그에 `android:localeConfig="@xml/locale_config"` 속성 추가
- Android 13+ 시스템 설정에서 앱별 언어 설정 연동 활성화

### 3. AppLocaleManager 유틸리티 생성
- **파일**: `app/src/main/java/com/allday/detoxy/core/locale/AppLocaleManager.kt`
- **기능**:
  - `setAppLocale(languageTag: String?)` - 앱 언어 설정 (AppCompatDelegate 기반)
  - `getAppLocale(): String?` - 현재 앱 언어 조회
  - `getSystemPrimaryLocale(): Locale` - 시스템 1순위 로케일 조회
  - `getCurrentLanguageTag(): String` - 현재 사용 중인 언어 태그
  - `findSupportedLanguage(languageTag: String?)` - 지원 언어 enum 조회
  - `getAllSupportedLanguages()` - 모든 지원 언어 목록

- **SupportedLanguage Enum**:
  - `SYSTEM` - 시스템 기본값
  - `KOREAN` - 한국어 (ko)
  - `ENGLISH` - 영어 (en)
  - `SPANISH` - 스페인어 (es)
  - `JAPANESE` - 일본어 (ja)
  - `CHINESE_SIMPLIFIED` - 중국어 간체 (zh-Hans)

### 4. 리소스 폴더 생성
- **생성된 폴더**:
  - `app/src/main/res/values-en/strings.xml`
  - `app/src/main/res/values-es/strings.xml`
  - `app/src/main/res/values-ja/strings.xml`
  - `app/src/main/res/values-b+zh+Hans/strings.xml`
- 각 파일에 빈 `<resources>` 태그로 초기화

### 5. AppCompat 의존성 추가
- **파일**: `gradle/libs.versions.toml`
  - `appcompat = "1.6.1"` 버전 추가
  - `androidx-appcompat` 라이브러리 정의 추가
- **파일**: `app/build.gradle.kts`
  - `implementation(libs.androidx.appcompat)` 추가
- **이유**: `AppCompatDelegate.setApplicationLocales()` API 사용을 위해 필요
