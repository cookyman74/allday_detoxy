## 🔧 기술적 수정 사항

### 포맷 파라미터 경고 해결

**문제**: `coach_high_risk_message` 문자열에서 다중 `%s` 파라미터로 인한 빌드 경고

**해결**: 모든 언어 파일에 `formatted="false"` 속성 추가

```xml
<!-- Before -->
<string name="coach_high_risk_message">%s%s\n...</string>

<!-- After -->
<string name="coach_high_risk_message" formatted="false">%s%s\n...</string>
```

**적용 파일**:
- `values/strings.xml`
- `values-en/strings.xml`
- `values-es/strings.xml`
- `values-ja/strings.xml`
- `values-b+zh+Hans/strings.xml`
