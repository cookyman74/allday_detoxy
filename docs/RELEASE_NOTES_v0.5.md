## 🎯 주요 업데이트

### 1. 디톡시 제어 설정 (신규) 🆕

**당신만의 디톡시 규칙을 만들어보세요!**

이제 어떤 앱을 차단할지 직접 선택할 수 있습니다.

#### ✨ 주요 기능

- **카테고리별 앱 차단 설정**
  - 📱 SNS (Instagram, Facebook, X 등)
  - 💬 메신저 (카카오톡, 텔레그램 등)
  - 🎬 동영상 (YouTube, Netflix, Tving 등)
  - 🌐 웹 (Chrome, Samsung Internet 등)
  - 📦 기타 앱

- **3가지 추천 프리셋**
  - **완전 차단**: 모든 카테고리 차단 (극도 집중)
  - **표준 디톡시**: SNS + 동영상 차단 (권장)
  - **완화**: 메신저 허용 (업무/학습용)

- **메신저 긴급 연락 옵션**
  - 중요한 메시지를 놓치지 않도록
  - 메신저 차단 시에도 긴급 연락은 가능

### 2. 리포트 고도화 (신규) 📊

**당신의 디톡시 상태를 한눈에 확인하세요!**

#### 🔴 디톡시 위험 지수 (0-100)

스마트폰 과다 사용 위험도를 3단계로 진단합니다.

- **회복 중 (0-33)**: 초록색 - 안정적인 디톡시 진행
- **주의 필요 (34-66)**: 주황색 - 주의가 필요한 상태
- **고위험 (67-100)**: 빨강색 - 즉각적인 개입 필요

**위험 지수 산식** (4가지 요소):
- 실패율 (40%)
- 연속 실패 패널티 (25%)
- 포기 시점 (20%)
- 차단 빈도 (15%)

#### 📈 회복률 추세

일별 회복률을 그래프로 시각화합니다.

- 최근 7일간 일별 회복률
- 주간 변화량 (↗️ 개선 / → 안정 / ↘️ 하락)
- 성공 세션 수 기반 계산

#### 🎯 방해요인 Top 3

어떤 앱이 당신을 가장 방해했는지 확인하세요.

- 카테고리별 차단 횟수 및 비율
- 순위별 색상 구분 (1위: 빨강, 2위: 주황, 3위: 노랑)
- 총 차단 횟수 표시

#### 💡 디톡시 코치 추천

위험 지수에 따라 맞춤형 행동 제안을 받으세요.

- 위험 단계별 차별화된 메시지
- 우선순위별 행동 제안 (높음/중간/낮음)
- "전체 보기"로 상세 조언 확인

## 🔧 기술 개선 사항

### 데이터베이스 업그레이드

- **Room v1→v2→v3 마이그레이션** 자동 진행
- 신규 테이블:
  - `focus_interruptions`: 차단 이벤트 기록
  - `focus_distractions`: 허용/차단 이벤트 전체

  - `focus_settings`: 디톡시 제어 설정
