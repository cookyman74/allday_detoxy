## 1. 리뷰 의견 요약

### 1.1 핵심 문제점
**"예약설정이 설정 화면 아래 숨어있어 발견성이 낮고, 핵심 기능인데 옵션처럼 인식될 위험이 있음"**

**현재 정보 구조** (2025-11-03 기준):
```
하단 탭 3개: [타이머] [리포트] [설정]
                                   ↓
                     DetoxyControlSettingsScreen
                     ├─ 프리셋 선택 (완전/표준/완화)
                     ├─ 카테고리별 토글 (SNS, 메신저 등)
                     ├─ 권한 상태 (DND, 접근성, 오버레이)
                     ├─ 📍 예약설정 섹션 ← 여기에 숨어있음!
                     │   └─ [설정하기] → ScheduleGroupScreen
                     └─ 디톡시 루틴
```

**문제점**:
1. **깊이 (Depth) 문제**: 설정 탭 → 스크롤 → 예약설정 섹션 → 클릭 (최소 3단계)
2. **혼재 (Mix) 문제**: 일반 설정(권한, 프리셋)과 핵심 기능(예약설정)이 동일 레벨
3. **인식 (Perception) 문제**: "설정의 일부"로 인식 → "옵션"처럼 느껴짐
4. **반복 사용성 (Frequent Use)**: 스케줄 수정 시마다 깊은 depth 진입 필요

### 1.2 리뷰 권장 사항
1. **정보 구조 재조정**: 예약설정을 독립 섹션으로 승격
2. **내비게이션 재배치**: 하단 탭 또는 상단에 "스케줄" 탭 신설
3. **홈/대시보드 강화**: 홈 화면에 "다음 예약", "오늘의 루틴" 카드 추가
4. **문구 & 분류 수정**: "예약설정" → "자동 실행" 또는 "루틴 관리"

    val scheduleGroups by viewModel.scheduleGroups.collectAsState()
    val activeGroup by viewModel.activeGroup.collectAsState()

    Scaffold(
        topBar = {

                title = { Text("스케줄") }

        floatingActionButton = {
            FloatingActionButton(onClick = { showCreateDialog = true }) {
                Icon(Icons.Default.Add, "시간표 추가")
            }
        }
    ) { paddingValues ->
        LazyColumn(
            modifier = Modifier
                .fillMaxSize()
                .padding(paddingValues)
                .padding(horizontal = 16.dp),
            verticalArrangement = Arrangement.spacedBy(16.dp)
        ) {
            // Header
            item {
                Spacer(Modifier.height(8.dp))
            }
            
            // 🆕 1. 활성 스케줄 카드
            if (activeGroup != null) {
                item {
                    ActiveScheduleSummaryCard(
                        group = activeGroup!!,
                        onClick = { onNavigateToDetail(activeGroup!!.id) }
                    )
                }
            }
            
            // 🆕 2. 다음 예약 카드
            item {
                NextScheduleSummaryCard(
                    viewModel = viewModel
                )
            }
            
            // 3. 시간표 목록 헤더
            item {
                Text(
                    text = "나의 시간표",
                    style = MaterialTheme.typography.titleLarge,
                    fontWeight = FontWeight.Bold
                )
            }

            if (scheduleGroups.isEmpty()) {
                item {
                    EmptyScheduleState(
                        onCreateClick = { showCreateDialog = true }
                    )
                }
            } else {
                items(scheduleGroups) { group ->
                    ScheduleSummaryCard(
                        group = group,
                        isActive = group.id == activeGroup?.id,
                        onClick = { onNavigateToDetail(group.id) },
                        viewModel = viewModel
                    )
                }
            }
            
            // Footer
            item {
                Spacer(Modifier.height(80.dp))  // FAB 여유 공간
            }
        }
    }
    
    // 시간표 생성 다이얼로그
    if (showCreateDialog) {
        QuickCreateScheduleDialog(
            onDismiss = { showCreateDialog = false },
            onConfirm = { name, mode, data ->
                // ... 생성 로직 (기존과 동일)

            },
            locationLabel = ""
        )
    }

    group: ScheduleGroup,
    isActive: Boolean,
    onClick: () -> Unit,
    viewModel: ScheduleGroupViewModel
) {
    val linkedLocations by viewModel.getLinkedLocations(group.id).collectAsState(initial = emptyList())
    val timeSlotCount by viewModel.getTimeBasedAutoRuns(group.id)

        modifier = Modifier.fillMaxWidth(),
        onClick = onClick,
        colors = CardDefaults.cardColors(
            containerColor = if (isActive) {
                MaterialTheme.colorScheme.primaryContainer.copy(alpha = 0.3f)
            } else {
                MaterialTheme.colorScheme.surfaceVariant
            }
        )
    ) {
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .padding(16.dp),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Column(modifier = Modifier.weight(1f)) {
                Text(
                    text = group.name,
                    style = MaterialTheme.typography.titleMedium,
                    fontWeight = FontWeight.Bold
                )
                Spacer(Modifier.height(4.dp))
                
                // 시간대 개수
                Text(
                    text = "$timeSlotCount개 시간대",

                    )
                }
            }
            
            if (isActive) {
                Badge {

                }
            }
        }
    }
