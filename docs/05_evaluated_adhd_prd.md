# 5차 고도화 개발 계획: Evaluated ADHD Support – Enhancement Plan 

## 1. 배경 & 목표
- 현재 앱은 집중 세션 기록, 자동 실행(시간·위치 기반) 관리, 사용자 알림 기능을 제공하지만 **ADHD 관련 자가 평가**에 필요한 정량/정성 데이터가 부족함.
- 목표: 앱 사용자가 개인의 집중 패턴과 방해 요인을 스스로 이해하고, 상담 전 참고용 자료로 활용할 수 있도록 **추가 데이터 수집 및 리포트 기능**을 제공한다.
- 범위: 의료용/진단용이 아님을 명확히 고지하며, 자가 관찰 수준의 정보를 제공한다.

## 2. 현황 요약
| 영역 | 현재 구현 | 부족한 부분 |
|------|-----------|-------------|
| 세션 컨텍스트 | 시간/차단 프리셋/라벨 정도만 저장 | 감정 상태, 목표 유형, 환경 정보 부재 |
| 집중 유지 데이터 | 세션 성공/실패만 기록 | 중단 원인, 집중도 변동, 회복 전략 정보 없음 |
| After-care | 자동 실행 로그 기록 (성공/실패) | 회복 전략/휴식 여부, 루틴 준수 데이터 없음 |
| 리포트 | 기본 통계 (성공률) 수준 | ADHD 특성 참고용 지표 및 그래프 미제공 |

## 3. 요구사항
### 3.1 최소 입력 기반 데이터 수집
> 사용자 자유 입력 없이 앱 사용 중 자동으로 수집/추론 가능한 항목에 집중한다.

1. **세션 준비 & 실행**
   - 알람이 울린 시점 대비 실제 시작까지의 지연(초)  
     → “시작 미루기” 경향 파악
   - 자동 실행 vs 사용자가 수동으로 실행했는지 여부
   - 알람 후 **스누즈/건너뛰기** 횟수 및 시간
2. **세션 진행 중 이벤트**
   - 세션 도중 앱이 **백그라운드로 이동한 횟수와 시간**(집중 이탈 추정)  
     *(UsageStatsManager/ActivityLifecycle 활용)*
   - 세션 강제 종료 / 중도 취소 비율
   - AutoRunLog 기반: STARTED, SKIPPED, FAILED 사유(권한, 타이머 실행 중 등)
3. **세션 후 결과**
   - 목표 지속 시간 대비 실제 수행 시간
   - 연속 성공/실패 스트릭
   - 하루/주간 누적 집중 시간, 자동 실행 성공률
4. **재시도 패턴**
   - 동일 시간대 자동 실행 알람을 몇 번이나 재시도 했는지
   - 자동 시작 딜레이 후 실제로 타이머가 시작되었는지 여부
5. **간접 루틴 데이터(선택 기능)**
   - 기상·취침 알람과의 간단한 연동(선택 허용 시 UsageStats 활용)  
     → 수면 패턴과 집중 성공률을 간접 비교

### 3.2 리포트 / 인사이트
1. **일·주간 요약**
   - 평균 시작 지연시간, 스누즈 비율, 실패 사유 Top 3
   - 시간대별/요일별 성공률 히트맵
2. **집중 유지 지표**
   - 세션당 백그라운드 전환 횟수(예: “평균 2.3회 화면 이탈”)
   - 중도 취소/실패 시각 클러스터링 (오전 vs 오후)
3. **재시도 & 루틴 인사이트**
   - 알람 재시도 횟수 vs 성공률(“3회 이상 미룬 세션은 성공률 20%↓”)
   - 자동 시작 딜레이 후 실제 자동 시작 비율
4. **누적 변동 그래프**
   - 7일/30일 이동 평균 성공률, 총 집중 시간
   - 스누즈/건너뛰기 추세
5. **PDF/이미지 요약 내보내기**
   - 위 지표를 한 페이지에 정리, 상담 전 공유 가능
6. **주의 문구**
   - “본 리포트는 자가 관찰용 참고 자료이며, 의료 진단이 아닙니다.”

### 3.3 알림 & UX 업데이트
- 알람 울리고 일정 시간 경과 시 “시작을 잊으셨나요?” 푸시(시작 지연 데이터 확보)
- 세션 중 복귀 유도 알림 (백그라운드 전환 감지 시)
- 리포트 화면에서 데이터 수집 항목 및 비식별화 안내

### 3.4 개인정보 & 환경 고려
- 민감 정보(감정, 생활 습관) 수집 동의 팝업 추가
- 데이터 암호화 / 익명화 옵션 제공 (예: 리포트 공유 시 개인 식별 숨기기)

## 4. 구현 계획
| 단계 | 기간 | 주요 작업 | 산출물 |
|------|------|-----------|--------|
| 1단계: 이벤트 계측 | Week 1 | Alarm/세션 라이프사이클에 지연·스누즈·백그라운드 이벤트 로깅 추가 | 확장된 AutoRunLog, Usage 이벤트 수집 코드 |
| 2단계: 데이터 적재/집계 | Week 2 | Room/로그 스키마 보강 (필요 시 뷰·인덱스 추가), 주간 집계 UseCase 구현 | Repository & UseCase 업데이트 |
| 3단계: 리포트 UI/Export | Week 3 | 일·주간 리포트 화면, 히트맵/트렌드 그래프, PDF/이미지 Export | Compose 리포트, Export 모듈 |
| 4단계: QA & 안내 | Week 4 | 통합 테스트, 개인정보 비고지 문구/옵션, 사용자 가이드 | QA 체크리스트, 사용 가이드 |

## 5. 기술 요소
- **Storage**: 기존 Room + AutoRunLog 확장, 필요 시 DB View/Index
- **Event Tracking**: ProcessLifecycleOwner, UsageStatsManager(선택), AlarmManager hooks
- **Analytics**: 이동 평균, 히트맵 계산, 재시도/성공률 간 단순 비교
- **Visualization**: Compose Charts 또는 MPAndroidChart
- **Export**: PDFDocument/ShareSheet 기반 요약 Export

## 6. 리스크 & 완화 전략
| 리스크 | 영향 | 대응 |
|--------|------|------|
| 이벤트 계측 누락/부정확 | 리포트 품질 저하 | QA에서 알람 → 실행 → snooze 등 시나리오 검증 |
| 민감 정보 수집 | 개인정보 우려 | 동의 팝업, 익명화/삭제 기능 제공 |
| 분석 로직 정확도 한계 | 오해 유발 | “참고용” 안내, 절대값 대신 추세 중심 |
| 데이터 마이그레이션 | 기존 사용자 데이터 손상 | Migration 테스트, 백업 안내 |

## 7. 오픈 이슈 / 추후 검토
- 집중도 샘플링 빈도(15분 기본, 사용자 설정 가능 여부)
- 루틴 항목 커스터마이즈 기능
- 상담용 공유 시 이메일/메신저 공유 자동화 가능성
- ADHD 전문 콘텐츠(자원 링크) 제공 여부

## 8. 문서 & QA 체크리스트
1. 집중도·컨텍스트 데이터가 정상 저장/동기화 되는지
2. 리포트 화면에서 모든 그래프/통계가 올바르게 반영되는지
3. PDF Export 파일 열기/공유 테스트
4. DataStore/Rooм 마이그레이션 테스트
5. 개인정보 동의/철회 플로우 동작 확인

## 9. 릴리스 노트 초안
- “ADHD 집중 패턴 자가 평가 기능(β)” 추가
  - 세션 시작/중간/종료 기록 강화
  - 방해 요인 및 회복 전략 효과 파악
  - 루틴 체크와 집중 성공률 비교
  - 주간 자가 체크 추세 그래프 제공
  - PDF 상담 자료 내보내기

> **주의**: 본 기능은 자가 모니터링을 위한 참고용이며, ADHD 진단이나 의료 상담을 대체하지 않습니다.
