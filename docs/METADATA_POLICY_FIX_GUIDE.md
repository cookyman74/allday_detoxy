## 3. 수정된 앱 설명

### 3.1 간단한 설명 (80자 이내) - 수정 버전

**원래 버전** (문제 가능성):
```
스마트폰 습관 교정 코치. 시간·위치 기반 자동 집중 모드로 규칙적인 디톡시 습관을 만들어보세요.
```

**수정 버전 1** (더 명확하고 간결):
```
집중이 필요한 시간과 장소에 자동으로 시작되는 스마트한 집중 모드 앱입니다.
```

**수정 버전 2** (기능 중심):
```
타이머 기반 집중 모드와 앱 차단 기능으로 스마트폰 사용 습관을 개선합니다.
```

**수정 버전 3** (가장 안전):
```
집중 모드 타이머와 앱 차단 기능을 제공하는 습관 관리 앱입니다.
```

### 3.2 자세한 설명 (4000자 이내) - 수정 버전

**주요 수정 사항**:
1. 과장된 표현 제거
2. "최고의", "유일한" 등의 표현 제거
3. 사용 후기/리뷰 제거
4. 실제 기능만 명확히 설명
5. 키워드 반복 최소화

**수정된 자세한 설명**:

```
ScreenSence는 스마트폰 사용 습관을 개선하기 위한 집중 모드 앱입니다.

【주요 기능】

집중 타이머
원하는 시간을 설정하고 집중 모드를 시작할 수 있습니다. 타이머 실행 중에는 설정한 앱이 차단되고 잠금 화면이 표시됩니다. 5분부터 3시간까지 시간을 설정할 수 있으며, 자주 사용하는 시간은 프리셋으로 저장할 수 있습니다.

앱 차단
카테고리별로 앱을 차단할 수 있습니다. SNS, 메신저, 동영상, 웹, 기타 앱을 선택적으로 차단하여 집중을 방해하는 요소를 제거할 수 있습니다. 긴급 연락이 필요한 경우 메신저 앱을 허용할 수 있습니다.

시간 기반 자동 실행
정해진 시간에 자동으로 집중 모드가 시작됩니다. 예를 들어, 매일 오전 9시와 오후 2시에 자동으로 집중 모드를 시작하도록 설정할 수 있습니다. 요일별 반복 설정도 가능하며, 최대 10개의 시간대를 등록할 수 있습니다.

위치 기반 자동 실행
특정 장소에 도착하면 자동으로 집중 모드가 시작됩니다. 회사, 학교, 도서관 등 집중이 필요한 장소를 등록할 수 있습니다. Google Places 검색으로 위치를 등록할 수 있으며, 반경을 50m부터 500m까지 설정할 수 있습니다. 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다.

디톡시 리포트
매일의 집중 시간과 성공률을 확인할 수 있습니다. 디톡시 위험 지수로 현재 상태를 파악하고, 회복률 추세를 그래프로 확인할 수 있습니다. 어떤 앱이 가장 많이 방해했는지 Top 3를 확인할 수 있습니다.

보상 시스템
집중 모드를 완료하면 포인트를 획득합니다. 연속으로 성공할수록 스트릭이 쌓이며, 성공한 세션 수와 총 집중 시간이 기록됩니다.

【주요 특징】

• 전화는 허용: 집중 중에도 긴급 전화는 받을 수 있습니다
• 배터리 효율적: 위치 기반 자동 실행은 Geofencing API를 사용하여 배터리 소모를 최소화합니다
• 프라이버시 보호: 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다
• 직관적인 UI: 도넛 그래프로 시간을 쉽게 설정할 수 있습니다
• 안정적인 알람: 정확 알람 권한을 지원하여 배터리 절약 모드에서도 정확하게 작동합니다

【사용 시나리오】

• 학생: 시험 기간에 집중이 필요한 시간대를 설정하고, 도서관에 도착하면 자동으로 집중 모드가 시작됩니다
• 직장인: 업무 시간에 SNS와 동영상 앱을 차단하고, 회사에 도착하면 자동으로 집중 모드가 활성화됩니다
• 자가관리: 매일 규칙적인 시간에 집중 모드를 시작하여 습관을 형성하고, 리포트로 진행 상황을 확인합니다

ScreenSence와 함께 건강한 스마트폰 사용 습관을 만들어보세요.
```

**주요 변경사항**:
- "최고의", "유일한" 등의 과장 표현 제거
- 사용 후기/리뷰 제거
- 키워드 반복 최소화
- 실제 기능만 명확히 설명
- 간결하고 읽기 쉬운 문장
