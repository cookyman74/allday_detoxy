# 뽀모도로 타이머 UI 확장 및 스와이프 UX 설계 (Multi-Style Timer)

## 1. 개요
사용자가 자신의 집중 성향이나 기분에 맞춰 타이머 화면을 선택할 수 있도록, **3가지 다른 스타일의 뽀모도로 타이머 UI**를 제공합니다.
좌우 스와이프(Horizontal Swipe) 제스처를 통해 직관적으로 타이머 스타일을 변경할 수 있으며, 이 경험은 **Liquid Glass** 디자인 언어 안에서 통일감을 유지합니다.

## 2. UX 설계 (Interaction Flow)
*   **제스처 (Gesture)**: 타이머 영역을 좌/우로 스와이프하여 테마 전환.
*   **인디케이터 (Indicator)**: 하단에 현재 선택된 타이머 스타일을 나타내는 페이지 인디케이터(Page Indicator, 점 3개) 표시.
*   **상태 유지 (Persistence)**: 사용자가 마지막으로 선택한 스타일을 로컬에 저장하여, 앱 재실행 시 해당 스타일 유지.
*   **타이머 상태 공유 (Shared State)**: 어떤 스타일을 보고 있든, 실제 타이머 시간(남은 시간, 진행 상태)은 공유됨. 스타일만 바뀔 뿐 타이머는 계속 돌아감.

## 3. UI 디자인 컨셉 (3 Types)

### Type A: Liquid Ring (Signature Glass)
*   **Concept**: 디톡시의 시그니처인 '액체(Liquid)'와 '유리(Glass)' 질감을 극대화한 스타일.
*   **Visual**:
    *   중앙에 거대한 Glass Ring 존재.
    *   시간이 흐름에 따라 링 내부의 액체(Gradient Progress)가 줄어들거나 차오름.
    *   남은 시간이 중앙에 큰 `Glass 숫자`로 표시됨.
*   **Vibe**: 세련됨, 현대적임, 기술적임.

### Type B: Minimal Flux (Zen Mode)
*   **Concept**: 숫자와 그래프에 얽매이지 않고, 색(Color)과 호흡(Breathing)으로 집중을 유도하는 엠비언트 스타일.
*   **Visual**:
    *   구체적인 테두리나 링 없음.
    *   화면 중앙에 부드럽게 일렁이는 **"빛의 구(Orb)"** 또는 **"그라데이션 배경"**.
    *   시간이 흐를수록 빛의 색상이 서서히 변화 (예: Blue → Purple → Deep Red).
    *   숫자는 매우 작게 표시되거나, 탭 했을 때만 등장하도록 하여 시각적 자극 최소화.
*   **Vibe**: 차분함, 명상적, 감성적.

### Type C: Glass Sector (Visual Analog)
*   **Concept**: 고전적인 '비주얼 타이머(Visual Timer)'를 Glassmorphism으로 재해석.
*   **Visual**:
    *   아날로그 시계 형태의 원형 디스크.
    *   남은 시간이 **"부채꼴(Sector)"** 모양으로 시각화되어 줄어듦 (타임타이머 방식).
    *   부채꼴 영역이 단순 색상이 아니라, `GlassSurface` 처리되어 반투명하게 빛남.
    *   눈금(Scale)이 미세하게 새겨져 있어 정확한 시간 흐름 인지 가능.
*   **Vibe**: 직관적, 클래식함, 생산성 중시.

## 4. 기술적 구현 계획
1.  **Pager 도입**: `androidx.compose.foundation.pager.HorizontalPager` 사용.
2.  **ViewModel 연동**: 3개의 UI가 하나의 `TimerViewModel` 상태(`remainingTime`, `progress`)를 구독.
3.  **Components**:
    *   `TimerStyleLiquidRing` (기존 `TimerCircle` 리팩토링)
    *   `TimerStyleMinimalFlux` (신규 구현: Canvas & Shader 활용 권장)
    *   `TimerStyleVisualAnalog` (신규 구현: Canvas `drawArc` 활용)

## 5. 예상 화면 구성
```
[ Top Bar: Status / Title ]
      
      <   Swipe Area   >

      [  Timer UI  ]
      (Type A / B / C)

      [ Page Indicator ]
      (  ●  ○  ○  )

[ Bottom Bar: Controls ]
( Play / Pause / GiveUp )
```
