# Allday Detoxy v0.6 - 자동 실행 & 커스텀 타이머

**릴리스 날짜**: 2025-10-26  
**버전**: v0.6.0 (2차 고도화)  
**빌드**: feat/v0.9

---

## 🎯 주요 업데이트

### 1. 시간 기반 자동 실행 (신규) 🆕

**정해진 시간에 자동으로 집중 모드 시작!**

바쁜 일상 속에서도 규칙적인 디톡시 습관을 만들어보세요.

#### ✨ 주요 기능

- **시간대 설정 (최대 10개)**
  - 원하는 시간에 타이머 자동 시작
  - 요일별 반복 설정 (월~일 선택 가능)
  - 프리셋 선택 (표준/집중/휴식/짧은휴식/커스텀)

- **스마트 알림**
  - 5분 전 사전 알림 (선택)
  - 알림 액션: 시작/스누즈(5분)/건너뛰기
  - 5분 후 자동 시작 (액션 없을 경우)

- **안정적인 알람**
  - 정확 알람 권한 지원 (Android 12+)
  - Doze 모드 대응 (배터리 절약 모드에서도 정확)
  - AlarmManager + WorkManager fallback
  - 앱 재시작 후 자동 재등록

---

### 2. 위치 기반 자동 실행 (신규) 📍

**특정 장소 도착 시 자동으로 집중 모드 시작!**

회사, 학교, 도서관 등 집중이 필요한 장소를 등록하세요.

#### ✨ 주요 기능

- **위치 등록 (최대 5개)**
  - Google Places 검색으로 간편 등록
  - 반경 설정 (50m~500m)
  - GPS 정확도 표시

- **배터리 효율적 감지**
  - Geofencing API 기반
  - Google Play Services 활용
  - 백그라운드 배터리 소모 최소화 (< 1.5% / 일)

- **프라이버시 보호**
  - 위치 정보는 기기에만 저장
  - 서버로 전송되지 않음
  - 언제든지 삭제 가능

---

### 3. 커스텀 타이머 UI (신규) 🎨

**직관적인 도넛 그래프로 시간 설정!**

5분부터 3시간까지, 원하는 시간을 자유롭게 조정하세요.

#### ✨ 주요 기능

- **도넛 그래프 인터랙션**
  - 드래그로 시간 조정 (5분 단위)
  - 탭으로 빠른 시간 설정
  - 햅틱 피드백 및 부드러운 애니메이션

- **커스텀 프리셋 (최대 10개)**
  - 자주 사용하는 시간을 프리셋으로 저장
  - 프리셋 이름 및 이모지 설정
  - 순서 변경, 편집, 삭제

- **기본 루틴 템플릿**
  - 표준 (45분)
  - 집중 (90분)
  - 휴식 (15분)
  - 짧은휴식 (5분)

---

### 4. 자동 실행 제어 (신규) ⚙️

**자동 실행을 유연하게 관리하세요!**

#### ✨ 주요 기능

- **마스터 토글**
  - 모든 자동 실행 일괄 활성화/비활성화
  - 예약설정 화면에서 간편 제어

- **임시 일시중지**
  - 30분 / 1시간 / 3시간 / 내일까지
  - 휴가, 외출 시 유용

- **다음 예정 자동 실행**
  - 타이머 화면에 표시
  - 시간 및 프리셋 미리 확인

## 🔧 기술 개선 사항

### 데이터베이스 업그레이드

- **Room v3→v4 마이그레이션** 자동 진행
- 신규 테이블:
  - `time_based_auto_run`: 시간 기반 자동 실행 (10개)
  - `location_based_auto_run`: 위치 기반 자동 실행 (5개)
  - `custom_timer_preset`: 커스텀 타이머 프리셋 (10개)
  - `auto_run_log`: 자동 실행 이력 (성공/실패 사유)
  - `user_settings`: 사용자 설정 (마스터 토글, 일시중지)
- 인덱스 7개 추가 (쿼리 성능 최적화)

### Analytics 이벤트 추가

- **21개 신규 이벤트** 로깅
  - 시간 기반 자동 실행: 생성/토글/삭제/트리거/스누즈/건너뛰기
  - 위치 기반 자동 실행: 생성/토글/삭제/트리거
  - 커스텀 프리셋: 생성/선택/삭제
  - 권한: 정확알람/위치/백그라운드위치 거부
- 프라이버시 준수 (해시 처리, 길이만 로깅)

### 성능 최적화

- **UI 성능**: 도넛 그래프 60fps 유지
  - `remember`, `animateFloatAsState`, `rememberTextMeasurer` 활용
- **DB 쿼리 최적화**: 인덱스 7개 설정
- **메모리 관리**: `viewModelScope`, Room Flow 자동 관리
- **배터리 최적화**:
  - AlarmManager: `setExactAndAllowWhileIdle()`
  - Geofence: `INITIAL_TRIGGER_ENTER`, `PRIORITY_BALANCED_POWER_ACCURACY`

### 빌드 시스템

- APK 크기: 12MB (목표 15MB 이하 달성)
- 소스 코드: 106개 파일, ~15,000줄
- 단위 테스트: 17개 (MVP 데이터 검증)
