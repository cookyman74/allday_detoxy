## 3️⃣ 주간 히트맵 (메인 UI)

### 📐 구조 정의

| 항목 | 값 |
|------|---|
| 가로 | 12칸 (1칸 = 1시간) |
| 세로 | 7요일 × 2줄 (AM/PM) = 14행 |
| 터치 단위 | **행(Row) 단위** (셀 단위 ❌) |
| 색상 | 계획된 집중 시간 기반 |

> ⚠️ **터치 오류 방지**: 개별 셀(24dp)은 터치 타겟으로 부적합
> ✅ **해결책**: 요일+AM/PM 행 전체를 터치 영역으로 사용

## 4️⃣ 데이터 집계 규칙 (핵심)

### 4-1. 시간 슬롯 분배

시간대가 1시간을 초과하거나 시간 경계를 넘는 경우:

```
예: 시작 09:15, duration 90분
→ 09시 슬롯: 45분 (09:15~10:00)
→ 10시 슬롯: 45분 (10:00~10:45)
```

### 4-2. 자정 넘김 처리

```
예: 시작 23:30, duration 60분
→ 23시 슬롯: 30분 (당일)
→ 00시 슬롯: 30분 (다음 요일로 이동)
```

### 4-3. 겹치는 시간대 합산

```
예: 같은 시간 슬롯에 2개 시간대
→ 합산 후 최대 60분으로 cap
→ 색상 매핑: 합산값 기준
```

| 합산값 | 색상 레벨 |
|--------|----------|
| 0분 | ▢ (없음) |
| 1~15분 | ░ (가벼움) |
| 16~30분 | ▒ (중간) |
| 31~45분 | ▓ (높음) |
| 46분 이상 | █ (최대, cap 60분) |

### 4-4. 비활성 시간대 처리

- `isEnabled=false` 시간대: **히트맵에서 제외**
- 요약 지표에서도 제외
- 시간 스케쥴 목록에서는 표시 (회색 처리)

## 5️⃣ 색상 규칙 및 범례 UI

### 색상 팔레트 (고정)

| Duration | 기호 | 색상 (HEX) | 의미 |
|----------|------|-----------|------|
| 0분 | ▢ | `#E0E0E0` | 계획 없음 |
| 1~15분 | ░ | `#90CAF9` | 가벼운 집중 |
| 16~30분 | ▒ | `#42A5F5` | 중간 집중 |
| 31~45분 | ▓ | `#1976D2` | 높은 집중 |
| 46~60분 | █ | `#0D47A1` | 최대 집중 |

> 💡 **색상 정책**: PRD 고정 팔레트 사용 (테마/그룹 컬러 별도 미적용)

### 범례 표시

```
┌─────────────────────────────────────┐
│ ▢ 없음  ░ ~15분  ▒ ~30분  ▓ ~45분  █ ~60분 │
└─────────────────────────────────────┘
```
- 위치: 히트맵 **하단** 고정
- 형태: 가로 배열, 아이콘 + 텍스트

**트리거**: 요일+AM/PM 행 전체 탭 (셀 단위 ❌)

```
[MON AM 행 탭 시]
┌─────────────────────────────────┐
│  월요일 오전 (0~11시)            │
├─────────────────────────────────┤
│  09:00~09:30  30분  표준 디톡시  │
```

- 겹치는 시간대 문제 해결 (개별 표시)

## 7️⃣ 아키텍처 / 성능 가이드

### 데이터 흐름

```kotlin
// ViewModel
class ScheduleGroupDetailViewModel : ViewModel() {
    
    // 히트맵 UI 모델 (StateFlow)
    val weeklyHeatmap: StateFlow<WeeklyHeatmapUiModel> = 
        combine(
            scheduleGroupFlow,
            timeBasedAutoRunsFlow
        ) { group, autoRuns ->
            WeeklyHeatmapCalculator.calculate(group, autoRuns)
        }.stateIn(viewModelScope, SharingStarted.Lazily, WeeklyHeatmapUiModel.EMPTY)
}

// UI 모델
data class WeeklyHeatmapUiModel(
    val rows: List<HeatmapRow>,  // 14행 (7요일 × 2)
    val summary: HeatmapSummary
)

data class HeatmapRow(
    val dayOfWeek: DayOfWeek,
    val period: Period,  // AM or PM
    val cells: List<HeatmapCell>,  // 12칸
    val timeSlots: List<TimeSlotInfo>  // 상세 정보용
)
```

### 성능 최적화

- ❌ UI에서 즉시 계산 → 재컴포즈 비용
- ✅ ViewModel에서 `WeeklyHeatmapUiModel` 생성 → StateFlow 제공
- ✅ `linkedTimeBasedAutoRuns` 갱신 시 자동 업데이트
