## 7.1 수동 QA 체크리스트

### 7.1.1 생성 플로우

| 테스트 항목 | 예상 결과 | 결과 |
|------------|----------|------|
| 시간 기반 스케줄 + 목표 생성 | 저장 성공, 상세 화면에 목표 표시 | |
| 시간 기반 스케줄 + 할일 5개 생성 | 저장 성공, 상세 화면에 할일 표시 | |
| 위치 기반 스케줄 + 목표/할일 생성 | 동일 동작 | |
| 목표 50자 초과 입력 | 50자에서 입력 제한 | |
| 할일 100자 초과 입력 | 100자에서 입력 제한 | |
| 할일 5개 초과 추가 시도 | 추가 버튼 비활성화 | |
| 빈 할일 저장 시도 | 검증 에러 메시지 표시 | |

### 7.1.2 오버레이 플로우

| 테스트 항목 | 예상 결과 | 결과 |
|------------|----------|------|
| 차단 앱 실행 시 목표 표시 | 오버레이에 목표 텍스트 표시 | |
| 세부 할일 표시 ON | 최대 3개 + "+N개 더" 표시 | |
| 30자 초과 목표 | "..." 처리 | |
| 20자 초과 할일 | "..." 처리 | |
| 목표 숨기기 ON | 이모지만 표시 | |
| 목표 표시 OFF | 할일 섹션 없음 | |

### 7.1.3 세션 종료 플로우

| 테스트 항목 | 예상 결과 | 결과 |
|------------|----------|------|
| 목표+할일 → 체크리스트 다이얼로그 | 체크박스 UI 표시 | |
| 목표만 → 예/아니오 다이얼로그 | 2개 버튼 표시 | |
| 목표/할일 없음 → 다이얼로그 생략 | 바로 종료 | |
| 30초 카운트다운 표시 | 숫자 감소 | |
| 30초 무응답 (필수 항목) | NOT_COMPLETED로 저장 | |
| 30초 무응답 (일반 항목) | NO_RESPONSE로 저장 | |
| 전체 할일 체크 → 완료 | COMPLETED로 저장, 목표도 COMPLETED | |
| 일부 필수 미체크 | 목표 NOT_COMPLETED | |

## 7.2 Migration 테스트

### 7.2.1 테스트 시나리오

```bash
# 1. 이전 버전 DB 덤프 준비
adb pull /data/data/com.allday.detoxy/databases/detoxy_database ./test_db/

# 2. 새 버전 앱 설치
./gradlew installDebug

# 3. 앱 실행 → Migration 자동 실행

# 4. DB 확인
adb shell "sqlite3 /data/data/com.allday.detoxy/databases/detoxy_database 'SELECT * FROM time_based_auto_run LIMIT 1;'"
```

### 7.2.2 확인 항목

| 항목 | 확인 방법 | 결과 |
|------|----------|------|
| 기존 스케줄 데이터 보존 | 기존 스케줄 목록 확인 | |
| scheduleInfoJson 컬럼 추가 | DB 스키마 확인 | |
| JSON 파싱 실패 시 fallback | 잘못된 JSON 삽입 후 확인 | |
| focus_session_todo_result 테이블 | 테이블 존재 확인 | |
