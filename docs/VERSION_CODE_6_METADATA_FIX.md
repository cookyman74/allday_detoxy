# 버전 코드 6 메타데이터 정책 위반 대응 가이드

**작성일**: 2025년 1월  
**거절 사유**: 메타데이터 정책 위반 (버전 코드: 6)  
**현재 버전**: versionCode: 6, versionName: "1.0.5"

---

## 🚨 문제 분석

**거절 내용**:
- 메타데이터 정책 위반 (앱 설명, 개발자 이름, 앱 제목, 앱 아이콘, 스크린샷, 홍보 이미지)
- **버전 코드: 6**에서 문제 발견

**가능한 원인**:
1. **앱 아이콘**: "Screen Sence" (띄어쓰기) vs "ScreenSence" (띄어쓰기 없음) 불일치
2. **홍보 이미지**: "스마트폰 습관 교정 코치" 과장 표현 가능성
3. **앱 설명**: 여전히 문제가 있는 내용이 포함되어 있을 수 있음
4. **스크린샷**: 실제 앱과 다른 화면이거나 문제가 있는 텍스트 포함 가능성

---

## ✅ 종합 점검 및 수정 가이드

### 1단계: Google Play Console에서 현재 메타데이터 확인

1. **Google Play Console** 접속
   - https://play.google.com/console
   - 앱 선택: **ScreenSence**

2. **"스토어 등록정보"** 메뉴로 이동

3. **각 섹션별로 확인**:
   - 앱 설명 (간단한 설명, 자세한 설명)
   - 앱 제목
   - 앱 아이콘
   - 스크린샷
   - 홍보 이미지
   - 개발자 이름

---

### 2단계: 필수 수정 사항

#### ✅ 1. 앱 아이콘 수정 (최우선)

**문제점**:
- 앱 아이콘에 "Screen Sence" (띄어쓰기)로 표기됨
- 코드베이스와 Google Play Console은 "ScreenSence" (띄어쓰기 없음)

**조치**:
1. 앱 아이콘 이미지 수정
   - "Screen Sence" → "ScreenSence"로 변경
   - 또는 아이콘에서 텍스트 제거 (아이콘만 표시)

2. Google Play Console에 업로드
   - **"스토어 등록정보" → "그래픽 자산" → "앱 아이콘"**
   - 수정된 아이콘 업로드

**우선순위**: 🔴 **최우선 (필수)**

---

#### ✅ 2. 앱 설명 최종 확인 및 수정

**확인 사항**:
- [ ] "사용 시나리오" 섹션이 완전히 제거되었는지 확인
- [ ] "학생", "직장인", "자가관리" 같은 사용자 예시가 없는지 확인
- [ ] "~해보세요" 같은 권유 문구가 없는지 확인
- [ ] 과장된 표현이 없는지 확인

**수정된 앱 설명 (최종 버전)**:

**간단한 설명**:
```
타이머 기반 집중 모드와 앱 차단 기능을 제공하는 습관 관리 앱입니다.
```

**자세한 설명**:
```
ScreenSence는 스마트폰 사용 습관 관리를 위한 집중 모드 앱입니다.

【주요 기능】

집중 타이머
시간을 설정하고 집중 모드를 시작할 수 있습니다. 타이머 실행 중에는 설정한 앱이 차단되고 잠금 화면이 표시됩니다. 5분부터 3시간까지 시간을 설정할 수 있으며, 자주 사용하는 시간은 프리셋으로 저장할 수 있습니다.

앱 차단
카테고리별로 앱을 차단할 수 있습니다. SNS, 메신저, 동영상, 웹, 기타 앱을 선택적으로 차단할 수 있습니다.

시간 기반 자동 실행
정해진 시간에 자동으로 집중 모드가 시작됩니다. 요일별 반복 설정이 가능하며, 최대 10개의 시간대를 등록할 수 있습니다.

위치 기반 자동 실행
특정 장소에 도착하면 자동으로 집중 모드가 시작됩니다. Google Places 검색으로 위치를 등록할 수 있으며, 반경을 50m부터 500m까지 설정할 수 있습니다. 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다.

디톡시 리포트
매일의 집중 시간과 성공률을 확인할 수 있습니다. 디톡시 위험 지수와 회복률 추세를 그래프로 확인할 수 있습니다.

보상 시스템
집중 모드를 완료하면 포인트를 획득합니다. 연속으로 성공할수록 스트릭이 쌓이며, 성공한 세션 수와 총 집중 시간이 기록됩니다.

【기술적 특징】

• 전화는 허용: 집중 중에도 긴급 전화는 받을 수 있습니다
• 배터리 효율적: 위치 기반 자동 실행은 Geofencing API를 사용하여 배터리 소모를 최소화합니다
• 프라이버시 보호: 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다
• 직관적인 UI: 도넛 그래프로 시간을 쉽게 설정할 수 있습니다
• 안정적인 알람: 정확 알람 권한을 지원하여 배터리 절약 모드에서도 정확하게 작동합니다
```

**⚠️ 제거해야 할 내용**:
- ❌ "사용 시나리오" 섹션
- ❌ "학생", "직장인", "자가관리" 같은 사용자 예시
- ❌ "~해보세요" 같은 권유 문구
- ❌ "ScreenSence와 함께 건강한 스마트폰 사용 습관을 만들어보세요" 같은 마무리 문구

**우선순위**: 🔴 **최우선 (필수)**

## 🚀 수정 절차

### 1단계: Google Play Console 접속

1. https://play.google.com/console 접속
2. 앱 선택: **ScreenSence**

### 2단계: 메타데이터 수정

1. **"스토어 등록정보"** 메뉴 클릭

2. **앱 아이콘 수정** (최우선)
   - "그래픽 자산" → "앱 아이콘"
   - "Screen Sence" → "ScreenSence"로 수정된 아이콘 업로드

3. **앱 설명 수정** (최우선)
   - "앱 설명" 섹션
   - 위의 "수정된 앱 설명 (최종 버전)"으로 교체
   - "사용 시나리오" 섹션 완전 제거 확인

4. **홍보 이미지 수정** (권장)
   - "그래픽 자산" → "홍보 이미지"
   - "스마트폰 습관 교정 코치" → "스마트폰 습관 관리 앱"으로 변경

5. **스크린샷 확인** (필요 시)
   - "그래픽 자산" → "스크린샷"
   - 실제 앱 화면인지 확인
   - 문제 발견 시 재촬영 및 업로드

6. **앱 제목 확인**
   - "스토어 설정" → "앱 이름"
   - "ScreenSence"로 일관성 확인

### 3단계: 변경사항 저장 및 재제출

1. **모든 변경사항 저장**
   - 각 섹션에서 "저장" 클릭

2. **변경사항 검토**
   - "변경사항 검토" 클릭
   - 모든 변경사항 확인

3. **재제출**
   - **"테스트 및 출시" → "프로덕션"** (또는 내부 테스트)
   - **"변경사항 전송"** 클릭
   - 검토 요청

4. **검토 대기**
   - 일반적으로 1-3일 소요
   - 거부 시 구체적인 이유 확인

## 🔍 문제가 계속되는 경우

### Google Play Console 지원팀 문의

위의 모든 단계를 완료했는데도 같은 거절 사유를 받는다면:

1. **Google Play Console → 도움말** 메뉴
2. **"문의하기"** 또는 **"지원팀에 문의"** 선택
3. 다음 내용으로 문의:

```
제목: 버전 코드 6 메타데이터 정책 위반 관련 문의

내용:
ScreenSence 앱(버전 코드: 6)이 메타데이터 정책 위반으로 거절되었습니다.

수정 완료 사항:
- 앱 아이콘: "Screen Sence" → "ScreenSence"로 수정 완료
- 앱 설명: "사용 시나리오" 섹션 제거 완료
- 홍보 이미지: "스마트폰 습관 교정 코치" → "스마트폰 습관 관리 앱"으로 변경 완료
- 스크린샷: 실제 앱 화면으로 확인 완료
- 앱 제목: "ScreenSence"로 일관성 확인 완료

그러나 여전히 메타데이터 정책 위반으로 거절되고 있습니다.

구체적으로 어떤 메타데이터 항목에서 문제가 발견되었는지 알려주시면 감사하겠습니다.
```

**문의 시 첨부할 정보**:
- 정책 상태 페이지의 스크린샷
- 앱 설명 페이지의 스크린샷
- 앱 아이콘 및 홍보 이미지
- 스크린샷
