# ScreenSence 테스터 매뉴얼

안녕하세요! ScreenSence 앱 테스트에 참여해주셔서 감사합니다.  
이 매뉴얼을 따라하시면 쉽게 앱을 사용하고 테스트할 수 있습니다.

---

## 📖 ScreenSence란?

### 앱의 목적

**ScreenSence**는 스마트폰 사용을 줄이고 집중력을 높이기 위한 **디톡시(디지털 디톡스) 앱**입니다.

공부, 업무, 독서 등 집중이 필요한 시간에 방해가 되는 앱(YouTube, 인스타그램, 카카오톡 등)을 차단하여  
**의도한 시간 동안 스마트폰에서 벗어날 수 있도록** 도와줍니다.

### 주요 특징

#### 🎯 집중 타이머
- 원하는 시간(5분~3시간)을 설정하여 집중 시간을 관리합니다
- 타이머 실행 중 방해 앱을 자동으로 차단합니다
- 남은 시간을 시각적으로 확인할 수 있습니다

#### 🚫 스마트 앱 차단
- YouTube, 인스타그램, 카카오톡 등 방해가 되는 앱을 선택적으로 차단합니다
- 차단한 앱을 열려고 하면 차단 화면이 나타납니다
- 전화는 정상적으로 받을 수 있어 긴급 상황에도 대응 가능합니다

#### ⏰ 자동 실행 기능
- **시간 기반**: 특정 시간(예: 오전 9시)에 자동으로 타이머가 시작됩니다
- **위치 기반**: 특정 장소(예: 도서관)에 도착하면 자동으로 타이머가 시작됩니다
- 반복 요일 설정으로 매일 자동 실행할 수 있습니다

#### 📊 집중 기록
- 매일 집중한 시간과 성공한 세션을 기록합니다
- 연속 성공 일수(스트릭)를 추적하여 동기부여를 제공합니다

### 누구를 위한 앱인가요?

- 📚 **학생**: 시험 공부, 자습 시간에 집중하고 싶은 학생
- 💼 **직장인**: 업무 집중 시간을 확보하고 싶은 직장인
- 📖 **독서가**: 독서 시간에 방해 없이 책에 집중하고 싶은 분
- 🎯 **목표 달성자**: 스마트폰 사용을 줄이고 목표를 달성하고 싶은 모든 분

### 핵심 가치

**강제 차단이 아닌, 자발적 집중 습관 형성**

ScreenSence는 단순히 앱을 막는 것이 아니라,  
사용자가 **스스로 집중 시간을 설정하고 성공 경험을 쌓아가는 것**을 돕습니다.

## 📱 1단계: 앱 설치하기

### 방법 1: 링크로 설치 (가장 쉬움)

1. 개발자가 보낸 **테스터 링크**를 클릭하세요
2. 브라우저에서 Play Store 페이지가 열립니다

![Google Play 내부 테스트 초대](install_screenshot/01_google_play_internal_test_invite.jpeg)

3. **"ACCEPT INVITE"** 버튼을 클릭하여 내부 테스트에 참여하세요

![Google Play 내부 테스트 프로그램](install_screenshot/02_google_play_internal_test_program.jpeg)

4. **"다운로드"** 또는 **"설치"** 버튼을 클릭하세요

![Google Play 설치 화면](install_screenshot/03_google%20play%20allday.detoxy%20설치%20화면.jpeg)

5. 설치가 완료되면 **"열기"** 버튼을 클릭하거나 앱 아이콘을 탭하여 앱을 실행하세요

### 방법 2: Play Store 앱에서 설치

1. Android 기기에서 **Play Store 앱**을 엽니다
2. **"내 앱 및 게임"** 탭을 클릭합니다
3. **"베타"** 또는 **"테스트"** 섹션에서 **Allday Detoxy**를 찾습니다
4. **"설치"** 버튼을 클릭합니다

## 🔐 2단계: 첫 실행 및 권한 설정

### 첫 실행 시 화면

앱을 처음 열면 **앱 소개 화면**이 나타납니다.

![앱 시작 화면](install_screenshot/04.1_allday_detoxy%20start%20화면.jpeg)

앱의 주요 기능을 확인하고 **"시작하기"** 버튼을 눌러 진행하세요.

### 권한 설정 화면

앱을 시작하면 **온보딩 설정 화면**이 나타납니다.

![온보딩 설정 화면](install_screenshot/04.2_시작후%20온보딩%20설정%20화면.jpeg)

집중 모드를 사용하기 위해 필요한 권한들을 설정해야 합니다.

### 필수 권한 설정

앱이 제대로 작동하려면 다음 권한이 필요합니다:

#### 1️⃣ 접근성 서비스 (가장 중요!)

**왜 필요한가요?**  
집중 타이머 실행 중 방해가 되는 앱(YouTube, 카카오톡 등)을 차단하기 위해 필요합니다.

**설정 방법:**

1. 권한 설정 화면에서 **"앱 차단 기능"** 섹션의 **"권한 설정하기"** 버튼을 클릭하세요

![접근성 설정 요청 화면](install_screenshot/05_온보딩%20설정을%20통한%20접근성%20설정%20요청화면.jpeg)

2. **설정 앱** > **접근성** 메뉴로 이동합니다

3. **"다운로드한 앱"** 메뉴를 선택합니다

![접근성 다운로드한 앱 목록](install_screenshot/13_accessibility_downloaded_apps_list.jpeg)

4. **"Allday Detoxy"**를 찾아 선택합니다

![접근성 설정 화면](install_screenshot/06_접근성%20설정%20중%20다운로드한%20앱선택후%20allday_detoxy설정.jpeg)

5. 접근성 권한의 위험성에 대한 경고 화면이 나타납니다. 내용을 읽고 확인란을 체크한 후 **"확인"** 버튼을 클릭하세요

6. 토글을 **켜기(ON)**로 변경합니다

**확인 방법:**  
앱으로 돌아와서 "앱 차단 기능" 섹션에 **"권한 허용됨"** 체크 표시가 보이면 성공입니다!

#### 2️⃣ 다른 앱 위에 표시 (오버레이 권한)

**왜 필요한가요?**  
타이머 실행 중 잠금 화면을 표시하기 위해 필요합니다.

**설정 방법:**

1. 권한 설정 화면에서 **"잠금 화면 표시"** 섹션의 **"권한 설정하기"** 버튼을 클릭하세요

2. **설정 앱** > **앱** > **특별 액세스** > **다른 앱 위에 표시** 메뉴로 이동합니다

![다른 앱 위에 표시 앱 목록](install_screenshot/10_display_over_other_apps_list.jpeg)

3. 앱 목록에서 **"Allday Detoxy"**를 찾아 선택합니다

4. **"다른 앱 위에 표시 허용"** 토글을 **켜기(ON)**로 변경합니다

![다른 앱 위에 표시 설정](install_screenshot/09_display_over_other_apps_settings.jpeg)

**확인 방법:**  
앱으로 돌아와서 "잠금 화면 표시" 섹션에 **"권한 허용됨"** 체크 표시가 보이면 성공입니다!

![잠금화면 권한 설정 완료](install_screenshot/08_permission_setup_잠금화면.jpeg)

#### 3️⃣ 방해 금지 모드 (선택 사항)

**왜 필요한가요?**  
타이머 실행 중 알림을 차단하여 집중을 돕습니다.

**설정 방법:**
1. 권한 요청 화면에서 **"설정으로 이동"** 클릭
2. 또는 **설정 앱** > **앱** > **특별 액세스** > **방해 금지 모드**
3. **"ScreenSence"** 찾기
4. 토글을 **켜기(ON)**로 변경

## ⏱️ 3단계: 기본 기능 사용하기

### 기능 1: 집중 타이머 시작하기

**가장 기본적인 기능입니다!**

1. 앱 메인 화면에서 **"집중 타이머"** 메뉴를 선택합니다
2. 화면 중앙의 **원형 차트(도넛 그래프)**가 보입니다
3. 시간을 선택하는 방법:
   - **드래그**: 원형 차트의 가장자리를 드래그하여 시간 조정
   - **탭**: 원형 차트의 원하는 위치를 탭하여 즉시 설정
   - **프리셋 버튼**: 하단의 **25분**, **45분**, **60분** 버튼 클릭
4. 시간 선택 후 **"시작하기"** 버튼을 클릭합니다
5. 타이머가 시작되면 잠금 화면이 표시됩니다

**확인 사항:**
- ✅ 원형 차트가 부드럽게 움직이나요?
- ✅ 프리셋 버튼을 누르면 차트가 함께 변하나요?
- ✅ 타이머 시작 후 잠금 화면이 나타나나요?

### 기능 2: 차단할 앱 선택하기

**타이머 실행 중 어떤 앱을 막을지 정합니다**

1. 메인 화면에서 **"설정"** 또는 **"차단 앱 관리"** 메뉴 선택
2. **"차단 앱 추가"** 버튼 클릭
3. 앱 목록에서 차단하고 싶은 앱 선택 (예: YouTube, 카카오톡, 인스타그램)
4. 선택한 앱들이 목록에 추가됩니다

**테스트 방법:**
1. 타이머를 시작합니다
2. 차단한 앱(예: YouTube)을 열어봅니다
3. 차단 화면이 나타나고 앱이 열리지 않아야 합니다 ✅

### 기능 3: 시간 기반 자동 실행 설정

**특정 시간에 자동으로 타이머가 시작됩니다**

1. 메인 화면에서 **"스케줄"** 메뉴를 선택합니다

2. **"첫 시간표 만들기"** 또는 **"+"** 버튼을 클릭합니다

![첫 시간표 만들기](install_screenshot/11_첫%20시간표%20만들기.jpeg)

3. **"시간표 만들기"** 화면에서:
   - **시간표 이름**: 예) "평일 집"
   - **시작 방법**: **"템플릿"** 또는 **"커스텀"** 선택
   - 템플릿을 선택하면 **"템플릿 선택"** 버튼을 클릭하여 매일/평일/주말 등 미리 정의된 템플릿을 선택할 수 있습니다

![템플릿 메뉴 선택](install_screenshot/14_위치기반%20스케쥴을%20만들기%20위한%20템플릿%20메뉴%20선택.jpeg)

![템플릿 리스트에서 선택](install_screenshot/15_템플릿%20리스트에서%20선택.jpeg)

![템플릿 선택 다이얼로그](install_screenshot/16_template_selection_dialog.jpeg)

4. 시간 설정:
   - **시작 시간**: 예) 오전 9시 30분
   - **타이머 시간**: 예) 25분
   - **반복 요일**: 예) 평일(월~금)

5. **"저장"** 또는 **"만들기"** 버튼을 클릭합니다

**테스트 방법:**
1. 설정한 시간이 되면 자동으로 타이머가 시작되어야 합니다
2. 또는 테스트를 위해 시간을 가까운 시간(예: 5분 후)으로 설정해보세요

**확인 사항:**
- ✅ 시간 입력 시 숫자 키패드가 나타나나요?
- ✅ 시간을 모두 지울 수 있나요?
- ✅ 시간을 수정할 때 커서가 정상적으로 동작하나요?

### 기능 4: 위치 기반 자동 실행 설정 (선택)

**특정 장소에 도착하면 자동으로 타이머가 시작됩니다**

1. **"자동 실행"** 또는 **"스케줄"** 메뉴에서 **"위치 기반 추가"** 버튼 클릭

![위치기반 스케줄 만들기](install_screenshot/12.1_위치기반%20스케쥴%20만들기.jpeg)

2. 위치 권한이 필요합니다. 권한 요청 다이얼로그가 나타나면 **"앱 사용 중에만 허용"** 또는 **"항상 허용"**을 선택하세요

![위치 권한 요청 다이얼로그](install_screenshot/07_location_permission_request.jpeg)

3. 위치 권한 설정 화면에서 **"항상 허용"**을 선택하는 것을 권장합니다

![위치 권한 설정](install_screenshot/17_위치권한%20설정.jpeg)

![위치 액세스 권한](install_screenshot/19_location_access_permissions.jpeg)

4. 백그라운드 위치 권한이 필요하다는 안내가 나타납니다. **"다음"** 버튼을 클릭하세요

![백그라운드 위치 권한 안내](install_screenshot/18_background_location_permission_dialog_2.jpeg)

5. 장소 이름 입력: 예) "회사", "도서관"

6. 위치 선택 화면에서 현재 위치를 지도에서 선택하거나 주소를 검색합니다

![위치 검색](install_screenshot/12.2_위치기반%20스케쥴%20만들기%20위한%20주소검색.jpeg)

7. 반경 설정: 슬라이더를 조정하여 반경을 설정합니다 (예: 100m)

![위치 검색 후 반경 설정](install_screenshot/13_위치검색후%20화면_반경설정.jpeg)

8. **"위치 기반 자동 실행"** 설정을 활성화합니다

![위치기반 자동실행 설정](install_screenshot/13.1_위치기반%20자동실행%20설정.jpeg)

9. **"저장"** 또는 **"다음"** 버튼을 클릭하여 완료합니다

**테스트 방법:**
1. 설정한 위치 근처로 이동합니다
2. 도착하면 자동으로 타이머가 시작되어야 합니다

## ❓ 자주 묻는 질문 (FAQ)

### Q1: 앱이 갑자기 종료되어요

**A:** 접근성 서비스가 활성화되어 있는지 확인해주세요.  
설정 > 접근성 > ScreenSence가 켜져 있어야 합니다.

### Q2: 차단한 앱이 여전히 열려요

**A:** 다음을 확인해주세요:
- 접근성 서비스가 활성화되어 있나요?
- 타이머가 실행 중인가요?
- 앱이 차단 목록에 추가되어 있나요?

### Q3: 자동 실행이 작동하지 않아요

**A:** 다음을 확인해주세요:
- 자동 실행이 일시정지 상태가 아닌가요?
- 시간 기반: 기기 시간이 정확한가요?
- 위치 기반: 위치 권한이 허용되어 있나요?

### Q4: 배터리가 빨리 닳아요

**A:** 위치 기반 자동 실행을 많이 사용하시나요?  
위치 기반 기능은 배터리를 조금 더 사용할 수 있습니다.  
시간 기반만 사용하면 배터리 소모가 적습니다.

### Q5: 타이머가 끝나도 차단이 해제되지 않아요

**A:** 앱을 완전히 종료하고 다시 실행해보세요.  
또는 기기를 재시작해보세요.
