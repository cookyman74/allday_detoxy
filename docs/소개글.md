# ScreenSence - 진짜 집중이 필요한 순간을 위한 앱

> 🎯 **스마트폰을 내려놓고, 당신의 목표에 집중하세요**

---

## 💡 왜 ScreenSence인가요?

하루에 스마트폰을 **150번 이상** 확인한다는 사실, 알고 계셨나요?

유튜브 "5분만...", 인스타그램 "한 번만..."이 어느새 1시간이 되고,
정작 해야 할 일은 뒤로 미뤄지는 악순환.

**ScreenSence**는 이런 순간에 부드럽게 개입해서
당신이 **진짜 원하는 일에 집중**할 수 있도록 도와줍니다.

---

## ✨ 주요 기능

### 🎯 집중 타이머
원형 다이얼로 원하는 시간을 설정하고 시작하면 끝!
직관적인 UI로 누구나 쉽게 집중 세션을 시작할 수 있습니다.

### 🚫 스마트 앱 차단
YouTube, 인스타그램, 카카오톡 등 방해가 되는 앱만 골라서 차단.
중요한 전화는 받을 수 있어 긴급 상황에도 문제없습니다.

### ⏰ 자동 실행 스케줄
- **시간 기반**: "평일 오전 9시에 자동으로 집중 모드 시작"
- **위치 기반**: "도서관에 도착하면 자동으로 2시간 집중"
- 반복 설정으로 매일 자동 실행, 의지력 소모 제로!

### 📋 목표 & 할일 관리 `NEW`
"왜 집중하는지" 잊지 마세요!
- 스케줄에 **오늘의 목표**와 **할일 체크리스트** 추가
- 차단된 앱을 열 때 목표가 표시되어 유혹 극복
- 세션 종료 시 할일 완료 여부 체크 → 성취감 UP!

### 🌑 흑백 모드 `NEW`
집중 모드 시작과 동시에 **화면이 자동으로 흑백**으로 전환!
- 화려한 컬러 UI의 시각적 자극을 차단
- 연구에 따르면 스마트폰 사용 욕구 **30~50% 감소**
- Android 15+에서 완전 자동화 지원

### 📊 주간 히트맵 & 리포트 `NEW`
- **주간 히트맵**으로 집중 패턴을 한눈에 파악
- 언제, 어디서 가장 집중을 잘 하는지 시각화
- 성공률, 총 집중 시간, 연속 성공(스트릭) 추적

## 🚀 이렇게 시작하세요

```
1️⃣ 스케줄 만들기
   "평일 오전 9시, 25분간 집중" + 목표: "보고서 초안 완성"

2️⃣ 자동 실행
   설정한 시간이 되면 자동으로 집중 모드 ON
   화면은 흑백으로, 방해 앱은 차단!

3️⃣ 유혹 극복
   습관적으로 유튜브를 열면?
   → 차단 화면에 "🎯 보고서 초안 완성" 목표가 떠오름!

4️⃣ 세션 완료 & 체크
   25분 완료! 할일 체크하고 성취감 느끼기 ✅
```

## 💎 ScreenSence만의 차별점

### ✅ 강제가 아닌 **자발적 습관 형성**
단순히 앱을 막는 게 아닙니다.
**왜 집중해야 하는지** 스스로 인식하고, 성공 경험을 쌓아갑니다.

### ✅ 맥락을 이해하는 **스마트 자동화**
시간과 장소를 인식해서 알아서 실행.
매번 설정할 필요 없이, 당신의 루틴에 녹아듭니다.

### ✅ **시각적 자극 차단** (흑백 모드)
다른 앱엔 없는 기능!
화려한 컬러 UI 자체를 흑백으로 바꿔 사용 욕구를 원천 차단.

### ✅ 목표 리마인더로 **유혹 순간 극복**
차단된 앱을 열 때 "오늘의 목표"가 떠오르면
"아, 지금은 집중 시간이지!" 하고 마음을 다잡을 수 있어요.
