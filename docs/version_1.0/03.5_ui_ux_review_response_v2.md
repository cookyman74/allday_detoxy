## 0. 서비스 목적 및 사용자 프로세스 일관성 검증 ✅

### 0.1 Allday Detoxy의 핵심 가치

**서비스 정의** (prd.md):
```
"디톡시 = 내가 정한 시간·장소·목표 동안 스마트폰을 '거의 못 쓰게' 만들고,
성공할수록 보상과 자유 시간을 얻는 **습관 교정 코치 앱**"

핵심 가치: 강제 차단 대신 **자발적 참여 + 실질적 보상**으로 장기 사용 유도
```

**대상 사용자**:
1. 청소년 자기관리형 (시험/학원/자습)
2. 성인 생산성형 (업무/공부/운동)
3. 보호자/교사 협력형 (자녀/학생 관리)

### 0.2 사용자 여정 (User Journey) 분석

**전체 프로세스**:
```
┌─────────────────────────────────────────────────────────┐
│                   Allday Detoxy 사용자 여정              │

   스케줄 관리 → 리포트 확인 → 조정 반복
```

### 0.3 네비게이션 변경의 일관성 검증

#### 현재 구조 (v0.9)
```
[타이머] [리포트] [설정]
   ↓        ↓       ↓
 수동실행  결과확인  조정
                     └─ 예약설정 (숨겨짐) ❌
```

**문제점**:
1. **사용자 여정 단절**: 수동(타이머) → 자동(예약설정)의 자연스러운 진화 경로가 숨어있음
2. **핵심 가치 약화**: "자발적 참여 + 보상" 중 **자동화(습관 형성)**가 옵션처럼 인식
3. **반복 사용성 저하**: 스케줄 수정 시마다 깊은 depth 진입

#### 제안 구조 (v0.10)
```
[타이머] [스케줄] [리포트] [설정]
   ↓        ↓        ↓       ↓
 수동실행  자동화   결과확인  조정
```

**개선 효과**:
1. **사용자 여정 강화**: 타이머(수동) → 스케줄(자동) 흐름 명확화 ✅
2. **핵심 가치 부각**: 자동화를 "핵심 기능"으로 승격 ✅
3. **반복 사용성 향상**: 1단계 접근 (3단계 → 1단계, 67% 단축) ✅

### 0.4 일관성 검증 결과

| 검증 항목 | 평가 | 근거 |
|-----------|------|------|
| **서비스 목적 일관성** | ✅ 통과 | 자동화는 "습관 교정 코치"의 핵심 도구 |
| **사용자 여정 일관성** | ✅ 통과 | 수동 → 자동화 → 반복의 자연스러운 진화 |
| **네비게이션 논리** | ✅ 통과 | 타이머-스케줄-리포트-설정 순서 직관적 |
| **용어 일관성** | ✅ 통과 | "스케줄", "어디서나 적용" 등 기존 용어 유지 |
| **기능 독립성** | ✅ 통과 | 타이머(수동), 스케줄(자동)은 독립적으로 작동 가능 |

**결론**: 🟢 **스케줄 탭 신설은 서비스 목적 및 사용자 프로세스와 완벽히 일관됩니다.**

## 1. 리뷰 의견 요약

### 1.1 핵심 문제점
**"예약설정이 설정 화면 아래 숨어있어 발견성이 낮고, 핵심 기능인데 옵션처럼 인식될 위험이 있음"**

**현재 정보 구조** (2025-11-03 기준):
```
하단 탭 3개: [타이머] [리포트] [설정]
                                   ↓
                     DetoxyControlSettingsScreen
                     ├─ 프리셋 선택 (완전/표준/완화)
                     ├─ 카테고리별 토글 (SNS, 메신저 등)
                     ├─ 권한 상태 (DND, 접근성, 오버레이)
                     ├─ 📍 예약설정 섹션 ← 여기에 숨어있음!
                     │   └─ [설정하기] → ScheduleGroupScreen
                     └─ 디톡시 루틴
```

**문제점**:
1. **깊이 (Depth) 문제**: 설정 탭 → 스크롤 → 예약설정 섹션 → 클릭 (최소 3단계)
2. **혼재 (Mix) 문제**: 일반 설정(권한, 프리셋)과 핵심 기능(예약설정)이 동일 레벨
3. **인식 (Perception) 문제**: "설정의 일부"로 인식 → "옵션"처럼 느껴짐
4. **반복 사용성 (Frequent Use)**: 스케줄 수정 시마다 깊은 depth 진입 필요

### 1.2 리뷰 권장 사항
1. **정보 구조 재조정**: 예약설정을 독립 섹션으로 승격
2. **내비게이션 재배치**: 하단 탭 또는 상단에 "스케줄" 탭 신설
3. **홈/대시보드 강화**: 홈 화면에 "다음 예약", "오늘의 루틴" 카드 추가
4. **문구 & 분류 수정**: "예약설정" → "자동 실행" 또는 "루틴 관리"
