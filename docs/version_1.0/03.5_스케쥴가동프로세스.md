flowchart TD
    %% === 런타임 엔진 메인 루프 (면적 우선 + 최근 유지) ===
    R0[백그라운드 엔진 시작] --> T1[현재 시각/요일 조회]
    T1 --> G1["현재 위치(GPS) 조회"]
    G1 --> M1["반경 내 포함되는 모든 위치 수집"]

    M1 --> C1{후보가 2개 이상인가?}
    C1 -->|"아니오(0)"| B0["어디서나 적용 스케줄 필터링"]
    C1 -->|"아니오(1)"| L0["단일 위치 확정"]
    C1 -->|예| S1["면적(반경) 가장 작은 위치만 남김"]

    %% 단일 위치 확정 경로 (🆕 수정)
    L0 --> TRESET["히스테리시스 타이머 리셋 및 기록"]

    %% 면적 우선 필터 이후
    S1 --> C2{여전히 2개 이상인가?}
    C2 -->|아니오| S2["단일 후보 확정"]
    C2 -->|예| RST["최근 활성 스케줄 유지 여부 확인"]

    %% 최근 활성 유지(히스테리시스)
    RST --> H1{직전 활성 위치가 후보에 포함?}
    H1 -->|예| H2{"히스테리시스 시간 내(120초)인가?"}
    H2 -->|예| KEEP["기존 스케줄 유지"]
    H2 -->|아니오| HRESET["히스테리시스 타이머 리셋"]
    H1 -->|아니오| HRESET

    %% 히스테리시스 만료 → 재평가
    HRESET --> DIST["거리 우선으로 결론"]

    %% 거리 우선 타이브레이커
    DIST --> C3{가장 가까운 위치 1개로 줄었나?}
    C3 -->|예| S2["단일 후보 확정"]
    C3 -->|아니오| MT["최근 수정(updatedAt) 최신 후보 선택"]

    MT --> S2
    
    %% 새 위치 확정 시 타이머 리셋
    S2 --> TRESET

    %% 단일 후보 스케줄 적용
    TRESET --> L3["위치 기반 스케줄 필터링(요일/시간)"]
    L3 --> C4{적용 가능?}
    C4 -->|예| ON["집중모드 ON + 시간대 알람 등록"]
    C4 -->|아니오| B0

    %% "어디서나 적용" 스케줄 경로 (구: 비위치/기본 정책)
    B0 --> B1["어디서나 적용 스케줄 필터링<br/>(요일/시간)"]
    B1 --> B2{2개 이상 적용 가능?}
    B2 -->|예| BP["우선순위: 구체적→최근수정→생성순"]
    B2 -->|아니오| B3{1개 적용 가능?}
    BP --> BON
    B3 -->|예| BON["어디서나 적용 스케줄 실행<br/>→ 집중모드 ON"]
    B3 -->|아니오| OFF[집중모드 OFF]

    %% 이벤트 루프
    ON --> EV["변경 이벤트 대기"]
    BON --> EV
    KEEP --> EV
    OFF --> EV
    EV -->|"위치 반경 진입/이탈"| HCHECK["히스테리시스 체크"]
    EV -->|"시간대 시작"| TSTART["시간표 활성화 + 알람 등록"]
    EV -->|"시간대 종료"| TEND["집중모드 종료 + 다음 시간대 대기"]
    
    HCHECK --> G1
    TSTART --> G1
    TEND --> T1

    %% 주석 노드
    N1["/충돌 해소 규칙<br/>1) 면적(반경) 우선<br/>2) 최근 활성 유지(히스테리시스 120초)<br/>   - 새 위치 전환 시 타이머 리셋<br/>   - 만료 시 즉시 재평가<br/>3) 거리 우선<br/>4) 최근 수정(updatedAt) 우선/"]
    S1 -. 참고 .- N1
    
    N2["/'어디서나 적용' 스케줄 우선순위<br/>(구: 비위치 스케줄)<br/>1) 더 구체적인 스케줄<br/>   (평일 > 매일)<br/>2) 최근 수정(updatedAt)<br/>3) 생성 순서(createdAt)/"]
    B0 -. 참고 .- N2

    %% 스타일(선택)
