## 1. 브랜드 아이덴티티

### 1.1 앱 컨셉

**ScreenSence**는 스마트폰 습관 교정을 위한 코치 앱입니다.

- **핵심 가치**: 자발적 참여, 습관 형성, 집중력 향상
- **타겟 사용자**: 청소년, 학생, 직장인 (집중이 필요한 모든 사용자)
- **차별화 포인트**: 시간/위치 기반 자동 실행, 스마트한 습관 형성

### 1.2 브랜드 톤앤매너

- **신뢰감**: 안정적이고 전문적인 느낌
- **친근함**: 접근하기 쉽고 사용하기 편한 느낌
- **동기부여**: 긍정적이고 격려하는 느낌
- **미니멀**: 깔끔하고 직관적인 디자인

## 2. 앱 아이콘 디자인 가이드

### 2.1 기술 사양

- **크기**: 512 x 512px (정사각형)
- **형식**: PNG (투명 배경 권장) 또는 JPEG
- **파일 크기**: 최대 1MB
- **해상도**: 고해상도 (레티나 디스플레이 대응)

### 2.2 디자인 컨셉

#### 컨셉 A: 집중 & 차단 (추천)

**아이디어**:
- 화면 잠금 아이콘 + 집중 아이콘 조합
- 방패 모양으로 보호/차단 의미 전달
- 시계/타이머 요소로 시간 관리 의미

**시각적 요소**:
- 중앙: 잠금 아이콘 또는 방패
- 배경: 그라데이션 (보라 → 틸)
- 강조: 집중을 나타내는 빛 효과

#### 컨셉 B: 습관 & 성장

**아이디어**:
- 체크마크 또는 성장 그래프
- 원형 진행 표시기 (타이머 느낌)
- 화살표로 향상/개선 의미

**시각적 요소**:
- 중앙: 체크마크 또는 원형 진행 표시
- 배경: 부드러운 그라데이션
- 강조: 성장을 나타내는 상승 효과

#### 컨셉 C: 시간 & 위치

**아이디어**:
- 시계 + 위치 핀 조합
- 자동 실행 기능 강조
- 스마트한 자동화 의미

**시각적 요소**:
- 중앙: 시계 또는 위치 핀
- 배경: 현대적인 그라데이션
- 강조: 자동화를 나타내는 연결선

### 2.3 색상 조합

**주요 색상** (선택 1):
- **보라 계열**: #6200EE (purple_500) - 신뢰감, 전문성
- **틸 계열**: #018786 (teal_700) - 차분함, 집중

**보조 색상**:
- **밝은 보라**: #BB86FC (purple_200) - 부드러운 느낌
- **밝은 틸**: #03DAC5 (teal_200) - 활기찬 느낌

**배경 옵션**:
1. **그라데이션 배경**: 보라 → 틸 (대각선 또는 원형)
2. **단색 배경**: 보라 또는 틸 (깔끔한 느낌)
3. **투명 배경**: 아이콘만 (시스템 테마에 맞춤)

### 2.4 디자인 원칙

✅ **권장 사항**:
- 단순하고 명확한 아이콘
- 작은 크기에서도 인식 가능
- Material Design 가이드라인 준수
- 브랜드 색상 일관성 유지
- 그림자/그라데이션으로 깊이감 표현

❌ **피해야 할 사항**:
- 너무 복잡한 디테일
- 텍스트 포함 (앱 이름 제외)
- 저작권 문제가 있는 이미지
- 투명도가 낮은 요소
- 너무 많은 색상 사용

### 2.5 레이아웃 제안

```

│                     │
│    ┌─────────┐     │
│    │         │     │

│    │         │     │
│    └─────────┘     │
│                     │
│   ScreenSence       │  ← 선택적 (작은 텍스트)

## 3. 그래픽 이미지 디자인 가이드

- **크기**: 1024 x 500px (가로형)

### 3.2 디자인 컨셉

#### 레이아웃 A: 기능 중심 (추천)

**구성**:
```
┌─────────────────────────────────────────┐
│  [왼쪽]              [오른쪽]            │
│  ┌──────┐          ┌──────────────┐    │

**요소**:
- 왼쪽: 앱 아이콘 (큰 크기)

- 오른쪽: 핵심 기능 3가지 (아이콘 + 텍스트)

### 3.3 핵심 메시지

**메인 메시지** (선택 1):
- "스마트폰 습관 교정 코치"
- "집중이 필요한 시간·장소에 자동으로 시작"
- "규칙적인 디톡시 습관을 만들어보세요"

**서브 메시지**:
- 시간 기반 자동 실행
- 위치 기반 자동 실행
- 집중 타이머 & 앱 차단
- 디톡시 리포트 & 보상

### 3.4 시각적 요소

**포함 가능한 요소**:
1. **앱 아이콘**: 왼쪽 또는 중앙 상단
2. **앱 스크린샷**: 주요 화면 미리보기
3. **기능 아이콘**: 시간, 위치, 타이머 아이콘
4. **일러스트**: 집중, 성장, 습관 형성 관련

**배경 스타일**:
- 그라데이션: 보라 → 틸 (대각선 또는 수평)
- 단색: 보라 또는 틸 (깔끔한 느낌)
- 패턴: 미묘한 기하학적 패턴
- 블러 효과: 배경에 블러 적용

## 4. 색상 팔레트

### 4.1 주요 색상

| 색상명 | HEX 코드 | RGB | 용도 |
|--------|----------|-----|------|
| **Primary Purple** | #6200EE | rgb(98, 0, 238) | 메인 브랜드 색상 |
| **Primary Teal** | #018786 | rgb(1, 135, 134) | 보조 브랜드 색상 |
| **Light Purple** | #BB86FC | rgb(187, 134, 252) | 강조, 그라데이션 |
| **Light Teal** | #03DAC5 | rgb(3, 218, 197) | 강조, 그라데이션 |

### 4.2 중립 색상

| 색상명 | HEX 코드 | 용도 |
|--------|----------|------|
| **Black** | #000000 | 텍스트, 아이콘 |
| **White** | #FFFFFF | 배경, 텍스트 |
| **Gray Dark** | #424242 | 서브 텍스트 |
| **Gray Light** | #F5F5F5 | 배경 |

### 4.3 그라데이션 조합

**추천 그라데이션**:
1. **보라 → 틸**: #6200EE → #018786 (대각선)
2. **밝은 보라 → 밝은 틸**: #BB86FC → #03DAC5 (부드러운 느낌)
3. **보라 → 어두운 보라**: #6200EE → #3700B3 (깊이감)

## 7. 제작 사양

### 7.1 앱 아이콘

**필수 사양**:
- 크기: **512 x 512px**
- 형식: PNG (투명 배경) 또는 JPEG
- 파일 크기: 최대 1MB
- 해상도: 72 DPI 이상 (권장: 144 DPI)

**추가 제작 권장**:
- 1024 x 1024px (원본, 나중에 리사이즈)
- 다양한 크기: 192px, 144px, 96px (테스트용)

### 7.2 그래픽 이미지

**필수 사양**:
- 크기: **1024 x 500px**
- 형식: PNG 또는 JPEG
- 파일 크기: 최대 15MB
- 해상도: 72 DPI 이상

**안전 영역**:
- 중요한 텍스트/요소는 중앙 80% 영역에 배치
- 가장자리 10%는 잘릴 수 있음

### 7.3 파일 명명 규칙

**앱 아이콘**:
- `app_icon_512x512.png`
- `screensence_icon_512.png`

**그래픽 이미지**:
- `feature_graphic_1024x500.png`
- `screensence_banner_1024x500.png`
