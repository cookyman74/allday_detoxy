# 메타데이터 정책 위반 최종 대응 가이드

**작성일**: 2025년 1월  
**거부 사유**: 메타데이터 정책 위반 - "익명으로 작성된 사용 후기" 포함  
**버전**: 6 (versionCode: 6)

---

## 🚨 핵심 문제점

Google Play Console이 **"익명으로 작성된 사용 후기"**를 앱 설명에서 발견했습니다.

**문제가 되는 내용**:
- "사용 시나리오" 섹션의 "학생", "직장인", "자가관리" 같은 예시
- 사용자 관점의 서술 ("~할 수 있습니다", "~해보세요" 등)
- 간접적인 사용 후기 형태의 문구

**해결책**: **모든 사용자 시나리오와 후기 형태의 문구를 완전히 제거**하고, **기능 설명만** 명확하게 작성해야 합니다.

---

## ✅ 수정된 앱 설명 (최종 버전)

### 간단한 설명 (80자 이내)

```
타이머 기반 집중 모드와 앱 차단 기능을 제공하는 습관 관리 앱입니다.
```

**또는 더 간결한 버전**:
```
집중 모드 타이머와 앱 차단 기능을 제공하는 앱입니다.
```

### 자세한 설명 (4000자 이내) - 최종 수정 버전

**⚠️ 중요**: 아래 설명은 **사용 시나리오, 사용자 후기, 과장 표현을 완전히 제거**한 버전입니다.

```
ScreenSence는 스마트폰 사용 습관 관리를 위한 집중 모드 앱입니다.

【주요 기능】

집중 타이머
시간을 설정하고 집중 모드를 시작할 수 있습니다. 타이머 실행 중에는 설정한 앱이 차단되고 잠금 화면이 표시됩니다. 5분부터 3시간까지 시간을 설정할 수 있으며, 자주 사용하는 시간은 프리셋으로 저장할 수 있습니다.

앱 차단
카테고리별로 앱을 차단할 수 있습니다. SNS, 메신저, 동영상, 웹, 기타 앱을 선택적으로 차단할 수 있습니다.

시간 기반 자동 실행
정해진 시간에 자동으로 집중 모드가 시작됩니다. 요일별 반복 설정이 가능하며, 최대 10개의 시간대를 등록할 수 있습니다.

위치 기반 자동 실행
특정 장소에 도착하면 자동으로 집중 모드가 시작됩니다. Google Places 검색으로 위치를 등록할 수 있으며, 반경을 50m부터 500m까지 설정할 수 있습니다. 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다.

디톡시 리포트
매일의 집중 시간과 성공률을 확인할 수 있습니다. 디톡시 위험 지수와 회복률 추세를 그래프로 확인할 수 있습니다.

보상 시스템
집중 모드를 완료하면 포인트를 획득합니다. 연속으로 성공할수록 스트릭이 쌓이며, 성공한 세션 수와 총 집중 시간이 기록됩니다.

【기술적 특징】

• 전화는 허용: 집중 중에도 긴급 전화는 받을 수 있습니다
• 배터리 효율적: 위치 기반 자동 실행은 Geofencing API를 사용하여 배터리 소모를 최소화합니다
• 프라이버시 보호: 위치 정보는 기기에만 저장되며 서버로 전송되지 않습니다
• 직관적인 UI: 도넛 그래프로 시간을 쉽게 설정할 수 있습니다
• 안정적인 알람: 정확 알람 권한을 지원하여 배터리 절약 모드에서도 정확하게 작동합니다
```

**⚠️ 제거된 내용**:
- ❌ "사용 시나리오" 섹션 전체 제거
- ❌ "학생", "직장인", "자가관리" 같은 사용자 예시 제거
- ❌ "~해보세요" 같은 권유 문구 제거
- ❌ "ScreenSence와 함께 건강한 스마트폰 사용 습관을 만들어보세요" 같은 마무리 문구 제거

## 🔍 Google Play Console에서 확인할 위치

### 1. 스토어 등록정보 → 앱 설명

1. **Google Play Console** 접속
2. **"스토어 등록정보"** 메뉴 클릭
3. **"앱 설명"** 섹션 확인
4. 위의 **"자세한 설명 (최종 수정 버전)"**으로 교체
5. **"간단한 설명"**도 위의 버전으로 교체

### 2. 스토어 등록정보 → 그래픽 자산

1. **"앱 아이콘"** 확인
2. **"스크린샷"** 확인 (최소 2개, 최대 8개)
3. **"홍보 이미지"** 확인 (1024 x 500px)

### 3. 스토어 등록정보 → 스토어 설정

1. **"앱 이름"** 확인: "ScreenSence"로 통일
2. **"개발자 이름"** 확인

## 🚀 재제출 절차

1. **Google Play Console 접속**
   - https://play.google.com/console
   - 앱 선택: **ScreenSence**

2. **스토어 등록정보 수정**
   - **"스토어 등록정보"** 메뉴 클릭
   - **"앱 설명"** 섹션에서 위의 **"자세한 설명 (최종 수정 버전)"**으로 교체
   - **"간단한 설명"**도 위의 버전으로 교체
   - **"앱 이름"** 확인: "ScreenSence"
   - **"스크린샷"** 확인 및 교체 (필요 시)
   - **"앱 아이콘"** 확인

3. **변경사항 저장**
   - 모든 변경사항 저장
   - "변경사항 검토" 클릭

4. **재제출**
   - **"테스트 및 출시"** → **"프로덕션"** (또는 내부 테스트)
   - **"변경사항 전송"** 클릭
   - 검토 요청

5. **검토 대기**
   - 일반적으로 1-3일 소요
   - 거부 시 구체적인 이유 확인
