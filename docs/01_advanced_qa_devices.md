## 4. 테스트 시나리오

### 4.1 집중모드 설정 테스트

#### 시나리오 1: 프리셋 선택
```
1. 집중모드 설정 화면 진입
2. "전체 차단" 프리셋 선택
3. 설정 저장
4. 타이머 시작
5. 각 카테고리 앱 실행 시도
   - SNS: Instagram (차단 확인 ✅)
   - Web: Chrome (차단 확인 ✅)
   - 영상: YouTube (차단 확인 ✅)
   - 메신저: KakaoTalk (허용 확인 ✅)
```

#### 시나리오 2: 커스텀 설정
```
1. "완화" 프리셋 선택
2. 메신저 카테고리 수동 활성화
3. 설정 저장
4. 타이머 시작
5. 메신저 앱 차단 확인 (KakaoTalk ✅)
6. SNS 앱 허용 확인 (Instagram ✅)
```

---

### 4.2 Room 마이그레이션 테스트

#### 시나리오 3: v1 → v2 마이그레이션
```
1. MVP 버전 (v1) 설치
2. 세션 3개 생성 (성공 2개, 실패 1개)
3. 앱 종료
4. 1차 고도화 버전 (v2) 설치 (OTA)
5. 앱 실행
6. 기존 세션 데이터 보존 확인 ✅
7. 새 필드 초기화 확인 (interruptedSeconds = 0) ✅
8. 리포트 화면에서 기존 데이터 정상 표시 ✅
```

#### 시나리오 4: v2 → v3 마이그레이션
```
1. Week 2A 버전 (v2) 설치
2. 세션 + FocusInterruption 데이터 생성
3. Week 2B 버전 (v3) 설치
4. 기존 데이터 보존 확인 ✅
5. 신규 테이블 생성 확인 (FocusDistraction, DetoxyRoutineLog, FocusSettings) ✅
6. 기본 설정 삽입 확인 (FocusSettings) ✅
```

---

### 4.3 리포트 고도화 테스트

#### 시나리오 5: Detoxy 위험 지수
```
1. 세션 10개 생성 (성공 7개, 실패 3개)
2. 방해요인 이벤트 5개 생성 (Instagram x3, YouTube x2)
3. 리포트 화면 진입
4. Detoxy 위험 지수 카드 확인 ✅
5. 점수 계산 정확도 검증 (예상: 32점) ✅
6. 위험 단계 표시 확인 ("안정") ✅
```

#### 시나리오 6: 방해요인 Top 3
```
1. 다양한 앱 차단 이벤트 생성
   - Instagram: 8회
   - YouTube: 5회
   - Chrome: 3회
2. 리포트 화면 진입
3. 방해요인 Top 3 카드 확인 ✅
4. 순위 및 횟수 정확도 검증 ✅
5. 앱 아이콘 표시 확인 ✅
```

---

### 4.4 권한 플로우 테스트

#### 시나리오 7: 권한 해제 후 재요청
```
1. 모든 권한 부여 상태에서 시작
2. 타이머 시작 (정상 작동 확인)
3. 설정 → 접근성 서비스 비활성화
4. 앱으로 복귀
5. 타이머 시작 시도
6. 권한 에러 다이얼로그 표시 확인 ✅
7. "설정으로 이동" 클릭 ✅
8. 접근성 서비스 재활성화
9. 앱으로 복귀 후 타이머 시작 (정상 작동) ✅
```

## 5. 성능 테스트

### 5.1 메모리 사용량
```
adb shell dumpsys meminfo com.allday.detoxy
```

**목표**:
- 유휴 상태: < 100MB
- 타이머 실행 중: < 150MB
- 오버레이 표시 중: < 180MB

---

### 5.2 배터리 소모
```
adb shell dumpsys batterystats --reset
# 24시간 사용 후
adb shell dumpsys batterystats > battery_stats.txt
```

**목표**:
- 일일 배터리 사용량: < 5%
- 타이머 1시간당 배터리 소모: < 2%

---

### 5.3 앱 크기
```
adb shell pm path com.allday.detoxy
adb pull /data/app/.../base.apk
ls -lh base.apk
```

**목표**:
- APK 크기: < 10MB
- 설치 후 크기: < 20MB

## 7. 버그 트래킹

### 7.1 버그 리포트 템플릿
```markdown
## 버그 제목
[간단한 설명]

## 재현 단계
1. [단계 1]
2. [단계 2]
3. [단계 3]

## 예상 결과
[정상 동작]

## 실제 결과
[실제 발생한 문제]

## 환경 정보
- 기기: Samsung Galaxy S23
- OS: Android 14 (One UI 6.1)
- 앱 버전: v2.0.0 (빌드 200)

## 로그
```
[logcat 출력 또는 스크린샷]
```

## 우선순위
- [ ] Critical (앱 크래시, 데이터 손실)
- [ ] High (주요 기능 동작 불가)
- [ ] Medium (일부 기능 오작동)
- [ ] Low (UI 이슈, 개선 제안)
```

---

### 7.2 버그 관리
- **도구**: GitHub Issues
- **라벨**:
  - `bug`: 버그
  - `critical`: 치명적 버그
  - `enhancement`: 개선 사항
  - `device-specific`: 특정 기기 이슈
  - `regression`: 회귀 버그
