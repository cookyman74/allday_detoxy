# Google Play 로그인 인증 정보 거절 대응 가이드

## 📋 거절 사유 분석

**거절 사유**:
```
제공하신 로그인 사용자 인증 정보에 다음과 같은 문제가 있어 앱을 검토할 수 없습니다.
- 제공된 사용자 아이디 또는 비밀번호가 잘못되었습니다.
- 데모 또는 게스트 계정 세부정보 누락
```

**원인 분석**:
- ScreenSence 앱은 **로그인 기능이 없는 완전 오프라인 앱**입니다.
- "액세스 제한 없이 앱의 모든 기능을 사용할 수 있음"으로 설정되어 있음에도 거절된 경우:
  1. **"추가 정보" 필드에 검토 방법 안내가 없어서** Google 검토자가 앱을 테스트하는 방법을 모를 수 있음
  2. ScreenSence는 **접근성 서비스 권한**이 필요한데, 이 권한 설정 방법을 안내하지 않아 검토자가 앱을 제대로 테스트하지 못했을 수 있음
  3. Google은 "앱 기능의 전부 또는 일부가 제한된 경우 Google에서 앱을 검토할 수 있는 방법에 관한 안내를 추가하세요"라고 명시하고 있음

**핵심 해결책**:
- **"앱 액세스 권한" 페이지 하단의 "추가 정보" 필드**에 검토 방법 안내를 명확히 작성해야 합니다.

---

## ✅ 해결 방법

### 0단계: 정책 상태 페이지에서 구체적인 거절 사유 확인 (가장 중요!)

1. **Google Play Console 접속**
   - https://play.google.com/console 접속
   - 앱 선택: **ScreenSence**

2. **정책 상태 페이지로 이동**
   - 대시보드에서 **"정책 상태로 이동"** 파란색 링크 클릭
   - 또는 **"정책 및 프로그램" → "정책 상태"** 메뉴

3. **거절 사유 상세 확인**
   - 거절된 항목 클릭하여 상세 내용 확인
   - **어떤 섹션에서 로그인 정보를 요구했는지** 확인
   - **수정해야 할 정확한 위치** 파악

### 1단계: 앱 액세스 페이지 확인

1. **앱 콘텐츠 → 앱 액세스 권한** 페이지로 이동
   - **"정책 및 프로그램" → "앱 콘텐츠" → "앱 액세스 권한"**

2. **라디오 버튼 확인**
   - ✅ **"액세스 제한 없이 앱의 모든 기능을 사용할 수 있음"** 선택되어 있는지 확인
   - 이미 선택되어 있다면 그대로 유지

3. **⚠️ 중요: "추가 정보" 필드가 보이지 않는 경우**
   - "액세스 제한 없이"를 선택하면 추가 정보 필드가 나타나지 않을 수 있습니다.
   - 이 경우 **다른 위치에서 검토 정보를 입력**해야 합니다 (2단계 참조)

4. **저장 버튼 클릭** (변경사항이 있다면)

### 2단계: 게시 개요에서 검토 정보 입력 (가장 중요!)

**⚠️ 핵심 해결책**: "게시 개요" 페이지에서 검토 정보를 입력해야 합니다.

1. **게시 개요 페이지로 이동**
   - 왼쪽 메뉴에서 **"게시 개요"** 클릭
   - 또는 대시보드에서 **"게시 개요로 이동"** 링크 클릭

2. **검토 정보 섹션 찾기**
   - 페이지에서 **"검토 정보"**, **"앱 검토를 위한 정보"**, **"추가 정보"** 같은 섹션 찾기
   - 또는 **"앱 액세스"** 관련 섹션 찾기

3. **검토 방법 안내 입력**
   - 다음 내용을 입력 필드에 작성:

```
ScreenSence는 로그인 기능이 없는 완전 오프라인 앱입니다.

앱 검토 방법:
1. 앱 설치 후 즉시 사용 가능합니다. 로그인이나 계정 생성이 필요하지 않습니다.
2. 앱 실행 시 온보딩 화면이 표시됩니다. "다음" 버튼을 눌러 진행하세요.
3. 권한 설정 화면에서 다음 권한을 활성화해야 합니다:
   - 접근성 서비스: "ScreenSence" 찾아 활성화
   - 다른 앱 위에 표시: 허용
   - 방해금지 모드 액세스: 허용
4. 권한 설정 완료 후 타이머 화면에서 시간을 설정하고 "시작" 버튼을 눌러 테스트할 수 있습니다.

주의사항:
- 로그인, 회원가입, 계정 생성이 필요하지 않습니다.
- 모든 기능은 오프라인에서 동작합니다.
- 위치 기반 자동 실행 기능은 선택 사항이며, 사용하지 않아도 앱의 핵심 기능을 테스트할 수 있습니다.
```

4. **저장**

### 3단계: 테스트 및 출시에서 검토 정보 확인

1. **테스트 및 출시 → 프로덕션** (또는 내부 테스트) 메뉴로 이동
2. **제출된 버전** 클릭하여 상세 정보 확인
3. **"검토 정보"** 또는 **"추가 정보"** 섹션 확인
4. **"테스트 계정"**, **"로그인 정보"** 같은 필드가 있는지 확인
5. **해당 필드가 있다면**:
   - **비워두기** (로그인이 필요하지 않으므로)
   - 또는 **"앱에 로그인 기능이 없습니다."** 명시

### 4단계: 앱 콘텐츠의 다른 섹션 확인

**"앱 콘텐츠"** 메뉴의 다른 항목들도 확인:

1. **"앱 액세스 권한"** (이미 확인함)
2. **"데이터 보안"** 섹션 (아래 상세 가이드 참조)
   - Firebase Analytics 사용 시 익명 데이터 수집 명시
   - 로그인과 무관함을 명확히 표시
   - 데이터 삭제 요청 방법 설정
   - 광고 ID 사용 목적 명시
3. **"권한"** 섹션
   - 각 권한의 사용 목적 명확히 설명
4. **"타겟 그룹 및 콘텐츠"** 섹션
   - 앱이 모든 사용자에게 무료로 제공됨을 명시

#### 📋 데이터 보안 섹션 상세 설정 가이드

**"앱 콘텐츠 → 데이터 보안"** 페이지에서 다음 항목들을 확인하고 설정하세요:

##### ✅ 이미 올바르게 설정된 항목
- ✅ **"사용자가 앱 외부에서 만든 계정으로 앱에 로그인할 수 있나요?"** → **"아니요"** 선택됨
- ✅ **"앱에서 사용자가 계정을 만들도록 허용하지 않음"** → 체크됨
- ✅ **"앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?"** → **"예"** 선택됨 (Firebase Analytics 사용)
- ✅ **"앱에서 수집하는 모든 사용자 데이터를 암호화하여 전송하나요?"** → **"예"** 선택됨

##### ⚠️ 추가로 설정해야 할 항목

1. **"사용자가 데이터 삭제를 요청할 수 있는 방편을 제공하나요?"**
   - **선택**: **"아니요(하지만 사용자 데이터가 90일 이내에 자동으로 삭제됨)"**
   - **이유**: 
     - ScreenSence는 로컬 데이터만 저장하며, 앱 삭제 시 모든 데이터가 자동으로 삭제됩니다.
     - Firebase Analytics 데이터는 Google의 정책에 따라 14개월 후 자동 삭제됩니다.
     - Firebase Crashlytics 데이터는 90일 후 자동 삭제됩니다.
   - **대안**: "아니요" 선택도 가능하지만, 위 옵션이 더 정확합니다.

2. **광고 ID 사용 여부** (AD_ID 권한 사용 시)
   - **"앱 콘텐츠 → 데이터 보안"** 페이지에서 **"광고 ID"** 섹션 찾기
   - **"광고 ID를 수집하거나 공유하나요?"** → **"예"** 선택
   - **"광고 ID 사용 목적"** → **"분석 목적"** 선택
   - **설명 추가**: "Firebase Analytics를 통한 익명화된 사용 통계 수집 목적으로만 사용됩니다. 로그인 기능과 무관하며, 개인을 식별할 수 없습니다."

3. **Firebase Analytics 데이터 수집 명시**
   - **"데이터 수집 및 보안"** 섹션에서 **"필수 데이터 유형 보기"** 클릭
   - **"기기 또는 기타 ID"** 섹션에서:
     - **"기기 ID"** → **"예"** 선택
     - **설명**: "Firebase Analytics를 통한 익명화된 기기 ID만 수집됩니다. 개인 식별이 불가능하며, 앱 사용 통계 분석 목적으로만 사용됩니다."
   - **"앱 상호작용"** 섹션에서:
     - **"앱 상호작용"** → **"예"** 선택
     - **설명**: "타이머 시작, 세션 완료 등 기능 사용 패턴을 익명화하여 수집합니다. 개인을 식별할 수 없습니다."

4. **가족 정책 준수** (이미 설정됨)
   - ✅ **"Google Play 가족 정책을 준수하겠다고 약속한 앱입니다"** → **"예"** 선택됨
   - 이 설정은 올바르게 되어 있습니다.

### 5단계: 앱 스토어 등록정보 확인

**"스토어 등록정보"** 메뉴에서도 확인:

1. **"앱 설명"** 섹션
   - 앱 설명에 "로그인 불필요", "오프라인 앱" 명시되어 있는지 확인
   - 혹시 "회원가입", "로그인" 같은 단어가 있다면 제거

2. **"앱 기능"** 섹션
   - "로그인" 기능이 목록에 있다면 제거

## 🔍 추가 확인 사항

### Firebase Analytics 사용 여부 확인

앱이 Firebase Analytics를 사용하는 경우, Google Play Console에서 다음을 확인:

1. **데이터 보안 섹션**
   - Firebase Analytics 사용 여부 명시
   - **중요**: Firebase Analytics는 **익명 데이터 수집**이므로 로그인과 무관합니다.

2. **광고 ID 사용 여부**
   - `com.google.android.gms.permission.AD_ID` 권한 사용 시
   - "광고 ID 사용" 섹션에서 **"분석 목적"** 선택
   - 로그인과 무관함을 명시

### 앱 권한 설명 확인

**앱 콘텐츠 → 권한** 섹션에서 각 권한의 사용 목적을 명확히 설명:

- **접근성 서비스**: 앱 차단 기능을 위한 필수 권한
- **다른 앱 위에 표시**: 잠금 화면 표시를 위한 필수 권한
- **위치 권한**: 위치 기반 자동 실행 기능 사용 시 선택 권한
- **정확 알람**: 시간 기반 자동 실행 기능 사용 시 선택 권한

## 🚨 주의사항

### ❌ 하지 말아야 할 것

1. **가짜 테스트 계정 정보 제공**
   - 로그인이 없는 앱에 테스트 계정을 만들지 마세요.
   - Google Play 팀이 실제로 테스트할 수 없어 추가 거절될 수 있습니다.

2. **"로그인 필요"로 잘못 설정 유지**
   - 앱에 로그인 기능이 없다면 반드시 "로그인 불필요"로 설정해야 합니다.

3. **불명확한 설명**
   - "로그인이 선택 사항입니다" 같은 모호한 표현은 피하세요.
   - "로그인 기능이 없습니다"라고 명확히 명시하세요.

### ✅ 올바른 접근

1. **명확한 설명**
   - "ScreenSence는 완전 오프라인 앱입니다. 로그인 기능이 없으며, 모든 기능은 기기에서만 동작합니다."

2. **정확한 설정**
   - Google Play Console에서 "로그인 불필요" 선택
   - 테스트 계정 정보 필드 비워두기

3. **일관성 유지**
   - 앱 설명, 데이터 보안, 앱 액세스 모든 섹션에서 일관된 설명 제공

## 📞 추가 도움이 필요한 경우

### Google Play Console 지원팀 문의

만약 위 방법으로 해결되지 않는다면:

1. **Google Play Console → 도움말** 메뉴
2. **"문의하기"** 또는 **"지원팀에 문의"** 선택
3. 다음 내용으로 문의:
   ```
   제목: 로그인 불필요한 오프라인 앱 제출 관련 문의
   
   내용:
   ScreenSence 앱은 로그인 기능이 없는 완전 오프라인 앱입니다.
   모든 기능은 기기에서만 동작하며 서버 연동이 필요하지 않습니다.
   
   앱 액세스 설정에서 "로그인 불필요"로 설정했으나,
   여전히 로그인 인증 정보를 요구받고 있습니다.
   
   앱 검토를 위해 추가로 필요한 정보가 있는지 확인 부탁드립니다.
   ```

### Google Play Console 지원팀에 문의

위의 모든 단계를 완료했는데도 같은 거절 사유를 받는다면:

1. **Google Play Console → 도움말** 메뉴
2. **"문의하기"** 또는 **"지원팀에 문의"** 선택
3. 다음 내용으로 문의:

```
제목: 로그인 불필요한 오프라인 앱 제출 관련 문의

내용:
ScreenSence 앱은 로그인 기능이 없는 완전 오프라인 앱입니다.
모든 기능은 기기에서만 동작하며 서버 연동이 필요하지 않습니다.

현재 설정 상태:
- 앱 액세스 권한: "액세스 제한 없이 앱의 모든 기능을 사용할 수 있음" 선택
- 테스트 계정 정보: 모든 필드 비워둠
- 앱 설명: "오프라인 앱, 로그인 불필요" 명시

그러나 여전히 "로그인 사용자 인증 정보" 관련 거절을 받고 있습니다.

앱 검토를 위해 추가로 필요한 정보나 설정이 있는지 확인 부탁드립니다.
또는 구체적으로 어떤 섹션에서 로그인 정보를 요구하는지 알려주시면 감사하겠습니다.
```
